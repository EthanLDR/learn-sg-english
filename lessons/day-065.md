# Day 65 | Is that included, or is it extra? Clarify scope and the full cost

### 今日主题：工作需求、报价和生活消费中，先问清“包含什么、额外算什么”

今天练一个新技能：**ask what's included → identify what's extra → confirm the total or scope → decide the next action**（问清包含项 → 找出额外项 → 确认总范围或总价 → 再行动）。昨天练礼貌表达不同意见；今天练一个更具体的沟通能力：**不要因为听到一个估算或套餐名称，就默认所有东西都包含在里面。**

> **Is that included, or is it extra?** 那个包含在内，还是需要额外付费／做额外工作？
>
> **What exactly does the estimate cover?** 这个估算具体包含哪些工作？
>
> **Does the price include all applicable charges?** 价格包含所有适用费用吗？
>
> **Would that be a separate task?** 那需要单独作为一个任务吗？
>
> **Could we confirm the total before proceeding?** 继续之前能确认一下总额吗？

**included** = 已包含；**extra** = 额外的；**on top of** = 在……之外再加；**out of scope** = 不在本次工作范围；**itemised breakdown** = 逐项明细。工作中要区分 **estimate（估算）** 和 **commitment（正式承诺）**；消费中要区分 **advertised price（标示价格）** 和 **final amount（最终金额）**。本课只模拟沟通，不预设任何商家、银行或平台实际收费规则。

复习句型只占少量时间：**I'm still waiting for / should be able to / by、on、before / 未来 if 条件句**。练习时先大声说，再核对文字。

**严格计时：0–5（5）+ 5–17（12）+ 17–23（6）+ 23–30（7）+ 30–35（5）+ 35–37（2）+ 37–38（1）+ 38–40（2）= 40 分钟。** 全部朗读、替换、准备和自检均在各自时间段内。

---

## 0–5 min | Warm-up：先问包含项

**0–2 min｜四句各朗读三遍，余下时间连起来说：**

> **Could you clarify what's included?** 可以说明一下包含哪些内容吗？
>
> **Does that cover testing as well?** 那也包含测试吗？
>
> **Would there be any additional charges?** 还有其他额外费用吗？
>
> **I'd like to check the full details before deciding.** 我想看清完整细节后再决定。

**2–4 min｜每轮一分钟；第一轮分角色读，第二轮遮住 You：**

**PM:** Can you estimate the new settings screen?

**You:** Sure. Just to clarify, does that include the API integration and QA support?

**PM:** The API work is separate, but please allow time to support QA.

**You:** Got it. I'll make the assumptions and exclusions clear in my estimate.

第二轮替换 **settings screen → upload screen**、**API integration → analytics tracking**，保持同样的确认逻辑。

**4–5 min｜口译三句，剩余时间核对：**

“我还在等最终报价。” → **I'm still waiting for the final quote.**

“如果中午前收到，我应该能最迟下午四点确认总价。” → **If it arrives by noon, I should be able to confirm the total by 4 p.m.**

“这个估算也包含测试吗？” → **Does this estimate include testing as well?**

## 5–17 min | Office Communication & Meetings

### 5–9 min | Scene 1：前端工期估算，避免漏算依赖工作

**PM:** Can we finish the new profile screen by Friday?

**You:** I should be able to estimate it, but could we clarify what's included first?

**PM:** The layout, form validation, and save flow.

**You:** Does the scope include updating the backend API or just integrating the existing endpoint?

**PM:** Backend changes are a separate task. Please include frontend error states and QA support.

**You:** Understood. I'll estimate the frontend work and list the API dependency separately.

**PM:** When can you share the breakdown?

**You:** I'm still waiting for the final field list. If it arrives by noon, I should be able to share an estimate by 4 p.m. I'll flag any assumptions.

**5–7 min：**朗读两轮；第二轮只看 PM 的话，说出 You 的回应。**7–8 min：**脱稿回答：What is included? What's separate? What's still missing? **8–9 min：**40 秒复述，20 秒自检：

> **The estimate covers ___. It doesn't include ___. I'm still waiting for ___. If ___, I should be able to share ___ by ___.**

**assumptions** = 估算所依赖的假设；**exclusions** = 明确不包含的工作。**I should be able to estimate it** 不等于承诺周五一定交付所有工作。

### 9–13 min | Scene 2：会议中新增埋点需求，确认是否影响既定范围

**Lead:** The design is approved. Let's add analytics events before release.

**You:** That sounds useful. Is analytics tracking already included in the agreed scope?

**PM:** Not explicitly. We need to understand the extra effort.

**You:** Could we list the events, confirm who defines them, and estimate the implementation separately?

**Lead:** Would this affect the release plan?

**You:** Possibly. Let's compare the extra work against the current timeline before making a commitment.

**PM:** Good. Please record the breakdown in the ticket.

**You:** Will do. I'll distinguish the existing scope from the proposed addition.

**9–11 min：**朗读两轮；第二轮将 **analytics events → accessibility improvements**。**11–12 min：**按 **new request → included? → owner → effort → decision** 复述。**12–13 min：**脱稿表达：

> **I understand the request. Could we check whether ___ is already in scope? If not, let's estimate ___ separately and confirm whether it affects ___.**

**scope creep** = 需求范围不断增加；指出额外工作不是拒绝合作，而是让优先级和时间承诺更准确。

### 13–15 min | Scene 3：Code Review 中确认“修复”是否包含回归测试

**Reviewer:** This PR fixes the empty-state message.

**You:** Thanks. Does it also cover the loading and error states, or only the empty state?

**Reviewer:** Only the empty state. Those other cases are unchanged.

**You:** Got it. I'll keep the review focused on this change, but I won't mark the other states as verified.

**Reviewer:** Can you add that limitation to the description?

**You:** Yes. I'll note what's covered and what hasn't been tested in this PR.

**13–14 min：**朗读，重读 **only / also / hasn't been tested**。**14–15 min：**40 秒复述 **included change → excluded cases → evidence → PR note**；20 秒说：**A narrow fix doesn't automatically verify unrelated states.**

### 15–17 min | Timed oral substitution：12 轮，每轮 10 秒

**15:00–15:40｜A. 问工作范围（4 轮）**

模板：**Does the estimate include ___ as well?**

1. API integration
2. error-state handling
3. analytics tracking
4. QA support

**15:40–16:20｜B. 问额外成本或任务（4 轮）**

模板：**Is ___ included, or would it be extra?**

1. delivery
2. an extended warranty
3. an additional stop
4. a new analytics event

**16:20–17:00｜C. 条件与期限（4 轮）**

模板：**If ___, I should be able to ___ ___.**

1. the field list arrives by noon / send the estimate / by 4
2. QA replies on Monday / update the scope / on Tuesday
3. the quote arrives today / decide / before Friday
4. the details are confirmed by Thursday / send the summary / on Friday

每轮 **3 秒看提示 + 7 秒完整说句子**，恰好 120 秒。**by Friday** 最迟周五；**on Friday** 周五当天；**before Friday** 不包含周五。

## 17–23 min | Colleague Small Talk & Socializing

### 17–20 min | Scene 4：同事约午餐，确认套餐是否包含饮料

**Colleague:** This lunch set looks good. Shall we try it?

**You:** Sure! Do you know whether the set includes a drink?

**Colleague:** I'm not sure. Let's check the menu.

**You:** Good idea. If the drink is extra, I'll just order water separately.

**Colleague:** Sounds good. We can order when everyone gets here.

**You:** Great. I'll check the options while we're waiting.

**17–18 min：**朗读两轮。**18–19 min：**替换 **drink → dessert**、**lunch set → dinner set**。**19–20 min：**40 秒脱稿说 **interest → included item? → alternative → friendly close**，20 秒复读。

**set meal / lunch set** 都可指套餐；具体包含什么看店家菜单，不用想当然。

### 20–23 min | Scene 5：参加同事活动，问费用怎样分摊

**Colleague:** We're organising badminton on Sunday. Want to join?

**You:** I'd love to. How are we splitting the court fee?

**Colleague:** We haven't worked out the amount per person yet.

**You:** No problem. Does the fee include equipment, or should I bring my own racket?

**Colleague:** Bring your own for now. We'll confirm the cost in the chat.

**You:** Thanks! I'm still waiting to confirm my schedule. If I'm free, I'll let you know by Friday.

**20–21 min：**朗读。**21–22 min：**换成 **board games / venue charge / entry fee**。**22–23 min：**40 秒按 **interest → cost sharing → included items → conditional reply** 脱稿说，20 秒自检。

**split the bill / split the cost** = 分摊账单或费用；**How much do I owe?** = 我应付多少？也是自然说法。

## 23–30 min | Restaurant / Shopping / Ride-hailing

### 23–25 min | Restaurant：结账前确认总金额

**You:** Excuse me, is this the final amount for the order?

**Staff:** Please check the total shown on the bill.

**You:** Thanks. Does it already include any applicable taxes and service charges?

**Staff:** Let's review the itemised bill together.

**You:** Great. I'd like to confirm the total before paying.

**23–24 min：**朗读；注意 **applicable** 表示“适用的”，不预设每家店都有相同收费。**24–25 min：**替换 **service charges → takeaway packaging charges**，说 **ask total → ask breakdown → pay after checking**。

### 25–27 min | Shopping：耳机报价是否包含配件和保修

**Staff:** This is the price for the headphones.

**You:** Thanks. Does that price include the charging case and the standard warranty?

**Staff:** Let's check what's included in the official product listing.

**You:** Are there any optional extras I should know about?

**Staff:** We can review the available accessories and their prices.

**You:** Perfect. I'll compare the full cost before choosing.

**25–26 min：**朗读。**26–27 min：**替换 **headphones → monitor**、**charging case → cable**，练 **base price → included accessories → optional extras**。实际包装内容及保修以对应商品说明为准。

### 27–30 min | Ride-hailing：多停一站可能影响车费

**Colleague:** Can we make another stop on the way?

**You:** Maybe, but let's check whether the booking allows an extra stop.

**Colleague:** Would that cost more?

**You:** It might. Could we check the updated fare and route in the app before changing anything?

**Colleague:** Sure. Let's check first.

**You:** If the option is available and the total works for us, we can decide through the app.

**27–28 min：**朗读两轮。**28–29 min：**替换 **extra stop → different destination**、**updated fare → estimated fare**。**29–30 min：**40 秒按 **new request → permitted? → extra charge? → official decision** 脱稿说，20 秒自检。费用与改程支持以平台实时规则为准。

## 30–35 min | Practical Singapore Errands

### 30–33 min | Scene 9：银行账户费用，看懂基本服务和附加收费

**You:** Hi, I'm comparing account options. Could you explain which services are included?

**Support:** Please check the account's official fees and terms.

**You:** Thanks. Are there any minimum-balance requirements or charges I should be aware of?

**Support:** Please review the relevant fee schedule for that account.

**You:** Understood. Could you point me to an itemised breakdown of any fees?

**Support:** Please use the bank's official product information.

**You:** Great. I'll confirm the terms before applying rather than assume the account is free.

**30–31 min：**朗读。**31–32 min：**按 **account option → what's included → possible charges → official fee schedule** 复述。**32–33 min：**替换成 **debit card / overseas transaction fees**，问三句：**What's included? / Are there extra fees? / Where can I find the official fee schedule?** 不假设具体银行费用或豁免资格。

### 33–35 min | Scene 10：手机套餐，看月费之外的项目

**You:** Hi, the monthly price looks reasonable, but I'd like to understand the full cost.

**Staff:** Which parts would you like to check?

**You:** Does the plan include roaming, or are overseas data charges separate?

**Staff:** Please review the plan's official roaming and billing terms.

**You:** Thanks. I'm still waiting for the written plan summary. If I receive it today, I should be able to compare the options before Friday.

**33–34 min：**朗读。**34–35 min：**40 秒脱稿说 **advertised price → included allowance → extra charges → written terms → decision**；20 秒自检。漫游是否包含、何时生效等以运营商条款为准。

## 35–37 min | Accurate Grammar Corrections

**35–36 min｜先独立修改前三句，再核对：**

1. ❌ **Is the delivery include in the price?** → ✅ **Is delivery included in the price?**（被包含：be + included）
2. ❌ **Does it includes testing?** → ✅ **Does it include testing?**（does 后接动词原形）
3. ❌ **How much does it costs in total?** → ✅ **How much does it cost in total?**（does 后接动词原形）

**36–37 min｜复习两句：**

4. ❌ **I'm still waiting the final quote.** → ✅ **I'm still waiting for the final quote.**
5. ❌ **If the details will arrive today, I should able to decide by Friday.** → ✅ **If the details arrive today, I should be able to decide by Friday.**（普通未来 if 条件句用现在时；should be able to）

**正确替代，不算错误：** **Is delivery included? / Does the price include delivery?** 都自然；**Is there an extra charge? / Does that cost extra?** 都正确；**What's the full cost? / How much is it altogether?** 都正确。**I'll decide by Friday / on Friday / before Friday** 都正确，但时间含义不同。

**37:00–37:30：**遮住英文，看中文快速口译。**37:30–38:00：**每句换成自己的工作或生活场景。

## 38–40 min | Final Speaking Challenges

### 38–39 min | Workplace：40 秒脱稿 + 15 秒参考核对 + 5 秒自检

提示：**profile screen → layout, validation, save flow → backend changes separate → frontend error states + QA support → final field list pending → if noon → estimate by 4 → assumptions**。

**38:00–38:40：**不看参考，向 PM 说明工期范围。**38:40–38:55：**对照参考句。**38:55–39:00：**确认已说明包含、不包含、依赖和期限。

> **Before I commit to an estimate for the profile screen, could we clarify what's included? I understand the scope covers the layout, form validation, save flow, frontend error states and QA support. Backend API changes are a separate task. I'm still waiting for the final field list. If it arrives by noon, I should be able to share an estimate by 4 p.m. I'll list the assumptions and exclusions clearly.**

### 39–40 min | Everyday：40 秒脱稿 + 15 秒参考核对 + 5 秒自检

提示：**mobile plan → advertised monthly price → roaming included? → any extra charges? → official written summary → decide before Friday if suitable**。

**39:00–39:40：**不看参考，向运营商询问费用。**39:40–39:55：**核对参考。**39:55–40:00：**检查有没有把标价直接当最终总价。

> **Hi, I'm comparing mobile plans. The monthly price looks reasonable, but I'd like to know exactly what's included. Does it cover roaming, or would overseas data cost extra? Are there any other charges I should consider? Could you show me the official plan summary and an itemised breakdown? If the terms meet my needs, I should be able to decide before Friday. Thank you.**

**40 分钟完成。今天最重要的一句：Is that included, or is it extra? Could we confirm the full scope or total before proceeding?**
