# Day 73 | What's our backup plan? Handle setbacks without losing momentum

### 今日主题：计划遇到阻碍时，提出可行的 Plan B，并约定什么时候切换

今天的新技能是 **name the risk → offer a backup option → set a trigger → confirm the next update**（指出风险 → 提出备用方案 → 明确切换条件 → 确认下一次更新）。昨天练习比较“之前和现在”；今天往前一步：即使问题暂时没解决，也能让团队和生活安排继续有序推进。

> **What's our backup plan if this doesn't work?** 如果这个方案行不通，我们的备选方案是什么？
>
> **We could use mock data for the internal demo.** 内部演示可以先使用模拟数据。
>
> **Let's agree on when to switch to Plan B.** 我们先约好什么时候启用备用方案。
>
> **This is a temporary workaround, not a permanent fix.** 这只是临时变通办法，不是永久修复。
>
> **If the API isn't ready by noon, I'll flag the risk and discuss the fallback with the owner.** 如果中午前 API 还没准备好，我会提示风险，并和负责人讨论备用方案。

**fallback** = 备用方案；**workaround** = 绕过问题的临时办法；**trigger** = 启动某项行动的条件；**roll back** = 回退到先前版本（需遵循授权发布流程）；**rain check** = 这次先不约、改天再说。今天特别注意：**Plan B 不是擅自跳过 QA、生产安全检查或客户告知**。所有技术和服务场景都是模拟练习，不代表真实项目或商家当前状态。

自然回收 **I'm still waiting for / should be able to / by、on、before / if + 一般现在时**。重点练英语口头反应，不重复长篇规则。

**严格 40 分钟：0–5（5）+ 5–17（12）+ 17–23（6）+ 23–30（7）+ 30–35（5）+ 35–37（2）+ 37–38（1）+ 38–40（2）= 40。** 各段的朗读、替换、思考及核对均计入该时间段。

## 0–5 min | Warm-up：主方案 + 备用方案

**0–2 min｜四句各朗读三遍；剩余时间连起来说：**

> **Let's stick with the original plan for now.** 目前先按原计划进行。
>
> **What if the API is still unavailable?** 如果 API 仍不可用呢？
>
> **We need a fallback that we can explain clearly.** 我们需要一个能清楚说明的备用方案。
>
> **I'll keep everyone updated.** 我会持续同步进展。

**2–4 min｜每轮一分钟；第一轮读完整对话，第二轮遮住 You：**

**PM:** Can we still show the AI feature in tomorrow's internal demo?

**You:** I'm still waiting for the API confirmation. Could we prepare an approved mock-data demo as a fallback?

**PM:** Would that show the real integration?

**You:** No. We'd clearly label it as a UI demonstration, not a verified end-to-end flow.

第二轮替换 **AI feature → upload feature**、**mock-data demo → recorded UI walkthrough**，说清备用方案的限制。

**4–5 min｜先中文转英文，再核对：**

“如果原计划行不通，备用方案是什么？” → **If the original plan doesn't work, what's our backup plan?**

“我还在等 QA 回复。” → **I'm still waiting for QA's reply.**

“如果中午前收到，我应该能最迟四点准备好演示。” → **If I receive it by noon, I should be able to prepare the demo by 4 p.m.**

## 5–17 min | Office Communication & Meetings

### 5–9 min | Scene 1：AI API 尚未就绪，如何准备内部演示

**PM:** The AI endpoint may not be ready for the demo. What do you suggest?

**You:** I'd keep the real integration as Plan A. For Plan B, could we prepare an approved mock-data walkthrough?

**PM:** Would the audience think the AI response is live?

**You:** We should make it explicit that the response is simulated. We shouldn't present it as a working integration.

**QA:** When would we switch to the backup?

**You:** Let's ask the demo owner to confirm a cutoff. For example, if the endpoint isn't verified by noon, we could use the labelled walkthrough.

**PM:** When will you update us?

**You:** I'm still waiting for the API status. If it arrives before noon, I should be able to share the integration findings by 4 p.m. Either way, I'll give a status update at the agreed time.

**5–7 min：**分角色朗读两轮；第二轮遮住 You。**7–8 min：**脱稿回答：What's Plan A? What's Plan B? Who approves the switch? **8–9 min：**40 秒口述、20 秒自检：

> **Plan A is ___. If ___, we could use ___ as a fallback. We'd clearly explain ___. I'll confirm the switch with ___ and update everyone by ___.**

**cutoff** = 截止判断点；**simulated** = 模拟的。使用 mock data 是为了展示 UI，不等于验证了真实 AI 服务。

### 9–13 min | Scene 2：会议中提出失败后的处理方案

**Lead:** What if the new client-side change causes a serious regression?

**You:** First, we'd follow the approved incident and release procedures. Could we agree on the escalation trigger before rollout?

**QA:** We should define which symptoms require us to stop.

**You:** Agreed. We can monitor the agreed signals and notify the release owner if the threshold is reached.

**Lead:** Should we roll back automatically?

**You:** Not without an authorised process. Let's confirm who can make that decision and how we'd verify recovery.

**PM:** Can you document the plan?

**You:** Yes. I'll record the trigger, owner, communication channel and recovery checks before the release review.

**9–11 min：**朗读两轮；第二轮替换 **serious regression → critical loading failure**、**release owner → incident owner**。**11–12 min：**按 **risk → trigger → authorised decision → recovery check** 复述。**12–13 min：**60 秒自由输出：

> **If ___ happens, we should ___. The decision owner is ___. We shouldn't ___ without approval. After the action, we'll verify ___.**

**escalate** = 向有决策权的人升级问题；**threshold** = 判断阈值。不要把“有回退方案”理解成“工程师能自行改动生产环境”。

### 13–15 min | Scene 3：Code Review 中讨论不可靠的第三方依赖

**Reviewer:** What happens if the optional analytics service is unavailable?

**You:** The main user flow shouldn't depend on that optional service. Could we check the agreed failure behaviour?

**Reviewer:** Are you suggesting we silently ignore every error?

**You:** No. We should handle the failure appropriately, keep the required user flow working where safe, and retain suitable diagnostics.

**Reviewer:** How would we test that?

**You:** We can simulate the approved failure case and verify the expected behaviour without exposing private data.

**13–14 min：**朗读，重读 **optional / shouldn't depend on / where safe**。**14–15 min：**40 秒总结 **dependency → failure mode → intended fallback → test**，20 秒再说：**A fallback should be tested, not just assumed to work.**

### 15–17 min | Timed oral substitution：12 轮 × 10 秒

**15:00–15:40｜A. 提出备用方案（4 轮）**

模板：**If ___ isn't available, could we use ___ instead?**

1. the API / approved mock data
2. the latest build / the previous approved build
3. the meeting room / another available room
4. the final design / the approved wireframe for discussion

**15:40–16:20｜B. 说明触发条件（4 轮）**

模板：**If ___ happens, we'll ___ after confirming with the owner.**

1. the test fails / pause the handoff
2. the reviewer finds a blocker / revise the plan
3. the demo environment goes down / use the prepared walkthrough
4. the agreed threshold is reached / start the escalation process

**16:20–17:00｜C. 复习期限（4 轮）**

模板：**If ___, I should be able to ___ ___.**

1. the API responds by noon / finish the check / by 4
2. QA replies on Monday / update the plan / on Tuesday
3. the owner approves today / prepare the fallback / before Friday
4. the review finishes by Thursday / share the summary / on Friday

每轮 **3 秒看提示 + 7 秒说完整句**，总计 120 秒。**by Friday** = 最迟周五；**on Friday** = 周五当天；**before Friday** = 周五之前。

## 17–23 min | Colleague Small Talk & Socializing

### 17–20 min | Scene 4：同事约午饭，餐厅排队太长怎么办

**Colleague:** Shall we try that popular noodle place for lunch?

**You:** I'd love to. What's our backup if the queue is too long?

**Colleague:** There's another food court nearby.

**You:** That works. We could check the queue first, then switch if we don't have enough time.

**Colleague:** Good idea. Our next meeting is at 1:30.

**You:** Exactly. If the wait looks too long, let's choose the quicker option.

**17–18 min：**朗读两轮。**18–19 min：**替换 **noodle place → chicken rice stall**、**food court → hawker centre**。**19–20 min：**40 秒脱稿说 **preferred place → risk → alternative → switch condition**，20 秒复读。

**queue** = 排队（新加坡常用）；**the queue is too long** = 队伍太长。不要编造实际等候时间。

### 20–23 min | Scene 5：周末下雨，户外活动准备 Plan B

**Colleague:** We're planning a picnic on Sunday.

**You:** Sounds fun! Have we got a backup plan in case it rains?

**Colleague:** We could move the gathering indoors if everyone agrees.

**You:** Good idea. Could we confirm the indoor option before Saturday?

**Colleague:** I'll check with the group.

**You:** Thanks. If the weather looks unsuitable, let's agree on the change early instead of making everyone travel twice.

**20–21 min：**朗读。**21–22 min：**替换 **picnic → outdoor badminton**、**indoors → another suitable venue**。**22–23 min：**40 秒说 **interest → weather risk → alternative → group confirmation**，20 秒自检。

**in case it rains** = 以防下雨；**if it rains** = 如果真的下雨。两句都正确，前者更突出提前准备。

## 23–30 min | Restaurant / Shopping / Ride-hailing

### 23–25 min | Restaurant：想点的菜卖完了，快速换一道

**You:** Hi, I'd like the beef noodle soup, please.

**Staff:** Sorry, it's sold out.

**You:** No problem. What would you recommend as an alternative if I still want a spicy soup dish?

**Staff:** You can check the other available noodle dishes on the menu.

**You:** Thanks. Could you confirm the ingredients and price before I order?

**23–24 min：**朗读。**24–25 min：**替换 **beef noodle soup → spicy rice noodles**、**spicy soup dish → non-spicy soup**，练 **preferred choice → unavailable → alternative → verify**。若有食物过敏，必须向店家确认配料及交叉接触风险。

### 25–27 min | Shopping：想买的型号缺货，不接受随意替换

**Staff:** The monitor you selected isn't in stock.

**You:** Thanks for checking. Is there a comparable model with the same required ports?

**Staff:** Let's compare the available models and their official specifications.

**You:** I'd rather wait than buy something incompatible. Could you explain the return terms if I choose an alternative?

**Staff:** Please review the store's written policy for that item.

**You:** Great. I'll decide after comparing the specifications and full cost.

**25–26 min：**朗读。**26–27 min：**替换 **monitor → keyboard**、**ports → device compatibility**，练 **unavailable → substitute criteria → terms → decision**。

### 27–30 min | Ride-hailing：司机取消行程之后怎样安全应对

**Colleague:** The ride was cancelled. What should we do now?

**You:** Let's check the booking status and available options in the app.

**Colleague:** Should we ask a random driver to take us?

**You:** I'd rather use an authorised booking option. We can compare another ride or a suitable public-transport route.

**Colleague:** Good point. Do we need to tell the others?

**You:** Yes. If our arrival time changes, I'll message them with the updated estimate.

**27–28 min：**朗读两轮。**28–29 min：**替换 **ride was cancelled → pickup point is unavailable**、**another ride → another permitted pickup point**。**29–30 min：**40 秒脱稿说 **disruption → check app → safe alternative → update others**，20 秒自检。不要绕过平台安全机制或要求违规停车。

## 30–35 min | Practical Singapore Errands

### 30–33 min | Scene 9：银行办理材料不符合要求，问可接受的替代文件

**You:** Hi, I want to prepare for my account appointment. What if one of my supporting documents isn't accepted?

**Support:** Please check the bank's official list of acceptable documents.

**You:** Is there an approved alternative I could bring, or would I need to arrange another appointment?

**Support:** Please follow the published requirements and appointment instructions.

**You:** Understood. I won't assume that a different document will be accepted without confirmation.

**Support:** Please keep the relevant reference details for official follow-up.

**You:** Thanks. I'll check the requirements before going to the branch.

**30–31 min：**朗读。**31–32 min：**按 **document risk → approved alternative? → official confirmation → next visit** 复述。**32–33 min：**替换为 **address-update supporting documents**，说三句：**What if this document isn't accepted? / Is there an official alternative? / Do I need to rebook?** 不假定某家银行或政府机构接受特定材料。

### 33–35 min | Scene 10：手机网络暂时不可用，先问可执行的排查方案

**You:** Hi, my mobile data isn't working. Is there an official troubleshooting step I should try first?

**Support:** Please follow the provider's published checks for your device and plan.

**You:** If those checks don't help, what's the next support option?

**Support:** Please use the provider's official case and escalation channels.

**You:** Thanks. I'm still waiting for the case update. If it arrives today, I should be able to follow the next step before tomorrow.

**33–34 min：**朗读。**34–35 min：**40 秒口述 **initial checks → if unsuccessful → official escalation → follow-up**，20 秒自检。不通过陌生链接提供 OTP、密码或账户凭据。

## 35–37 min | Accurate Grammar Corrections

**35–36 min｜先独立改三句，再核对：**

1. ❌ **If the API won't works, we'll use mock data.** → ✅ **If the API doesn't work, we'll use mock data.**（一般未来条件句：if + 一般现在时；doesn't 后用动词原形）
2. ❌ **What if the plan will fail?** → ✅ **What if the plan fails?**（询问未来可能情形时常用现在时）
3. ❌ **We need a backup plan in case of it rains.** → ✅ **We need a backup plan in case it rains.** / ✅ **We need a backup plan in case of rain.**（in case + 从句；in case of + 名词）

**36–37 min｜旧句型复习：**

4. ❌ **I'm still waiting the API update.** → ✅ **I'm still waiting for the API update.**
5. ❌ **If QA will reply today, I should able to finish before Friday.** → ✅ **If QA replies today, I should be able to finish before Friday.**（if + 一般现在时；should be able to）

**正确替代，不算语法错误：** **What's our backup plan? / What's Plan B? / What if that doesn't work?** 都自然；**We could use a fallback / We could prepare an alternative** 都正确；**if it rains / in case it rains** 都正确但侧重点不同。**by Friday / on Friday / before Friday** 都正确，截止范围不同。**If the API doesn't work** 也可能描述一般情况；有明确未来语境时同样自然。

Is there an officially approved alternative I could bring, or would I need to arrange another appointment? Could you point me to the written requirements and the correct booking process? I'd rather confirm the options before visiting the branch. Thank you.**
