# Day 35 | Troubleshooting clearly: reproduce the problem before proposing a fix

### Theme: 先问清“何时发生、怎样复现、影响谁”，再讨论解决方案

今天学习一种工程师很常用、生活中也很实用的沟通方式：**不要一听到“有问题”就猜原因；先确认症状、复现步骤和影响范围，再约定下一次更新。**

核心顺序：**symptom → steps → frequency → impact → next check**。

- **What exactly happens when you tap the button?** 你点按钮后具体发生什么？
- **Could you walk me through the steps?** 能带我过一遍操作步骤吗？
- **Does it happen every time or only sometimes?** 每次都会发生，还是偶尔发生？
- **When did you first notice it?** 你最早什么时候发现的？
- **Let me try to reproduce it.** 我先尝试复现。
- **I’m still waiting for the logs. If they arrive by noon, I should be able to narrow it down today.** 我还在等日志；如果中午前拿到，今天应该能缩小排查范围。

**计时：0–5 + 5–17 + 17–23 + 23–30 + 30–35 + 35–37 + 37–38 + 38–40 = 恰好 40 分钟。** 每段严格按指定时间练，参考答案用于核对，不额外增加时间。

---

## 0–5 min | Warm-up：先问问题，不急着判断

### 0–2 min | Read aloud

每句读两遍，刻意把疑问词和关键动词读清楚。

> **What exactly happens when you tap the button?**  
> 点击按钮后具体会发生什么？

> **Could you walk me through the steps?**  
> 你能按顺序说一下操作过程吗？

> **Does it happen every time?**  
> 是每次都发生吗？

> **When did you first notice it?**  
> 你是什么时候最先注意到的？

> **Let me try to reproduce it.**  
> 我先尝试复现。

### 2–4 min | One symptom, three questions

情境：同事说 **“The page sometimes freezes.”**（页面有时卡住。）

连续问出三个问题，不要先下结论：

> **Which page does it happen on?**  
> **Does it happen every time or only sometimes?**  
> **What were you doing just before it froze?**

第 2 轮替换问题情境：**“The upload sometimes fails.”**

参考：

> **Which file types are affected?**  
> **Does it fail every time?**  
> **What error message do you see?**

### 4–5 min | Quick retrieval

看中文，立刻说英文：

1. 我先试着复现。
2. 这个问题影响所有用户吗？
3. 我还在等日志。

参考：

> **Let me try to reproduce it.**  
> **Does this affect all users?**  
> **I’m still waiting for the logs.**

# 5–17 min | Office Communication & Meetings

## 5–9 min | 场景 1：PM 说“支付按钮坏了”，但信息还不够

**PM:**  
The Pay button seems broken. Can you fix it?

**You:**  
I’ll take a look. What exactly happens when you tap it?

**PM:**  
Nothing happens for a few seconds, and then I see an error.

**You:**  
Got it. Does it happen every time or only sometimes?

**PM:**  
Only sometimes, mostly on mobile.

**You:**  
Could you walk me through the steps you took just before it happened?

**PM:**  
I changed the delivery address and then tapped Pay.

**You:**  
That helps. I’ll try the same steps on mobile. I’m still waiting for the request logs, so I don’t want to guess at the root cause yet.

**PM:**  
When can you update us?

**You:**  
If the logs come through by noon, I should be able to narrow down the cause this afternoon.

**5–7 min：**两人角色朗读，先读 PM，再只读 You 的句子。  
**7–8 min：**遮住 You 的句子，依次问出 **symptom / frequency / steps** 三个问题。  
**8–9 min：**用 30–45 秒总结已知信息，再说明下一步。

参考总结：

> **So far, the issue is intermittent and seems more common on mobile. I’ll reproduce the address-change flow and check the logs before suggesting a fix.**

实用模板：

> **What exactly happens when ___?**  
> **Does it happen every time or only sometimes?**  
> **Could you walk me through ___?**

**intermittent** = 间歇性出现的。口语中说 **It happens sometimes** 也完全正确。

---

## 9–13 min | 场景 2：QA 报 bug，你需要最小可复现步骤

**QA:**  
I found a bug in the profile form.

**You:**  
Thanks for flagging it. Which browser and device were you using?

**QA:**  
Safari on an iPhone.

**You:**  
What are the steps to reproduce it?

**QA:**  
Open the profile page, change the display name, and tap Save twice quickly.

**You:**  
And what do you expect to happen?

**QA:**  
The name should be saved once, and the Save button should become disabled while the request is running.

**You:**  
What actually happens?

**QA:**  
Two requests are sent, and sometimes the second one fails.

**You:**  
Got it. I’ll try those steps and check whether the button prevents duplicate submissions.

这里有一个重要的工作表达：

> **What did you expect to happen?** = 预期是什么？  
> **What actually happened?** = 实际发生了什么？

别把 **expected** 和 **actual** 混在一起。复现 bug 时，这两项比一句 “It’s broken” 有用得多。

**9–11 min：**分角色读对话一轮，再把浏览器替换成 Chrome on Android，重新问一次。  
**11–12 min：**只看关键词 **device → steps → expected → actual**，独立提四个问题。  
**12–13 min：**模拟给 QA 回答：

> **Thanks, that’s enough for me to start. I should be able to reproduce it before lunch. If I need more details, I’ll follow up.**

这句话表达的是“可以开始排查”，**不是**承诺已经修好。

---

## 13–15 min | 场景 3：会议里汇报排查进度，不制造假确定性

**Manager:**  
Do we have a fix for the duplicate requests?

**You:**  
Not yet. I can reproduce the issue, but I haven’t confirmed the cause.

**Manager:**  
What have you ruled out?

**You:**  
It doesn’t happen on every form. So far, I’ve only seen it when Save is tapped twice quickly.

**Manager:**  
What’s next?

**You:**  
I’ll check the loading-state logic and the request logs. If I find the cause today, I should be able to propose a fix before Friday.

### 13–14 min | Read and repeat

> **I can reproduce it, but I haven’t confirmed the cause.**  
> 我能复现，但还没确认根因。

> **So far, I’ve only seen it when ___.**  
> 到目前为止，我只在……时观察到它。

> **The next step is to check ___.**  
> 下一步是检查……

### 14–15 min | Speak without notes

用 **known → unknown → next step** 说 30–45 秒。

注意：**reproduce / identify the cause / fix / verify** 是四个不同阶段。不要把“能复现”说成“已经解决”。

---

## 15–17 min | Two-minute oral substitution drill

**每组四轮，每轮约 15 秒；总计 2 分钟。必须开口替换。**

### 15:00–15:40 | Pattern A: Ask for symptoms

> **What exactly happens when you tap Save?**

替换：

1. open the settings page
2. upload a large image
3. switch accounts
4. refresh the dashboard

### 15:40–16:20 | Pattern B: Check frequency

> **Does it happen every time or only sometimes?**

替换：

1. only on mobile
2. only after a refresh
3. only with large files
4. only on a slow connection

练习把回答接成完整句：

> **It only happens with large files.**

### 16:20–17:00 | Pattern C: Conditional update

> **If I get the logs by noon, I should be able to narrow it down today.**

替换：

1. the screenshots / by 2 p.m. / reproduce it this afternoon
2. the API response / today / confirm the affected flow tomorrow
3. QA's results / before lunch / update the ticket today
4. the fix / by Thursday / retest it on Friday

# 17–23 min | Colleague Small Talk & Socializing

## 17–20 min | 场景 1：同事说家里网络老掉线，轻松帮忙但不装专家

**Colleague:**  
My Wi-Fi has been acting up all morning.

**You:**  
Oh no. Does it keep disconnecting, or is it just slow?

**Colleague:**  
It keeps disconnecting during calls.

**You:**  
Is it happening on your phone too, or only on your laptop?

**Colleague:**  
Only on my laptop, I think.

**You:**  
That’s useful to know. You could try reconnecting to the network first. If it keeps happening, maybe check with your IT team.

**Colleague:**  
Good idea. Thanks!

这里要练的是“先问清楚，再给低风险建议”，不是给同事做完整技术支持。

> **Has been acting up** = 最近总是出问题、不太正常。  
> **Is it just slow?** = 只是速度慢吗？  
> **You could try ___ first.** = 可以先试试……，语气比命令柔和。

**17–18 min：**朗读。  
**18–19 min：**将 Wi-Fi 换成 Bluetooth headset，练 “Does it disconnect or just sound unclear?”  
**19–20 min：**用 30 秒讲：症状、适用设备、建议下一步。

---

## 20–23 min | 场景 2：同事组织聚餐，消息里信息不一致

**Colleague:**  
A few people say they can't see the dinner booking in the app.

**You:**  
Is everyone having the issue, or only the people who joined later?

**Colleague:**  
Only those who joined later, I think.

**You:**  
Could you check whether their names were added to the booking?

**Colleague:**  
Good point. I’m still waiting for the organiser to confirm.

**You:**  
No worries. If we get the final headcount by 5, we should be able to confirm the table before dinner.

> **Is everyone affected, or only ___?**  
> 是所有人都受影响，还是只有……？

> **If we get ___ by ___, we should be able to ___.**  
> 如果最迟……拿到……，应该就能……

**20–21 min：**对话朗读。  
**21–22 min：**把 booking 换成 shared event invitation（共享活动邀请），重新问影响范围。  
**22–23 min：**不看稿，邀请同事帮忙确认最终人数，并说清截止时间。

# 23–30 min | Restaurant / Shopping / Ride-hailing

## 23–25 min | Restaurant：订单不对，准确描述而不争论原因

**You:**  
Hi, I think there’s been a mix-up with my order.

**Staff:**  
What seems to be wrong?

**You:**  
I ordered chicken rice without chilli, but this one has chilli on it.

**Staff:**  
Sorry about that. Would you like us to replace it?

**You:**  
Yes, please. Could you make sure the replacement has no chilli?

**Staff:**  
Of course.

要点是区分 **what I ordered** 和 **what I received**：

> **I ordered ___, but I received ___.**  
> **Could you make sure the replacement ___?**

**23–24 min：**对话朗读。  
**24–25 min：**把 chicken rice 换成 an iced coffee without sugar，再完整说两句。菜品只是口语情境，不涉及商家实际政策。

---

## 25–27 min | Shopping：设备偶尔关机，向售后说清频率

**Staff:**  
What problem are you having with the device?

**You:**  
It turns off unexpectedly after a few minutes.

**Staff:**  
Does that happen every time?

**You:**  
Not every time. It seems to happen more often when I use it while charging.

**Staff:**  
When did you first notice it?

**You:**  
Yesterday evening. Could you check what the next step is for an inspection?

> **It turns off unexpectedly.** = 它会意外关机。  
> **It seems to happen more often when ___.** = 似乎在……时更容易发生。  
> **Could you check what the next step is?** = 能帮我确认下一步怎么处理吗？

**25–26 min：**对话朗读。  
**26–27 min：**换成耳机“右耳偶尔没声音”，用 **symptom → frequency → first noticed → next step** 说四句。

---

## 27–30 min | Ride-hailing：司机找不到你，排查是不是上车点不同

**Driver:**  
I’m at the pickup point, but I can’t see you.

**You:**  
Could I confirm which pickup point you’re at?

**Driver:**  
Pickup Point A, near the main entrance.

**You:**  
Ah, the app is showing Pickup Point B for me, beside the taxi stand.

**Driver:**  
I see. Can you come to A?

**You:**  
Yes. I’m still waiting for the lift, but I should be there in about three minutes.

**Driver:**  
Okay, I’ll stay here.

**You:**  
Thanks. If you need to move, please message me in the app.

高频：

> **The app is showing ___ for me.**  
> **Could I confirm where you are?**  
> **I should be there in about ___ minutes.**

**27–28 min：**朗读。  
**28–29 min：**把 A/B 互换，重新说明不同位置。  
**29–30 min：**独立说 30–45 秒：确认上车点、解释自己位置、预计到达时间。实际上车时仍要通过平台核对车辆信息。

# 30–35 min | Practical Singapore Life Errands

## 30–33 min | 场景 1：空调故障，向维修人员描述可复现现象

**Technician:**  
What seems to be wrong with the air conditioner?

**You:**  
It starts normally, but after about ten minutes it stops blowing cold air.

**Technician:**  
Does the whole unit turn off?

**You:**  
No. The fan keeps running, but the air becomes warm.

**Technician:**  
Does it happen every time?

**You:**  
Almost every time in the evening. I first noticed it on Monday.

**Technician:**  
I’ll check the unit.

**You:**  
Thanks. Before you leave, could you let me know what you found and whether another visit is needed?

> **It starts normally, but after ___ it ___.**  
> **The fan keeps running, but ___.**  
> **Before you leave, could you let me know ___?**

**30–31 min：**对话朗读。  
**31–32 min：**扮演维修人员，问三句：什么时候开始、多久后发生、是否每次发生。  
**32–33 min：**换成热水器故障练四句：正常部分、异常部分、频率、下一步。

---

## 33–35 min | 场景 2：网上提交材料失败，确认操作步骤

**You:**  
Hi, I’m trying to upload a supporting document, but the portal keeps showing an error.

**Staff:**  
At which step does the error appear?

**You:**  
Right after I select the file and tap Upload.

**Staff:**  
Does it happen with every file?

**You:**  
I’ve only tried one PDF so far. Is there a file-size limit I should check?

**Staff:**  
Please check the upload requirements shown on the page.

**You:**  
Understood. If it still fails after I check them, what’s the best way to report the problem?

> **At which step does the error appear?**  
> **Right after I ___.**  
> **If it still fails, what should I do next?**

**33–34 min：**对话朗读。  
**34–35 min：**把 supporting document 换成 proof of address，独立说明问题并问下一步。具体上传要求以实际办事网站为准。

# 35–37 min | Accurate Grammar Corrections

**35–36 min：**读前两组和第三组；每一组先自己纠正，再看答案。

### 1 | 一般疑问句需要助动词

❌ **How often it happens?**  
✅ **How often does it happen?**

但 **I want to know how often it happens.** 是正确的间接疑问句，不要误判。

### 2 | did 后用动词原形

❌ **When did you first noticed it?**  
✅ **When did you first notice it?**

### 3 | wait for

❌ **I’m still waiting the logs.**  
✅ **I’m still waiting for the logs.**

**36–37 min：**读后两组，并分别自己造一个句子。

### 4 | 普通未来条件句

❌ **If it will happen again, I’ll take a screenshot.**  
✅ **If it happens again, I’ll take a screenshot.**

在这里 if 从句表示普通未来条件，通常用一般现在时。

### 5 | should be able to

❌ **I should can reproduce it today.**  
✅ **I should be able to reproduce it today.**

三句都正确，但时间不同：

> **I’ll update you by Friday.** = 最迟周五更新  
> **I’ll update you on Friday.** = 周五当天更新  
> **I’ll update you before Friday.** = 周五之前更新

# 37–38 min | Compact Review：一分钟快速回顾

**37:00–37:30：**遮住右列，把中文提示说成英文。  
**37:30–38:00：**倒过来，看英文说使用场景；不必重读所有对话。

| 目的 | 直接说 |
|---|---|
| 具体症状 | **What exactly happens when ___?** |
| 操作步骤 | **Could you walk me through the steps?** |
| 发生频率 | **Does it happen every time or only sometimes?** |
| 最早出现时间 | **When did you first notice it?** |
| 影响范围 | **Is everyone affected, or only ___?** |
| 预期与实际 | **What did you expect to happen? What actually happened?** |
| 尝试复现 | **Let me try to reproduce it.** |
| 表达尚未确认 | **I can reproduce it, but I haven’t confirmed the cause.** |
| 等待依赖 | **I’m still waiting for the logs.** |
| 条件化更新 | **If I get them by noon, I should be able to narrow it down today.** |
| 时间词 | **by Friday / on Friday / before Friday** |

今天记住一条原则：**Ask for evidence before making a diagnosis.**（下判断前，先收集依据。）

# 38–40 min | Final Speaking Challenges

## 38–39 min | Workplace: Bug triage

只看关键词，连续说 **45–60 秒**，剩余时间自检：

**mobile → after changing address → sometimes → steps → logs → still waiting → by noon → next update**

参考（先自己说，再看）：

> **I’m looking into the checkout issue. So far, it seems to happen only sometimes, mostly on mobile after the delivery address changes. Could you walk me through the exact steps one more time? I’ll try to reproduce it and check the request logs. I’m still waiting for those logs, so I haven’t confirmed the root cause yet. If they arrive by noon, I should be able to give you a clearer update this afternoon.**

## 39–40 min | Everyday: Fault report

只看关键词，说 **45–60 秒**：

**air conditioner → ten minutes → warm air → every evening → first noticed → technician → next step**

参考：

> **Hi, I’m reporting an issue with my air conditioner. It turns on normally, but after about ten minutes the air becomes warm even though the fan is still running. It happens almost every evening, and I first noticed it on Monday. Could someone check what might be causing it? After the inspection, could you tell me what you found and whether a follow-up visit is needed?**

最终检查：你的表达有没有说清 **现象、频率、步骤或时间、下一步**？如果能不看稿自然说完两段，今天的 40 分钟就完成了。
