# Day 26 | Reprioritizing work when something urgent comes in

### Theme: 突然插入紧急任务时，既配合优先级变化，又把原计划、影响和新时间说清楚

今天重点练一个工程师非常高频的场景：**正在做 A，突然有人让你马上做 B。你不需要只说“Okay”，而是要确认新优先级、说明会被挤掉的事情，并给出新的完成时间。**

你会反复练这几个动作：

- 确认是否真的要切优先级：**Should I treat this as the top priority?**
- 说明取舍：**If I switch to this now, the current task will move to tomorrow.**
- 让对方明确哪个任务后移：**Which task would you like me to push back?**
- 给现实承诺：**I should be able to get the critical part done by Friday.**
- 继续同步依赖：**I’m still waiting for the backend API, so that part is unchanged.**

同时继续复习：**I’m still waiting... / should be able to / by / on / before / future if**。

---

## 0–5 min | Warm-up：把“新任务进来 → 重新排优先级”说顺

下面 5 句，每句大声说 3 遍。

> **Should I treat this as the top priority?**  
> 我应该把这个当成最高优先级吗？

> **If I switch to this now, the current task will move to tomorrow.**  
> 如果我现在切到这个任务，当前任务就会顺延到明天。

> **Which task would you like me to push back?**  
> 你希望我把哪个任务往后推？

> **I’m still waiting for the backend API, so that dependency hasn’t changed.**  
> 我还在等后端 API，所以这个依赖并没有变化。

> **I should be able to get the critical part done by Friday.**  
> 我应该能在周五前把关键部分完成。

快速复习：

- **by Friday** = 最迟周五完成
- **on Friday** = 周五当天发生
- **before Friday** = 周五之前，不包括周五

Future `if`：

> **If this becomes the top priority, I’ll pause the reporting work.**

不是：

> ❌ If this will become the top priority...

# 5–17 min | Office Communication & Meetings

## 5–9 min | 场景 1：经理突然插入一个紧急任务

**Manager:**  
We have a production issue. Can you look at it now?

**You:**  
Yes. Should I treat this as the top priority?

**Manager:**  
Yes, please.

**You:**  
Got it. I’ll pause the dashboard work and switch to the production issue. If I do that now, the dashboard changes will probably move to tomorrow.

**Manager:**  
That’s fine.

**You:**  
Okay. I’ll send you an update once I know the root cause.

这里的核心不是“拒绝紧急任务”，而是让优先级变化变得明确：

> **Should I treat this as the top priority?**

> **I’ll pause ___ and switch to ___.**

> **If I do that now, ___ will move to ___.**

这样可以避免后面出现：

> “为什么原来的任务还没做完？”

### Reusable Pattern

> **If this becomes the top priority, I’ll pause ___ and move ___ to ___.**

例如：

> If this becomes the top priority, I’ll pause the refactor and move it to tomorrow.

> If this becomes the top priority, I’ll pause the analytics work and move it to next week.

---

## 9–13 min | 场景 2：两个任务都说“很急”，你需要让对方做取舍

**PM:**  
Can you finish the checkout fix today as well?

**You:**  
I can work on it today, but I’m already handling the production issue. Which one should take priority?

**PM:**  
The production issue is more important.

**You:**  
Okay. In that case, I’ll focus on production first and pick up the checkout fix after that.

**PM:**  
Can we still release the checkout fix on Friday?

**You:**  
If the production issue is resolved by tomorrow morning, I should be able to finish the checkout fix by Friday.

非常好用的句型：

> **Which one should take priority?**

> **Which task would you like me to push back?**

> **I can do both, but not at the same time.**

> **If we move this up, something else will need to move back.**

最后一句特别适合优先级管理：不是说“不做”，而是明确“资源是有限的”。

---

## 13–15 min | 场景 3：你的依赖并不会因为任务变急就自动消失

**Manager:**  
Can we bring the integration forward and finish it tomorrow?

**You:**  
I can prioritize it, but I’m still waiting for the backend API.

**Manager:**  
So what can you do today?

**You:**  
I can finish the UI and prepare the integration layer. If the API is ready by 3 p.m., I should be able to start integration today. Otherwise, the earliest realistic finish is Thursday.

这里很重要：

> **I can prioritize it, but I’m still waiting for ___.**

“任务更急”不等于“依赖消失”。

再加一句会更专业：

> **The priority has changed, but the dependency hasn’t.**

---

## 15–17 min | 2-minute Oral Substitution Drill

不要默读，直接快速替换。

### Pattern 1

> **Should I treat this as the top priority?**

替换：

- Should I pause the current task and switch to this?
- Should this come before the checkout work?
- Do you want me to handle this first?
- Is this more urgent than the release work?

### Pattern 2

> **If I switch to this now, the dashboard task will move to tomorrow.**

替换：

- the code review / this afternoon
- the refactor / next week
- testing / Thursday
- the documentation / after the release

### Pattern 3

> **If the API is ready by 3 p.m., I should be able to finish by Friday.**

替换：

- get approval by noon / merge today
- resolve the incident before lunch / resume testing this afternoon
- receive the design today / finish before Friday
- get the data by Wednesday / release on Friday

# 17–23 min | Colleague Small Talk & Socializing

## 17–20 min | 场景 1：原本约了咖啡，但临时有事

**Colleague:**  
Still up for coffee at 3?

**You:**  
I’d like to, but something urgent just came up.

**Colleague:**  
No worries.

**You:**  
Can we push it back to 4? If I finish this by then, I should be free.

**Colleague:**  
Sure, just let me know.

几个非常自然的表达：

> **Something urgent just came up.**  
> 刚临时出了点急事。

> **Can we push it back to 4?**  
> 我们能推迟到 4 点吗？

> **Can we move it to tomorrow instead?**  
> 要不改到明天？

注意 `push back` 在这里是“往后推时间”。

---

## 20–23 min | 场景 2：朋友临时改计划，你需要确认新安排

**Colleague:**  
Dinner at 7 might be too late for me. Can we do 6 instead?

**You:**  
Six might be difficult because I have a call before that. Would 6:30 work?

**Colleague:**  
Yeah, 6:30 works.

**You:**  
Great. If my call finishes early, I’ll message you and come over sooner.

这里可以练：

> **Would 6:30 work?**

> **Six might be difficult for me.**

> **If my call finishes early, I’ll let you know.**

Future `if` 仍然是一般现在时：

> If my call **finishes** early...

不是：

> ❌ If my call **will finish** early...

# 23–30 min | Restaurant / Shopping / Ride-hailing

## 23–25 min | Restaurant：想点的菜没了，需要快速换方案

**Staff:**  
Sorry, the grilled fish is sold out.

**You:**  
No problem. What’s the quickest alternative?

**Staff:**  
The chicken rice should be ready in about ten minutes.

**You:**  
That works. I need to leave by 1:30, so I’ll go with that.

这里的重点是：你有时间约束时，直接说出来。

> **What’s the quickest alternative?**

> **I need to leave by 1:30.**

> **I’ll go with that.**

`by 1:30` = 最迟 1:30 要离开。

---

## 25–27 min | Shopping：原计划买某款，但库存变化

**Staff:**  
The black one is out of stock, but we have the blue one.

**You:**  
I see. Do you know when the black one will be back in stock?

**Staff:**  
Probably on Friday.

**You:**  
Okay. If it’s back in stock by Friday afternoon, I can come back. Otherwise, I’ll take the blue one today.

继续复习：

> **on Friday** = 周五这一天补货

> **by Friday afternoon** = 最迟周五下午已经有货

> **If it’s back in stock by Friday afternoon, I can come back.**

---

## 27–30 min | Grab：司机临时要求换上车点

**Driver:**  
The main entrance is blocked. Can you come to Pickup Point C instead?

**You:**  
Sure. I’m still waiting for the lift, but I should be downstairs in about two minutes.

**Driver:**  
Okay, I’ll wait at Pickup Point C.

**You:**  
Thanks. If the entrance is still blocked, I’ll meet you there.

如果你不确定位置：

> **Is Pickup Point C next to the taxi stand?**

> **Could you send me the exact pickup point in the app?**

重点仍然是：变化发生后，马上确认新的执行方案。

# 30–35 min | Practical Singapore Life Errands

## 30–33 min | 场景 1：维修时间临时变了，你需要重新安排

**Staff:**  
Hi, the technician can’t come this morning. Can we move the appointment to this afternoon?

**You:**  
What time this afternoon?

**Staff:**  
Between 3 and 5.

**You:**  
I have a meeting at 4. Could you come before 4 if possible?

**Staff:**  
We should be able to arrive around 3:30.

**You:**  
Okay. If the technician is delayed, could you let me know before 3?

这里复习三个时间概念：

> **before 4** = 4 点之前

> **around 3:30** = 大约 3:30

> **by 3** = 最迟 3 点前通知我

实用句型：

> **Could we move the appointment to ___?**

> **Could you come before ___ if possible?**

> **If anything changes, could you let me know by ___?**

---

## 33–35 min | 场景 2：办事时突然发现还缺一个文件

**Staff:**  
We also need your proof of address.

**You:**  
I don’t have the original with me today. Can I submit the rest first and bring that document tomorrow?

**Staff:**  
Yes, that’s fine.

**You:**  
Great. If I bring it in before noon tomorrow, should everything still be processed by Friday?

**Staff:**  
Yes, it should.

这里非常实用：

> **Can I submit the rest first?**

> **Can I bring the missing document tomorrow?**

> **If I bring it in before noon, should it still be processed by Friday?**

遇到条件变化，不要只问“可以吗”，把**新方案 + 时间影响**一起确认。

# 35–38 min | Common Grammar Fixes

今天只纠正确实有问题的句子。

### 1

❌ **Which task should I delay it?**  
✅ **Which task should I delay?**  
✅ **Which task should I push back?**

`which task` 已经是宾语，不需要再加 `it`。

---

### 2

❌ **If I will switch to this now, the other task will be late.**  
✅ **If I switch to this now, the other task will be late.**

Future `if` 条件从句通常用一般现在时。

---

### 3

❌ **I should can finish the critical part by Friday.**  
✅ **I should be able to finish the critical part by Friday.**

`should` 后不能直接接 `can`。

---

### 4

❌ **I’m still waiting the backend API.**  
✅ **I’m still waiting for the backend API.**

`wait for + 人 / 事物`。

---

### 5

❌ **Can we change it on tomorrow?**  
✅ **Can we change it tomorrow?**

`tomorrow / today / yesterday` 前通常不加 `on`。

但下面这些都正确：

> **We’ll release it on Friday.** = 周五当天发布  
> **We need to finish it by Friday.** = 最迟周五完成  
> **We need to test it before Friday.** = 周五之前完成测试

# 38–40 min | Final Speaking Challenge

## 第 1 分钟：Workplace Challenge

只看关键词，自己说 45–60 秒：

**urgent issue → top priority → pause current work → dependency → by 3 p.m. → should be able to → Friday**

参考版本：

> A production issue just came in. If this is now the top priority, I’ll pause the dashboard work and switch to it immediately. I’m still waiting for the backend API on the dashboard task, so that dependency hasn’t changed anyway. If we resolve the production issue by 3 p.m., I should be able to return to the dashboard work this afternoon and still finish the critical part by Friday. If it takes longer, I’ll need to move the remaining dashboard work to next week.

## 第 2 分钟：Everyday Challenge

关键词：

**appointment changed → afternoon → meeting at 4 → before 4 → delayed → by 3**

参考版本：

> Hi, I understand the morning appointment needs to move to the afternoon. I have a meeting at 4, so could the technician come before 4 if possible? Around 3:30 would work well. If the technician is delayed, could you let me know by 3 so I can rearrange my schedule?
