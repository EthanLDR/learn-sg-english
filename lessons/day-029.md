# Day 29 | Giving concise status updates, surfacing risks, and asking for decisions

### Theme: 用最短的话把“做完了什么、正在做什么、卡在哪里、需要谁决定什么”讲清楚

今天重点练一个全栈工程师非常高频的能力：**stand-up、项目群、周会里做简洁状态更新，不把所有细节都倒出来，而是让别人快速知道进展、风险和你需要的支持。**

你会反复练这几个动作：

- 先说完成项：**I’ve finished the UI changes.**
- 再说当前动作：**I’m working on the integration now.**
- 明确依赖：**I’m still waiting for the backend API.**
- 提前暴露风险：**The main risk is that we may not have enough time for regression testing.**
- 明确需要的决定：**Could we confirm which option we’re going with by noon?**
- 给条件化时间：**If I get the API by noon, I should be able to finish by Friday.**

同时继续复习：**I’m still waiting... / should be able to / by / on / before / future if**。

---

## 0–5 min | Warm-up：把“Done → Now → Risk → Ask”说顺

下面 5 句，每句大声说 3 遍。

> **I’ve finished the UI changes.**  
> UI 修改已经完成。

> **I’m working on the integration now.**  
> 我现在正在做集成。

> **I’m still waiting for the backend API.**  
> 我还在等后端 API。

> **The main risk is that testing may get squeezed.**  
> 主要风险是测试时间可能会被压缩。

> **If I get the API by noon, I should be able to finish by Friday.**  
> 如果我中午前拿到 API，我应该能在周五前完成。

快速复习：

- **by Friday** = 最迟周五完成
- **on Friday** = 周五当天发生
- **before Friday** = 周五之前，不包括周五

Future `if`：

> **If the API arrives today, we can test tomorrow.**

不是：

> ❌ If the API will arrive today...

# 5–17 min | Office Communication & Meetings

## 5–9 min | 场景 1：30 秒 stand-up，不讲流水账

**Manager:**  
Ethan, quick update?

**You:**  
Sure. I’ve finished the UI changes and I’m working on the integration now. I’m still waiting for the backend API, so I’m using mock data for the moment. The main risk is testing time. If I get the API by noon, I should be able to finish by Friday.

**Manager:**  
Anything you need from us?

**You:**  
Yes. Could we confirm the final response format with the backend team this morning?

这一段可以直接拆成四块：

> **Done:** I’ve finished ___.

> **Now:** I’m working on ___.

> **Risk:** The main risk is ___.

> **Ask:** Could we confirm ___ by ___?

这比从昨天早上开始把所有过程重新讲一遍更有效。

### Reusable Pattern

> **I’ve finished ___. I’m working on ___ now. The main risk is ___. If ___, I should be able to ___ by ___.**

例如：

> I’ve finished the form validation. I’m working on analytics now. The main risk is that the event names aren’t final. If I get confirmation by 2 p.m., I should be able to finish today.

---

## 9–13 min | 场景 2：状态“绿色”，但你仍然要提前说风险

**PM:**  
Are we still on track for Friday?

**You:**  
Yes, overall we’re still on track.

**PM:**  
Any concerns?

**You:**  
One. The implementation is on track, but the testing window is getting tight.

**PM:**  
What could cause us to slip?

**You:**  
If the API changes after Wednesday, we may not have enough time to retest before Friday.

**PM:**  
What do you recommend?

**You:**  
I’d suggest freezing the response format by Wednesday afternoon.

这里重点练：

> **Overall, we’re still on track.**  
> 整体还按计划。

> **The implementation is on track, but ___.**  
> 开发本身按计划，但……

> **The main risk is ___.**  
> 最大风险是……

> **What could cause us to slip is ___.**  
> 可能导致延期的是……

“有风险”不等于“项目已经延期”。提前说风险，是为了给团队处理时间。

---

## 13–15 min | 场景 3：事情卡在一个“没人做决定”的点

**You:**  
There’s one decision we still need before I continue.

**PM:**  
What is it?

**You:**  
We need to choose whether failed uploads should retry automatically or show a retry button.

**PM:**  
Which option do you recommend?

**You:**  
I’d prefer the retry button for the first version. It’s simpler and easier to control.

**PM:**  
Okay.

**You:**  
Great. Could we confirm that decision by noon? If we do, I should be able to finish the flow today.

很好用：

> **There’s one decision we still need.**

> **I need confirmation on ___.**

> **Could we confirm that by noon?**

> **Once that’s confirmed, I can move forward.**

状态更新里，别只说：

> I’m blocked.

最好补一句：

> **I’m blocked on one decision: ___.**

---

## 15–17 min | 2-minute Oral Substitution Drill

不要默读，连续开口替换。

### Pattern 1

> **I’ve finished the UI changes.**

替换：

- the loading state
- the form validation
- the error handling
- the unit tests

### Pattern 2

> **The main risk is testing time.**

替换：

- the API dependency
- the final design
- the data migration
- the release approval

### Pattern 3

> **If I get confirmation by noon, I should be able to finish by Friday.**

替换：

- the API by 2 p.m. / test today
- approval before lunch / merge this afternoon
- the design today / finish tomorrow
- the fix by Thursday / release on Friday

# 17–23 min | Colleague Small Talk & Socializing

## 17–20 min | 场景 1：同事问“最近忙什么？”

**Colleague:**  
What are you working on these days?

**You:**  
Mostly a new checkout flow. The UI is done, and I’m working on the integration now.

**Colleague:**  
Going smoothly?

**You:**  
Pretty much. I’m still waiting for one backend change, but nothing too serious.

**Colleague:**  
Sounds manageable.

**You:**  
Yeah. If that comes through today, I should be in good shape.

几个自然表达：

> **Pretty much.**  
> 基本上是。

> **Nothing too serious.**  
> 没什么太严重的。

> **I should be in good shape.**  
> 到时候情况应该会比较稳。

工作闲聊里不需要把完整 stand-up 再说一遍，简化就行。

---

## 20–23 min | 场景 2：约咖啡，但你还不确定什么时候有空

**Colleague:**  
Coffee around 3?

**You:**  
Maybe. I’m still waiting for one review.

**Colleague:**  
How long do you think it’ll take?

**You:**  
Hard to say, but I should know by 2:30. If the review is done by then, I can join you at 3.

**Colleague:**  
Sure, just ping me.

这里很好用：

> **I should know by 2:30.**

> **If it’s done by then, I can join you.**

> **I’ll let you know before 3.**

注意：

- **by 2:30** = 最迟 2:30 知道结果
- **at 3** = 3 点这个时间
- **before 3** = 3 点之前

# 23–30 min | Restaurant / Shopping / Ride-hailing

## 23–25 min | Restaurant：问进度，但不用一直催

**You:**  
Hi, could I get a quick update on my order?

**Staff:**  
Sure. It should be ready in about ten minutes.

**You:**  
Okay, thanks. I need to leave by 1:30. Do you think it’ll be ready before then?

**Staff:**  
Yes, it should.

**You:**  
Great, thank you.

这里可以直接记：

> **Could I get a quick update on my order?**

> **Do you think it’ll be ready before then?**

比不断问：

> Is it ready yet?

更自然，也更有信息量。

---

## 25–27 min | Shopping：等补货，需要一个明确 update

**You:**  
Hi, I’m checking on the size I asked about yesterday. Is there any update?

**Staff:**  
The shipment is expected on Friday.

**You:**  
Okay. Will you know before Friday whether it has shipped?

**Staff:**  
Yes, we should know by Thursday afternoon.

**You:**  
Great. If it’s confirmed by then, I’ll come back on Friday.

继续复习：

> **by Thursday afternoon** = 最迟周四下午知道

> **on Friday** = 周五当天回来

> **before Friday** = 周五之前

---

## 27–30 min | Grab：你和司机都在移动，需要简洁同步

**Driver:**  
I’m two minutes away.

**You:**  
Thanks. I’m still waiting for the lift, but I should be downstairs in about two minutes too.

**Driver:**  
Okay. I’ll wait at Pickup Point A.

**You:**  
Perfect. If I don’t see you there, I’ll message you.

如果位置变化：

> **Quick update: I’m at Pickup Point B now.**

> **I’m walking over to you.**

> **I should be there in about a minute.**

日常状态更新的原则一样：**现在在哪里 + 下一步 + 大概多久**。

# 30–35 min | Practical Singapore Life Errands

## 30–33 min | 场景 1：跟进维修，但重点问“当前状态和下一步”

**You:**  
Hi, I’m following up on my maintenance request. Could I get a quick update on the status?

**Staff:**  
The technician has inspected the unit, and we’re waiting for a replacement part.

**You:**  
Okay. Do you know when the part is expected?

**Staff:**  
It should arrive by Thursday.

**You:**  
Got it. If it arrives by Thursday, should the repair be completed before Friday?

**Staff:**  
Yes, we should be able to do that.

这里的关键问法：

> **Could I get a quick update on the status?**

> **What’s the next step?**

> **When is that expected?**

> **If that happens by Thursday, should everything be completed before Friday?**

---

## 33–35 min | 场景 2：申请还在处理中，想知道自己是否需要做什么

**You:**  
Hi, I’m checking the status of my application. It still shows “under review”.

**Staff:**  
Yes, the team is still processing it.

**You:**  
Okay. Is there anything you’re still waiting for from me?

**Staff:**  
No, we have all the documents.

**You:**  
Great. So there’s nothing I need to do for now, right?

**Staff:**  
That’s right.

**You:**  
And if there’s no update by Friday, should I follow up again?

非常实用：

> **Is there anything you’re still waiting for from me?**

> **Is there anything I need to do for now?**

> **If there’s no update by Friday, should I follow up again?**

这比只问：

> Why is it still pending?

更容易得到可执行信息。

# 35–38 min | Common Grammar Fixes

今天只纠正确实有问题的表达。

### 1

❌ **I have finished the UI yesterday.**  
✅ **I finished the UI yesterday.**

有明确过去时间 `yesterday` 时，通常用一般过去时。

但下面是正确的：

> **I’ve finished the UI.**

这里没有给具体过去时间，重点是“现在已经完成”。

---

### 2

❌ **I’m still waiting the backend API.**  
✅ **I’m still waiting for the backend API.**

`wait for + 人 / 事物`。

---

### 3

❌ **If the API will arrive today, we can test tomorrow.**  
✅ **If the API arrives today, we can test tomorrow.**

Future `if` 条件从句通常用一般现在时。

---

### 4

❌ **The main risk is we don’t have enough testing time.**  
✅ **The main risk is that we don’t have enough testing time.**

口语里省略 `that` 有时能听到，但完整、清晰的表达是 `The main risk is that...`。

---

### 5

❌ **I should can finish it by Friday.**  
✅ **I should be able to finish it by Friday.**

`should` 后不能直接接 `can`。

注意下面三句都正确，只是意思不同：

> **I should be able to finish by Friday.** = 最迟周五完成

> **We’re planning to release on Friday.** = 周五当天发布

> **We need to finish testing before Friday.** = 周五之前完成测试

# 38–40 min | Final Speaking Challenge

## 第 1 分钟：Workplace Challenge

只看关键词，自己说 45–60 秒：

**done → now → waiting → risk → decision → by noon → should be able to → Friday**

参考版本：

> I’ve finished the UI changes, and I’m working on the integration now. I’m still waiting for the backend API, so I’m using mock data for the moment. The main risk is that the testing window may get too tight. There’s also one decision we still need on the retry behaviour. If we can confirm that by noon and I get the API this afternoon, I should be able to finish by Friday.

## 第 2 分钟：Everyday Challenge

关键词：

**application → under review → waiting from me? → nothing to do → by Friday → follow up**

参考版本：

> Hi, I’m checking the status of my application. It still shows “under review”. Is there anything you’re still waiting for from me? If you already have all the documents, I just want to confirm there’s nothing else I need to do for now. If there’s no update by Friday, should I follow up again?

# Day 29 Compact Review

| 场景 | 直接说 |
|---|---|
| 已完成 | **I’ve finished the UI changes.** |
| 正在做 | **I’m working on the integration now.** |
| 还在等待 | **I’m still waiting for the backend API.** |
| 总体正常 | **Overall, we’re still on track.** |
| 提前说风险 | **The main risk is that...** |
| 说明可能延期的原因 | **What could cause us to slip is...** |
| 明确还缺一个决定 | **There’s one decision we still need.** |
| 请求确认 | **Could we confirm that by noon?** |
| 条件化时间 | **If I get the API by noon, I should be able to finish by Friday.** |
| 最迟周五 | **by Friday** |
| 周五当天 | **on Friday** |
| 周五之前 | **before Friday** |
| 日常问状态 | **Could I get a quick update on the status?** |
| 确认自己是否要行动 | **Is there anything you’re still waiting for from me?** |

今天最值得练到脱口而出的 6 句：

> **I’ve finished the UI changes.**

> **I’m working on the integration now.**

> **I’m still waiting for the backend API.**

> **The main risk is that testing may get squeezed.**

> **Could we confirm that by noon?**

> **If I get the API by noon, I should be able to finish by Friday.**
