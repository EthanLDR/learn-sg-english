# Day 38 | Checking costs and unexpected charges before agreeing

### Theme: 不只是问“How much?”——确认费用构成、变化原因，再决定是否接受

今天练习在工作和新加坡生活中**发现报价、账单或费用有差异时，礼貌地问清楚**。工程师需要解释 AI API 的使用成本，生活里则会遇到餐厅账单、购物价格、打车费用和手机套餐。

核心顺序：**quoted amount → actual amount → breakdown → reason → next step**。

> **Could you walk me through the breakdown?** 能带我看一下费用明细吗？
>
> **Is that the final amount, or are there any additional charges?** 这是最终金额，还是还有额外收费？
>
> **I noticed a difference between the quote and the invoice.** 我注意到报价和账单有差异。
>
> **Do we know what caused the increase?** 我们知道费用上涨的原因吗？
>
> **I'm still waiting for the usage report.** 我还在等使用量报告。
>
> **If we receive the figures by noon, I should be able to confirm the estimate before Friday.** 如果中午前收到数据，我应该能在周五之前确认估算。

继续复习 **I'm still waiting for / should be able to / by、on、before / 未来 if 条件句**。本课所有金额与规则均为虚构练习，不代表任何商家或平台的实际收费。

**总计严格 40 分钟：0–5 + 5–17 + 17–23 + 23–30 + 30–35 + 35–37 + 37–38 + 38–40。** 跟读、口头替换和核对都安排在对应时段内。

---

## 0–5 min | Warm-up：先问清总价与明细

### 0–2 min | Read aloud

每句读两遍，注意语气是确认信息，而不是责问对方。

> **Does that price include everything?** 这个价格包含所有费用吗？
>
> **Could you break it down for me?** 能帮我拆分说明一下吗？
>
> **What does this extra charge cover?** 这笔额外费用包含什么？
>
> **Is the amount an estimate or a final quote?** 这是预估金额还是最终报价？
>
> **I'd like to understand the difference before I confirm.** 我想先弄清差异，再确认。

**break down** 在这里指拆解明细；**breakdown** 是名词，“费用明细”。

### 2–4 min | Ask three useful questions

情况：原先预估 **$80**，现在显示 **$95**。这是虚构金额。

先连续问：

> **I was expecting $80, but the total shows $95.**
>
> **Could you explain the difference?**
>
> **Are there any fees included in the total that weren't in the original quote?**

第 2 轮换成：预估 $120，实际 $138。不要猜“肯定是税”，先问明细。

### 4–5 min | Quick recall

遮住答案，快速说英文：

1. 这是不是最终金额？
2. 我还在等明细。
3. 如果今天收到数据，我应该能在周五之前确认。

参考：

> **Is that the final amount?**
>
> **I'm still waiting for the breakdown.**
>
> **If I get the figures today, I should be able to confirm before Friday.**

# 5–17 min | Office Communication & Meetings

## 5–9 min | Scene 1: AI API costs are higher than expected

**PM:** Our AI feature seems more expensive to run than we expected. Do you know why?

**You:** Not yet. I noticed the difference, but I'm still waiting for the usage report.

**PM:** What will you look at first?

**You:** I'd like to break the cost down by model, request volume, and average input and output size.

**PM:** Could the new summary flow be responsible?

**You:** It's possible, but I don't want to assume that without checking the data.

**PM:** When can you give us an estimate?

**You:** If the usage report arrives by noon, I should be able to share a revised estimate this afternoon.

**5–7 min：**分角色朗读两轮。第二轮只读 You 的句子。

**7–8 min：**遮稿回答：**What do we know? What are we waiting for? What will we measure?**

**8–9 min：**用 40 秒汇报：**observed increase → missing data → cost breakdown → conditional update**。

可复用：

> **The cost is higher than expected, but we haven't confirmed why.**
>
> **Let's break it down by ___.**
>
> **I'd rather check the numbers before drawing a conclusion.**

注意：**more requests**、**longer responses** 和 **different models** 都可能影响 AI 推理费用，具体计费取决于供应商规则；练习时不要把某一原因说成已确定的事实。

## 9–13 min | Scene 2: Estimate the impact before approving a change

**Engineer:** Product wants to double the maximum response length.

**You:** That might improve some answers, but it could also affect cost and latency.

**Engineer:** Should we go ahead?

**You:** Could we test it with a small set of representative requests first?

**Engineer:** Sure. What should we measure?

**You:** Response quality, latency, and estimated cost per request. Then we can compare the results.

**Engineer:** When will the comparison be ready?

**You:** I'm still waiting for the test dataset. If I get it on Thursday, I should be able to share the comparison on Friday.

**9–11 min：**朗读两轮，并指出两个不同概念：**benefit（收益）** 和 **trade-off（代价）**。

**11–12 min：**把 **maximum response length** 替换为 **larger model / more frequent refresh / longer context window**，用自己的话提一个合理的验证问题。

**12–13 min：**不看稿，用 35–45 秒说 **proposal → possible trade-off → test → decision**。

可复用：

> **Before we commit, could we measure ___?**
>
> **Let's compare A and B under the same conditions.**
>
> **We can decide once we have the numbers.**

## 13–15 min | Scene 3: Confirm a budget decision in a meeting

**Manager:** Let's keep the current model for the first release and review costs next week.

**You:** Just to confirm, we're not changing the model before Friday's launch, right?

**Manager:** Correct. We still want the usage report.

**You:** Understood. I'll share the report once it's ready, including the assumptions behind the estimate.

**Manager:** Great. Please flag any unexpected increase.

**You:** Will do. If the cost goes above the agreed threshold, I'll raise it in the project channel before we make further changes.

**13–14 min：**朗读；分辨 **decision / evidence / escalation trigger**。

**14–15 min：**遮稿总结 30–45 秒，必须说清：现在不改、下周复核、超过阈值要通知。

> **Just to confirm, we're keeping ___ for now.**
>
> **I'll flag it if ___.**

**flag** 在这里是“主动提醒、标出风险”，不是制造恐慌。

## 15–17 min | Two-minute oral substitution

**15:00–15:40 | Ask for a breakdown：4 × 10 秒**

模板：**Could you break the cost down by model?**

依次换成 **request type / team / day / feature**。

**15:40–16:20 | Separate estimate and final amount：4 × 10 秒**

模板：**Is that an estimate or the final amount?**

依次替换提问对象：**monthly API bill / delivery fee / subscription renewal / repair quote**，每轮说完整句。

**16:20–17:00 | Conditional commitment：4 × 10 秒**

模板：**If I get the usage report by noon, I should be able to update the estimate today.**

替换：

1. invoice / by 2 p.m. / check the difference this afternoon
2. test results / on Thursday / share a comparison on Friday
3. final quote / before lunch / confirm the order today
4. approval / by Friday / place the order on Friday

# 17–23 min | Colleague Small Talk & Socializing

## 17–20 min | Scene 1: Splitting a team lunch bill

**Colleague:** Shall we split the lunch bill equally?

**You:** That works for me, but one person only ordered a drink. Would it be fairer to split it by what we ordered?

**Colleague:** Good point. The app can calculate each person's share.

**You:** Great. Could you send the breakdown in the group chat?

**Colleague:** Sure.

**You:** Thanks. Once I know my share, I'll transfer it.

**17–18 min：**朗读。  
**18–19 min：**把 **one person only ordered a drink** 换成 **two people shared a dessert**，礼貌提出公平一点的分摊方式。  
**19–20 min：**用 30–45 秒完成 **agree politely → raise concern → suggest alternative → confirm next step**。

> **Shall we split it equally?** = 要不要均摊？
>
> **Would it be fairer to ___?** = ……会不会更公平？
>
> **What's my share?** = 我该付多少？

## 20–23 min | Scene 2: Agreeing on a group gift budget

**Colleague:** We're getting a small farewell gift. Are you keen to chip in?

**You:** Sure. Do we have a budget in mind?

**Colleague:** We're thinking of around $20 per person.

**You:** Sounds reasonable. Is that the final amount, or does it depend on how many people join?

**Colleague:** It might change slightly.

**You:** No problem. Let me know the final share before you order.

**20–21 min：**朗读。  
**21–22 min：**改成 **birthday cake for a teammate**，问清参与人数和最终金额。  
**22–23 min：**遮稿 30–45 秒，说 **interest → budget → possible change → confirmation**。

**chip in** = 大家各出一点钱；很适合同事闲聊，不必用过于正式的 financial contribution。

# 23–30 min | Restaurant / Shopping / Ride-hailing

## 23–25 min | Restaurant: Checking the final bill

**You:** Excuse me, could you help me check this bill?

**Staff:** Sure. Which part would you like to check?

**You:** The menu showed one price, but the total is higher. Does it include any additional charges?

**Staff:** Let me show you the breakdown.

**You:** Thanks. I'd just like to understand the final amount before paying.

**23–24 min：**朗读，不要预设额外收费是什么。  
**24–25 min：**把 **menu price** 换成 **set-meal price**，再次问清最终价格。

> **Does the listed price include all charges?**
>
> **Could you show me the breakdown?**

商家是否收服务费、税费和其他费用，以现场标价、票据及适用规则为准。

## 25–27 min | Shopping: Price at checkout differs from the shelf label

**You:** Hi, the shelf label showed a lower price, but the checkout screen shows a different amount.

**Staff:** Could you show me which item you picked up?

**You:** Sure, it's this model. Could you check whether the promotion applies to it?

**Staff:** Let me verify the promotion details.

**You:** Thanks. I'll decide once we confirm the correct price.

**25–26 min：**朗读。  
**26–27 min：**把 **promotion** 换成 **bundle discount**，询问适用条件。

> **Does this promotion apply to this model?**
>
> **I'd like to check the price before I pay.**

## 27–30 min | Ride-hailing: A fare is different from what you expected

**You:** Hi, I noticed the fare shown at the end is different from the amount I expected.

**Driver:** I'm not sure why. You may need to check the trip details in the app.

**You:** Understood. I'll review the fare breakdown there.

**Driver:** Okay.

**You:** If I still can't understand the difference, I'll contact support through the app. Thanks.

**27–28 min：**朗读。  
**28–29 min：**替换成 **an extra stop / a changed destination**，询问是否会影响费用。  
**29–30 min：**遮稿说 40 秒：**expected amount → actual amount → check details → follow up**。

实际计费、动态价格及争议渠道以平台订单页面为准；不要在车内争执或要求司机现场修改无法控制的费用。

# 30–35 min | Practical Singapore Life Errands

## 30–33 min | Scene 1: Clarifying a mobile plan charge

**You:** Hi, I'm checking my mobile bill. There's an additional charge I don't recognise.

**Staff:** Could you tell me which line item you're referring to?

**You:** It's listed as an add-on. Could you explain what it covers and when it was activated?

**Staff:** I'll check the account details.

**You:** Thanks. I'd also like to know whether it will appear again next month.

**Staff:** Let me verify that for you.

**You:** If it's recurring, could you show me how to review or change the add-on?

**30–31 min：**朗读。  
**31–32 min：**不看稿，按 **line item → reason → one-off or recurring → next step** 说四句。  
**32–33 min：**把 **mobile bill** 换成 **broadband bill**，重新说明问题。

> **Is this a one-off charge or a recurring charge?** = 一次性收费还是定期收费？
>
> **When was it activated?** = 什么时候开通的？

## 33–35 min | Scene 2: Confirming parcel delivery fees

**You:** Hi, I'd like to send this parcel overseas. Could I get a quote before booking?

**Staff:** Sure. We'll need the destination and parcel details.

**You:** Does the quote include collection, or would that be charged separately?

**Staff:** It depends on the service. Let's check the options.

**You:** Thanks. Could you explain the differences and confirm the final amount before I book?

**33–34 min：**朗读。  
**34–35 min：**遮稿口头完成 **destination → quote → included services → final amount**。

真实报价可能受重量、体积、目的地、附加服务和其他条件影响；这里不预设任何物流商的收费规则。

# 35–37 min | Accurate Grammar Corrections

**35–36 min：**先开口纠正前三句，再核对。

1. ❌ **How much does it costs?**  
   ✅ **How much does it cost?**  
   **does** 后接动词原形。

2. ❌ **Could you explain me the extra charge?**  
   ✅ **Could you explain the extra charge to me?**  
   **explain something to someone**。

3. ❌ **I'm still waiting the invoice.**  
   ✅ **I'm still waiting for the invoice.**  
   **wait for**。

**36–37 min：**纠正后两句，并说清三种时间。

4. ❌ **If the fee will change, I'll check with the team.**  
   ✅ **If the fee changes, I'll check with the team.**  
   普通未来条件句里，**if** 从句通常用现在时。

5. ❌ **I should can confirm the total by Friday.**  
   ✅ **I should be able to confirm the total by Friday.**

三句都正确，区别在于时间：

> **I'll send the estimate by Friday.** = 最迟周五发。  
> **I'll send the estimate on Friday.** = 周五当天发。  
> **I'll send the estimate before Friday.** = 周五之前发。

**What's the total?** 和 **How much is it altogether?** 都是自然且正确的问法；后者不是语法错误。

# 38–40 min | Final Speaking Challenges

## 38–39 min | Workplace: Explain an unexpected API cost

**38:00–38:50：**只看关键词说 45–50 秒：**AI API → higher cost → not sure why → usage report → model / requests / response length → test → by noon → update**。  
**38:50–39:00：**检查有没有把未确认的原因说成确定事实。

参考：

> **Our AI API cost is higher than expected, but we haven't confirmed the cause yet. I'm still waiting for the usage report. Once we have it, I'd like to break the cost down by model, request volume, and response length. We'll compare the results with our original assumptions before changing anything. If the report arrives by noon, I should be able to share a revised estimate this afternoon. I'll flag any unexpected increase to the team.**

## 39–40 min | Everyday: Question a bill politely

**39:00–39:50：**只看关键词说 45–50 秒：**mobile bill → unfamiliar add-on → breakdown → when activated → recurring? → next month → confirm before changing**。  
**39:50–40:00：**检查是否问清收费是什么、会不会再次出现、下一步是什么。

参考：

> **Hi, I'm reviewing my mobile bill and noticed an additional charge that I don't recognise. Could you show me the breakdown and explain what this add-on covers? I'd also like to know when it was activated and whether it's a one-off or recurring charge. If it will appear again next month, could you explain my options before I make any changes? Thanks for helping me check.**

**40 分钟结束。今天要能自然说出：Could you break down the total and explain the extra charge?**
