# Day 45 | What's included? Confirm scope, extra costs and conditions

### 今日主题：答应之前，先问清“包含什么、哪些另收费、有什么条件”

新技能：**ask what's included → check extras → confirm conditions → decide**（确认包含内容 → 询问额外费用 → 核对条件 → 再决定）。在工程讨论里，时间估算可能不含测试；在新加坡生活里，套餐价格也可能不代表所有费用。今天练习**不靠猜测，礼貌问清楚**。

> **What's included in the estimate?** 这个工期预估包括哪些工作？
>
> **Is testing included, or is that separate?** 包含测试吗，还是要单独算？
>
> **Is there an extra charge for that?** 那个需要额外收费吗？
>
> **Are there any conditions I should know about?** 有什么我应该知道的条件吗？
>
> **Let me confirm the total before I decide.** 我决定前确认一下总额。

**工程师词汇：** **one-time cost** 一次性成本；**ongoing cost** 持续成本；**scope** 工作范围；**breakdown** 明细。所有服务条款、报价与工作人员回答均为**虚构练习**，实际以官方页面、合同或商家确认的信息为准。

复习贯穿：**I'm still waiting for / should be able to / by、on、before / if + 一般现在时**。

**严格 40 分钟：0–5（5）+ 5–17（12）+ 17–23（6）+ 23–30（7）+ 30–35（5）+ 35–37（2）+ 37–38（1）+ 38–40（2）= 40。** 朗读、替换、自检与最终挑战全部计入。

---

## 0–5 min | Warm-up：先问明细，再做决定

**0–2 min｜四句各读三遍：**

> **Does that include testing?** 那包含测试吗？
>
> **Is the delivery fee included?** 运费算在里面吗？
>
> **Could you break down the cost?** 可以拆开说明费用吗？
>
> **I don't want to assume it's included.** 我不想想当然地以为它包含在内。

**2–4 min｜两轮一分钟对话：**

**A:** The setup will take two days.

**You:** Does that include testing and review?

**A:** No, just the implementation.

**You:** Got it. Could we estimate testing separately?

第一轮朗读并交换角色；第二轮把 **setup → UI change**、**testing and review → QA and documentation**，遮住 You 的台词重说。

**4–5 min｜中文口译后核对：**

“我还在等费用明细。” → **I'm still waiting for the cost breakdown.**

“如果今天拿到，我应该能最迟周二回复。” → **If I get it today, I should be able to reply by Tuesday.**

“那是包含在内，还是另外收费？” → **Is that included, or is there an extra charge?**

## 5–17 min | Office Communication & Meetings

### 5–9 min | Scene 1：确认前端工期是否包含测试

**PM:** Can we finish the new settings page in two days?

**You:** Possibly. Just to clarify, does that include QA and code review?

**PM:** I was thinking of implementation only.

**You:** Got it. Then let's estimate implementation and testing separately.

**PM:** What's blocking the estimate?

**You:** I'm still waiting for the final API contract. If it arrives by noon, I should be able to share a clearer estimate by 4 p.m.

**PM:** Great. Please call out anything that's out of scope.

**You:** Will do. I'll include assumptions and the remaining work.

**5–7 min：**分角色朗读两轮，第二轮遮住 You。**7–8 min：**不看稿回答：What does “two days” include? What's still missing? What will you share? **8–9 min：**口述 40–50 秒：

> **Does the estimate include ___? If not, let's estimate ___ separately. I'm still waiting for ___. If ___, I should be able to ___ by ___.**

**implementation** = 开发实现；**API contract** = API 接口约定；**out of scope** = 不在本次范围内。

### 9–13 min | Scene 2：AI 功能的试用成本

**Lead:** The AI summary demo looks good. Should we use it for more requests?

**You:** Before we decide, can we check how usage is charged?

**Lead:** What exactly do you want to know?

**You:** Is there a fixed monthly fee, a charge per request, or both?

**Lead:** I'm not sure. We need the pricing details.

**You:** Okay. Let's separate the one-time integration effort from the ongoing usage cost.

**Lead:** Good point. Can you put together a comparison?

**You:** Yes. If I get the pricing details on Monday, I should be able to send a simple comparison by Tuesday.

**9–11 min：**朗读两轮；第二轮将 **AI summary → image generation**。**11–12 min：**按 **pricing model → missing details → cost categories → next step** 复述。**12–13 min：**脱稿说：

> **Before we scale this up, can we confirm ___? I want to compare ___ with ___. If ___, I can share ___ by ___.**

**per request** = 按请求计费；**scale up** = 扩大使用规模。这里不假定任何真实模型或服务的定价。

### 13–15 min | Scene 3：会议收尾，确认任务边界

**Designer:** Can you update the error screen and the empty state?

**You:** Sure. Is the copy already final, or do we need another review?

**Designer:** The error copy is ready, but the empty-state copy isn't.

**You:** Understood. I'll update the error screen first. I'll leave the empty state pending until the copy is approved.

**Designer:** Sounds good.

**You:** Just to confirm, my task covers the UI changes, while copy approval stays with your team. Right?

**13–14 min：**朗读；找出 **included / pending / owner**。**14–15 min：**遮稿按 **what's ready → what's missing → owner → next step** 复述 40 秒，剩余 20 秒重说确认句。

### 15–17 min | Timed oral substitution：12 轮，每轮 10 秒

**15:00–15:40｜A. 询问是否包含（4 轮）**

模板：**Does that include ___?**

1. testing
2. code review
3. API integration
4. documentation

**15:40–16:20｜B. 询问是否另外计算（4 轮）**

模板：**Is ___ included, or is it separate?**

1. QA
2. the setup fee
3. delivery
4. ongoing support

**16:20–17:00｜C. 条件与期限（4 轮）**

模板：**If ___, I should be able to ___ ___.**

1. I get the quote by noon / reply / by 4
2. the API contract arrives on Monday / update the estimate / on Tuesday
3. QA finishes by Thursday / share the summary / before Friday
4. the pricing details arrive today / compare the options / by Friday

每轮 **3 秒看提示 + 7 秒说完整句**。**by Tuesday** 最迟周二；**on Tuesday** 周二当天；**before Tuesday** 周二之前。

## 17–23 min | Colleague Small Talk & Socializing

### 17–20 min | Scene 4：同事聚餐，怎么分账？

**Colleague:** We're ordering a few dishes to share. Want to join?

**You:** Sure! How are we splitting the bill?

**Colleague:** We usually split the shared dishes evenly.

**You:** Got it. Do we pay for our own drinks separately?

**Colleague:** Yes, that's the plan.

**You:** Sounds good. Thanks for clarifying!

**17–18 min：**读两轮。**18–19 min：**改成 **team coffee order**，问 **Are we paying separately or together?**。**19–20 min：**遮稿按 **accept → ask how to split → clarify exceptions → friendly response** 说 40 秒。

**split the bill** = 分账；**split evenly** = 平均分摊。直接问规则很自然，不需要为提问道歉。

### 20–23 min | Scene 5：活动邀请是否包含餐食

**Colleague:** We're going to a weekend event. Are you keen?

**You:** Sounds interesting! What does the ticket include?

**Colleague:** Entry is included, but food is separate.

**You:** Thanks. Do we need to book in advance?

**Colleague:** Let's check the booking page.

**You:** Great. If I can confirm my plans by Friday, I'll let you know before Saturday.

**20–21 min：**朗读。**21–22 min：**替换成 **museum visit / guided tour**，问是否包含导览。**22–23 min：**脱稿说 **interest → what's included → booking requirement → confirmation time**，最后 15 秒复读。

## 23–30 min | Restaurant / Shopping / Ride-hailing

### 23–25 min | Restaurant：套餐包含什么？

**You:** Hi, does this set meal include a drink?

**Staff:** This option includes a main dish only.

**You:** I see. How much extra would a drink be?

**Staff:** Please check the drinks menu.

**You:** Sure. I'll check the total before ordering.

**23–24 min：**朗读。**24–25 min：**把 **drink → side dish**，重新问 **Does it include ___? / How much extra is ___?**。不要假定特定餐厅的套餐内容。

### 25–27 min | Shopping：价格是否包含保修

**You:** Is the warranty included in this price?

**Staff:** The product comes with the standard warranty stated on the label.

**You:** Could you show me what it covers and how long it lasts?

**Staff:** Sure, let's check the terms.

**You:** Thanks. I'll review them before buying.

**25–26 min：**朗读。**26–27 min：**换成 **monitor / delivery fee**，问 **Is delivery included? Are there any extra charges?**。**warranty** = 保修；**covers** = 保修覆盖哪些情况。

### 27–30 min | Ride-hailing：增加停靠点会不会改变费用

**You:** Hi, if I add a stop, could that change the fare?

**Driver:** Please check what the app allows and the fare it shows.

**You:** Okay. So I'll check the updated fare before confirming the change.

**Driver:** Yes, please follow the app's instructions.

**You:** Understood. If I can't make the change in the app, I'll keep the original trip.

**27–28 min：**朗读两轮。**28–29 min：**替换成 **change the destination**，问费用与操作方式。**29–30 min：**脱稿按 **request → possible extra cost → check app → decide** 说 40 秒，最后 20 秒自检。实际费用及路线调整以平台显示为准。

## 35–37 min | Accurate Grammar Corrections

**35–36 min｜先自己纠正前三题：**

1. ❌ **Does it includes testing?** → ✅ **Does it include testing?**（does 后用动词原形）
2. ❌ **How much it costs?** → ✅ **How much does it cost?**（直接疑问句用 does）
3. ❌ **Is included the delivery fee?** → ✅ **Is the delivery fee included?**（be + 主语 + included）

**36–37 min｜两题复习：**

4. ❌ **I'm still waiting the cost breakdown.** → ✅ **I'm still waiting for the cost breakdown.**
5. ❌ **If I will get the quote, I should able to reply by Friday.** → ✅ **If I get the quote, I should be able to reply by Friday.**

**正确替代，不是错误：** **Does the price include delivery? / Is delivery included in the price?** 都正确；**How much extra is it? / Is there an additional charge?** 都自然；**finish by Friday / finish on Friday** 都正确，但前者表示最迟周五，后者表示周五当天。

提示：**settings page → two-day estimate → QA included? → implementation only → API contract pending → if noon → clearer estimate by 4 → next step**。

参考（先说，再看）：

> **Before we agree on the two-day estimate for the settings page, could I clarify what's included? Does that cover QA and code review, or only implementation? If testing is separate, let's estimate it separately. I'm still waiting for the final API contract. If it arrives by noon, I should be able to share a clearer estimate by 4 p.m. Then we can agree on the scope and timeline.**

### 39–40 min | Everyday：50 秒自由说 + 10 秒自检

提示：**mobile plan → monthly fee → roaming included? → activation fee → full breakdown → decide later**。

参考（先说，再看）：

> **Hi, I'm comparing mobile plans. Could you tell me what's included in the monthly fee? Is roaming included, or is that charged separately? Are there any one-time activation fees? I'd like to check the full breakdown and the main conditions before signing up. Thanks for explaining. I'll review the details before I decide.**

自检：**月费、额外费用、条款、决定时点** 是否明确？
