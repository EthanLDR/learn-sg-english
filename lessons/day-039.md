# Day 39 | Time zones, async updates and clear handoffs

### 主题：跨地区开会和新加坡生活，讲清“几点、谁负责、何时更新”

今日新增 **async update（异步进度同步）**：无法同时在线时，发一条对方能直接采取行动的消息，而不是只说 “I'll get back to you.” 核心顺序 **time zone → availability → owner → next update**。

- **Does 3 p.m. Singapore time work for you?** 新加坡时间下午三点方便吗？
- **Could you include the time zone in the invite?** 邀请中能注明时区吗？
- **I can't join, but I can leave a written update.** 我参加不了，但可以提前发书面进度。
- **I'm still waiting for the API confirmation.** 我仍在等待 API 确认。
- **If it arrives by noon, I should be able to update the ticket today.** 如果中午前收到，今天应该能更新工单。

新加坡和中国大陆都使用 UTC+8；跨其他地区安排会议时应明确当地时区。下面均为英语模拟情境。

**严格 40 分钟：0–5（5）+ 5–17（12）+ 17–23（6）+ 23–30（7）+ 30–35（5）+ 35–37（2）+ 37–38（1）+ 38–40（2）= 40。** 朗读、替换和核对都算在对应时间内。

---

## 0–5 min | Warm-up：把模糊时间说清楚

**0–2 min：**每句朗读两遍：

> **Let's meet at 3 p.m. Singapore time.** 新加坡时间三点见。
>
> **I'll send the notes by 4 p.m.** 最迟四点发会议记录。
>
> **I'll check the design before the meeting.** 我会在开会前看设计。
>
> **Please tag me if anything is unclear.** 有不清楚的地方请在文档里 @ 我。

**2–4 min：**将 “Can we sync at 3?” 扩展成两句，分别重复两遍：

> **Could we sync at 3 p.m. Singapore time to review the mobile build?**
>
> **I can't make it at 3. Could we move it to 4, or would a written update work?**

**4–5 min：**遮住参考，口译“写清时区 / 还在等结果 / 如果中午前收到，五点前更新”：

> **Please include the time zone in the invite.**
>
> **I'm still waiting for the results.**
>
> **If they arrive by noon, I should be able to update you by 5.**

## 5–17 min | Office Communication & Meetings

### 5–9 min | Scene 1：确认跨地区项目会议

**PM:** Can we have a review at 3 tomorrow?

**You:** Sure. Just to confirm, is that 3 p.m. Singapore time?

**PM:** Yes. We need to review the latest mobile build.

**You:** That works. Could you add the time zone and agenda to the invite?

**PM:** Will you have the QA results?

**You:** I'm still waiting for them. If they arrive by noon, I should be able to share a summary before the meeting.

**PM:** Great. If they're delayed, please flag it.

**You:** Will do. I'll post the build link in the chat as well.

**5–7 min：**分角色读两轮，第二轮遮住 You 的句子。**7–8 min：**不看稿回答：What time zone? What's the goal? What's pending? **8–9 min：**说 40–50 秒：

> **We're meeting at ___ Singapore time to ___. I'm still waiting for ___. If ___, I should be able to ___ by ___.**

### 9–13 min | Scene 2：不能参加评审，提供异步方案

**Engineer:** Can you join the design review at 6 p.m. Singapore time?

**You:** I won't be online then. Would a written update work instead?

**Engineer:** Yes. We mainly need feedback on the loading state.

**You:** I'll leave comments in the document and attach a screenshot.

**Engineer:** Could you send them by 5?

**You:** Yes, I should be able to send them by 5. Please tag me if anything needs clarification.

**9–11 min：**读两轮，第二轮换成 **error state**。**11–12 min：**遮住台词，依次说 **can't join → document comments → screenshot → deadline**。**12–13 min：**把设计评审换成每日站会，说出：

> **I can't join the stand-up, but I can post a status update in the team chat before it starts.**

**Async** = asynchronous，不要求所有人同时在线；**Would a written update work instead?** 比直接拒绝更协作。

### 13–15 min | Scene 3：下线前交接

**Teammate:** Who's handling the API issue while you're away?

**You:** I've handed it over to another engineer. The latest status is in the ticket.

**Teammate:** What's still blocked?

**You:** We're still waiting for the backend response.

**Teammate:** When is the next update?

**You:** If the response arrives by 2 p.m., we should be able to update the ticket before the end of the day.

**13–14 min：**朗读，标出 **owner（负责人）/ blocker（阻塞）/ update（更新）**。**14–15 min：**遮稿说 30–45 秒：

> **I've handed ___ over to ___. We're still waiting for ___. If ___, we should be able to ___ by ___.**

### 15–17 min | Timed substitution：12 轮，每轮 10 秒

**15:00–15:40 | A：时间（4 轮）**

模板：**Does 3 p.m. Singapore time work for you?** 替换 **10 a.m. / 2 p.m. / 4:30 p.m. / 11 a.m. tomorrow**；每轮都读出时区。

**15:40–16:20 | B：异步替代（4 轮）**

模板：**I can't join the review, but I can leave comments.** 替换 **demo → recording / stand-up → chat update / planning → estimate / design review → screenshots**。

**16:20–17:00 | C：未来条件（4 轮）**

模板：**If I get the API response by noon, I should be able to update the ticket today.**

替换：
1. screenshots / by 2 / update the report today
2. test results / before lunch / send the summary by 5
3. approval / on Monday / start the rollout on Tuesday
4. final design / by Thursday / finish the UI before Friday

每轮按 **看关键词 → 完整造句 → 说出声** 完成。

## 17–23 min | Colleague Small Talk & Socializing

### 17–20 min | Lunch plan

**Colleague:** A few of us are going for lunch. Want to join?

**You:** Sounds good! What time are you heading out?

**Colleague:** Around 12:30.

**You:** My call ends at 12:15. Where should we meet?

**Colleague:** At the lobby.

**You:** Great. If my call runs late, I'll message you before 12:30.

**17–18 min：**朗读。**18–19 min：**替换 **lunch → coffee / 12:30 → 3:30 / call → meeting**。**19–20 min：**遮稿接受邀请、确认时间地点、说明可能迟到的通知方式。

> **What time are you heading out?** 你们什么时候出发？
>
> **If I'm running late, I'll let you know.** 如果快迟到了会告诉你。

### 20–23 min | Friday dinner

**Colleague:** We're grabbing dinner on Friday. Are you keen?

**You:** Maybe! What time are you meeting?

**Colleague:** Around 7.

**You:** I should be free by then. Can I confirm by Thursday?

**Colleague:** Sure.

**You:** Thanks. If I can't make it, I'll let you know before Friday.

**20–21 min：**朗读。**21–22 min：**改成 **weekend walk** 并说清何时确认。**22–23 min：**不看稿依次说 **interest → time → tentative yes → deadline**。

**Are you keen?** = 你有兴趣吗？**I'm free at 7**（七点有空）与 **I'm free by 7**（到七点已能空出来）都正确。

## 23–30 min | Restaurant / Shopping / Ride-hailing

### 23–25 min | Restaurant：确认预约时间

**You:** Hi, I'd like to confirm my dinner booking.

**Staff:** What time was it booked for?

**You:** 7 p.m. tonight. Is that when we should arrive?

**Staff:** Yes, that's the time on the booking.

**You:** If we're running late, how should we let you know?

**23–24 min：**朗读。**24–25 min：**将 **7 p.m. → 6:30 p.m.**，练“核对时间 + 如何通知迟到”。纯口语情境，不是实时预约。

### 25–27 min | Shopping：确认到店取货

**Staff:** Your order is ready for collection.

**You:** Great. Is there a collection time window?

**Staff:** You can come in the afternoon.

**You:** Would 4 p.m. work?

**Staff:** Yes.

**You:** Perfect. I'll aim to be there at 4.

**25–26 min：**朗读。**26–27 min：**将 order 换成 **a repaired laptop**，问 **Do I need to collect it before 5 p.m.?**

> **collection window** = 允许取货的时间段；**aim to** = 尽量做到，不是保证。

### 27–30 min | Ride-hailing：更新预计上车时间

**Driver:** I'm at the pickup point.

**You:** I'm still waiting for the lift. I should be there in about three minutes.

**Driver:** I'm near the main entrance.

**You:** The app shows Pickup Point B. Are you at B?

**Driver:** Yes.

**You:** Thanks. If I can't find you, I'll message you in the app.

**27–28 min：**朗读。**28–29 min：**替换 **lift → security gate / three → five / B → A**。**29–30 min：**遮稿连续说 40 秒：**current location → ETA → pickup point → next message**。

**ETA** = estimated time of arrival（预计抵达时间）。**in three minutes** 是三分钟后。

## 30–35 min | Practical Singapore Life Errands

### 30–33 min | Home visit：上门服务的时间窗口

**You:** Hi, I'm checking my service appointment at my flat.

**Staff:** The technician is scheduled for Friday afternoon.

**You:** Is that a fixed time or an arrival window?

**Staff:** It's a window. We'll send the details.

**You:** Could you confirm the window by Thursday? I need someone to be at home.

**Staff:** We'll check.

**You:** Thanks. If the timing changes, please let me know before the visit.

**30–31 min：**朗读。**31–32 min：**只看提示 **day → window → reason → deadline** 复述。**32–33 min：**换成 **parcel delivery**，重新说清确认时间的需求。

### 33–35 min | Service counter：最后受理时间

**You:** Hi, what time does your service counter close today?

**Staff:** At 5 p.m.

**You:** If I arrive at 4:30, can I still submit a form?

**Staff:** That depends on the service.

**You:** Is there a separate last-admission time?

**Staff:** Let me check.

**33–34 min：**朗读。**34–35 min：**独立说出 **closing time → reason for visit → last admission → thank you**。

**closing time**（关门）与 **last-admission time**（最后受理）可能不同。实际时间和规定请看机构公告。

## 35–37 min | Accurate Grammar Corrections

**35–36 min：**三题先改再核对：

1. ❌ **What time the meeting starts?** → ✅ **What time does the meeting start?** 直接疑问句需助动词；但 **Do you know what time the meeting starts?** 正确（间接疑问句）。
2. ❌ **I'm still waiting the API reply.** → ✅ **I'm still waiting for the API reply.** 用 **wait for**。
3. ❌ **If I will get the results, I'll call you.** → ✅ **If I get the results, I'll call you.** 普通未来 if 条件句用现在时。

**36–37 min：**两题纠正 + 时间区别：

4. ❌ **I should can finish it.** → ✅ **I should be able to finish it.**
5. ❌ **Can you tell me when will the technician arrive?** → ✅ **Can you tell me when the technician will arrive?** 间接问句用陈述语序。

**这些表达都正确：** **Does 3 p.m. work? / Would 3 p.m. work?**（后者更委婉）；**move the meeting to 4 / reschedule it for 4**。

**by Friday** = 最迟周五；**on Friday** = 周五当天；**before Friday** = 周五之前，不含周五。

### 38–39 min | Workplace：50 秒自由说 + 10 秒自检

参考：

关键词：**Friday afternoon → fixed time or window → someone at home → confirm by Thursday → notify changes**。

参考：

> **Hi, I'm checking my home service appointment for Friday afternoon. Is that a fixed time or an arrival window? I need someone to be at home, so could you confirm the window by Thursday? If the schedule changes, please message me before the visit. Thanks for your help.**
