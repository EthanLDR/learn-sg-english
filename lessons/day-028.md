# Day 28 | Giving realistic estimates, stating assumptions, and updating timelines

### Theme: 别把“估算”说成“保证”——给出范围、说明假设、在信息变化时及时更新时间

今天重点练一个全栈工程师每天都会遇到的场景：**别人问“多久能做完？”时，不是随口给一个死时间，而是说明当前信息、关键假设和可信度；等依赖或需求变化后，再主动更新估算。**

你会反复练这几个动作：

- 给粗略估算：**My rough estimate is one to two days.**
- 说明假设：**That assumes the API contract doesn’t change.**
- 表达不确定性：**I’m reasonably confident, but there’s still some uncertainty around testing.**
- 更新估算：**Now that we know more, I’d revise the estimate to three days.**
- 给条件化承诺：**If I get the API by noon, I should be able to finish by Friday.**

同时继续复习：**I’m still waiting... / should be able to / by / on / before / future if**。

---

## 0–5 min | Warm-up：把“估算 ≠ 保证”说顺

下面 5 句，每句大声说 3 遍。

> **My rough estimate is one to two days.**  
> 我的粗略估算是一到两天。

> **That assumes the scope stays the same.**  
> 这个估算的前提是范围不变。

> **I’m still waiting for the backend API, so there’s some uncertainty.**  
> 我还在等后端 API，所以现在还有一些不确定性。

> **If I get the API by noon, I should be able to finish by Friday.**  
> 如果我中午前拿到 API，我应该能在周五前完成。

> **Now that we know more, I’d revise the estimate to three days.**  
> 现在信息更多了，我会把估算调整为三天。

快速复习时间表达：

- **by Friday** = 最迟周五完成
- **on Friday** = 周五当天发生
- **before Friday** = 周五之前，不包括周五

Future `if`：

> **If the scope stays the same, we can release on Friday.**

不是：

> ❌ If the scope will stay the same...

---

# 5–17 min | Office Communication & Meetings

## 5–9 min | 场景 1：经理问“这个要多久？”

**Manager:**  
How long do you think this change will take?

**You:**  
My rough estimate is one to two days.

**Manager:**  
Can we commit to Friday?

**You:**  
I think Friday is achievable, but that assumes the API contract doesn’t change and we don’t find any major issues in testing.

**Manager:**  
How confident are you?

**You:**  
I’m reasonably confident. I’d say around 80%, based on what we know right now.

这里的重点是把三个东西分开：

> **estimate** = 估算  
> **assumption** = 这个估算成立的前提  
> **commitment** = 真正对外承诺的时间

非常实用的结构：

> **My rough estimate is ___. That assumes ___.**

例如：

> My rough estimate is two days. That assumes the backend endpoint is ready.

> My rough estimate is three to four hours. That assumes there are no changes to the design.

如果你还不够确定：

> **I can give you a rough estimate now, but I’d like to confirm the dependency before I commit to a date.**

---

## 9–13 min | 场景 2：信息变化后，主动更新 estimate

昨天你说“两天”，今天发现还有迁移工作。

**You:**  
Quick update on the estimate: now that I’ve looked at the migration work, I’d revise it from two days to three.

**PM:**  
What changed?

**You:**  
The implementation itself is still about two days, but we also need data migration and regression testing.

**PM:**  
Does that affect Friday’s release?

**You:**  
Possibly. If we finish the migration by Thursday morning, we should still be able to release on Friday. If it runs later than that, I’d prefer to move the release.

这里要练的是：**更新估算不是“打脸”，而是新信息出现后的正常动作。**

很好用：

> **Quick update on the estimate...**

> **Now that we know more, I’d revise it from ___ to ___.**

> **What changed is ___.**

> **The main new factor is ___.**

不要为了维护旧估算而硬撑。

---

## 13–15 min | 场景 3：依赖没到，只能给范围而不是死时间

**Tech Lead:**  
When will the integration be done?

**You:**  
I’m still waiting for the final API response, so I’d rather give you a range than a fixed date.

**Tech Lead:**  
What range are you thinking?

**You:**  
Once the API is ready, I expect the integration to take about half a day. If I get it by noon today, I should be able to finish by the end of the day. If it comes tomorrow, the finish date moves with it.

这里很值得记：

> **I’d rather give you a range than a fixed date.**

> **Once ___ is ready, I expect ___ to take ___.**

> **If it comes later, the timeline moves with it.**

这比不确定的时候直接说：

> It’ll definitely be done today.

更专业，也更可信。

---

## 15–17 min | 2-minute Oral Substitution Drill

不要默读，直接快速替换。

### Pattern 1

> **My rough estimate is one to two days.**

替换：

- two to three hours
- about half a day
- three to four days
- roughly one week

### Pattern 2

> **That assumes the scope stays the same.**

替换：

- the API is ready today
- the design is final
- there are no major test failures
- we don’t add another requirement

### Pattern 3

> **If I get the API by noon, I should be able to finish by Friday.**

替换：

- get approval by 2 p.m. / merge today
- receive the design today / test tomorrow
- finish migration before Thursday / release on Friday
- get feedback by Wednesday / finish before Friday

# 17–23 min | Colleague Small Talk & Socializing

## 17–20 min | 场景 1：同事问你几点下班

**Colleague:**  
What time are you leaving today?

**You:**  
Probably around 6:30, but it depends on one review.

**Colleague:**  
Still waiting on it?

**You:**  
Yeah. I’m still waiting for the final comments. If they come in by 6, I should be able to wrap up quickly.

**Colleague:**  
Want to grab dinner after?

**You:**  
Maybe. I should know by 6:15.

这里可以练“估计时间但不说死”：

> **Probably around 6:30.**

> **I should know by 6:15.**

> **It depends on ___.**

日常场景不需要讲一大堆“confidence level”，一句 `probably` 或 `around` 就够了。

---

## 20–23 min | 场景 2：朋友问你多久能到

**Colleague:**  
How long will you take to get here?

**You:**  
About twenty minutes, I think.

**Colleague:**  
So around 7?

**You:**  
Yeah, roughly. If traffic is okay, I should be there before 7.

**Colleague:**  
No rush.

这里很好用：

> **About twenty minutes.**

> **Roughly around 7.**

> **I should be there before 7.**

> **I’ll message you if I’m running late.**

`roughly`、`about`、`around` 都可以帮助你表达“这是估计，不是精确到分钟的保证”。

# 23–30 min | Restaurant / Shopping / Ride-hailing

## 23–25 min | Restaurant：问等位时间

**You:**  
Hi, roughly how long is the wait for a table?

**Staff:**  
About twenty to thirty minutes.

**You:**  
Okay. Is that usually accurate, or could it be longer?

**Staff:**  
It could be a little longer if the current tables stay longer.

**You:**  
Got it. If it’s more than thirty minutes, we may come back later.

实用句型：

> **Roughly how long is the wait?**

> **Could it take longer than that?**

> **If it’s more than ___, we may ___.**

这里问的是估算，所以服务员给一个范围很正常。

---

## 25–27 min | Shopping：确认到货时间是不是保证

**You:**  
When do you expect this size to be back in stock?

**Staff:**  
Probably on Friday.

**You:**  
Is Friday confirmed, or is that just an estimate?

**Staff:**  
It’s an estimate. The shipment may arrive later.

**You:**  
Okay. If it arrives by Friday afternoon, I’ll come back then.

非常实用：

> **Is that confirmed, or is that just an estimate?**

> **When do you expect it to arrive?**

> **If it arrives by Friday, I’ll come back.**

注意：

> **on Friday** = 预计周五到  
> **by Friday** = 最迟周五到  
> **before Friday** = 周五之前到

---

## 27–30 min | Grab：ETA 变化了

**Driver:**  
I’ll be there in about five minutes.

**You:**  
Okay, thanks. I’m still waiting for the lift, so that timing should work.

两分钟后，司机发消息：

**Driver:**  
Traffic is moving slowly. Maybe another five minutes.

**You:**  
No problem. Just message me when you’re close.

如果你也可能晚：

> **I should be downstairs in about three minutes.**

> **If I’m not there when you arrive, please wait at Pickup Point B.**

这里的 `in about three minutes` 是 ETA，不是绝对保证。

# 30–35 min | Practical Singapore Life Errands

## 30–33 min | 场景 1：问申请处理时间

**You:**  
Hi, roughly how long does this application usually take to process?

**Staff:**  
Usually three to five working days.

**You:**  
Is that from the day I submit the documents?

**Staff:**  
Yes, as long as all the documents are complete.

**You:**  
Okay. I’m still waiting for one supporting document. If I submit everything by Friday, should it be processed sometime next week?

**Staff:**  
That would be the usual timeline, but it isn’t guaranteed.

这段非常实用：

> **Roughly how long does it usually take?**

> **Is that from the day I submit everything?**

> **Is that a guaranteed timeline or an estimate?**

> **If I submit everything by Friday, when should I expect an update?**

现实办事里，很多处理时间本来就是估算范围，不要自动理解成承诺。

---

## 33–35 min | 场景 2：维修人员给了一个大概到达时间

**Staff:**  
The technician should arrive between 2 and 4 p.m.

**You:**  
Okay. Is there a narrower estimate once the technician is on the way?

**Staff:**  
Yes, we can call you about thirty minutes before arrival.

**You:**  
Great. I have a meeting at 4. If they’re going to arrive after 4, could you let me know before 3:30?

这里可以直接记：

> **Could you give me a narrower estimate?**

> **Could you let me know about thirty minutes before arrival?**

> **If they’re going to be late, could you let me know by 3:30?**

# 35–38 min | Common Grammar Fixes

今天只纠正确实有问题的表达。

### 1

❌ **My estimate is about two days to finish.**  
✅ **My estimate is about two days.**  
✅ **I estimate it will take about two days.**

两种结构都自然，但不要把它们混在一起。

---

### 2

❌ **It depends of the API.**  
✅ **It depends on the API.**

固定搭配：`depend on`。

---

### 3

❌ **If the API will arrive today, I can finish tomorrow.**  
✅ **If the API arrives today, I can finish tomorrow.**

Future `if` 条件从句通常用一般现在时。

---

### 4

❌ **I’m still waiting the final confirmation.**  
✅ **I’m still waiting for the final confirmation.**

`wait for + 人 / 事物`。

---

### 5

❌ **I should can finish it by Friday.**  
✅ **I should be able to finish it by Friday.**

`should` 后不能直接接 `can`。

注意下面这些都正确，只是意思不同：

> **I should be able to finish by Friday.** = 最迟周五完成，带合理预期  
> **We’re planning to release on Friday.** = 计划周五当天发布  
> **We need to finish testing before Friday.** = 周五之前完成测试

# 38–40 min | Final Speaking Challenge

## 第 1 分钟：Workplace Challenge

只看关键词，自己说 45–60 秒：

**rough estimate → assumptions → waiting → confidence → if → by noon → by Friday → update estimate**

参考版本：

> My rough estimate is one to two days, but that assumes the scope stays the same and the API contract is final. I’m still waiting for the backend confirmation, so there’s some uncertainty at the moment. Based on what we know now, I’m reasonably confident we can finish by Friday. If I get the API by noon today, I should be able to start integration this afternoon. If the dependency changes, I’ll update the estimate rather than keep the old date.

## 第 2 分钟：Everyday Challenge

关键词：

**application → three to five days → estimate → waiting for document → by Friday → next week**

参考版本：

> Hi, roughly how long does this application usually take to process? I understand the normal estimate is three to five working days. I’m still waiting for one supporting document. If I submit everything by Friday, should I expect an update sometime next week? I understand that’s an estimate rather than a guaranteed date.
