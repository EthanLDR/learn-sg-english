# Day 33 | Pushing back politely and proposing a workable alternative

### Theme: 不直接说 “No”——先说明顾虑，再给替代方案，让对方能继续做决定

今天重点练一个全栈工程师非常实用的能力：**当需求、时间或方案不合理时，怎么礼貌地提出异议，而不是生硬拒绝；同时给出一个可以继续推进的替代方案。**

你会反复练这几个动作：

- 礼貌表达不同意见：**I see the point, but I have one concern.**
- 说明为什么有风险：**My concern is that we won’t have enough time to test it properly.**
- 给替代方案：**Could we reduce the scope for this release?**
- 给明确选择：**We could either ship the core flow now or move the full feature to Friday.**
- 保留现实承诺：**If we agree on the smaller scope by noon, I should be able to finish today.**
- 继续同步依赖：**I’m still waiting for the backend confirmation.**

同时继续复习：**I’m still waiting... / should be able to / by / on / before / future if**。

---

## 0–5 min | Warm-up：把“不同意 + 给方案”说顺

下面 5 句，每句大声说 3 遍。

> **I see the point, but I have one concern.**  
> 我理解这个想法，但我有一个顾虑。

> **My concern is that we won’t have enough time to test it properly.**  
> 我的顾虑是我们可能没有足够时间完整测试。

> **Could we reduce the scope for this release?**  
> 这次发布我们能不能缩小一点范围？

> **I’m still waiting for the backend confirmation.**  
> 我还在等后端确认。

> **If we agree on the smaller scope by noon, I should be able to finish today.**  
> 如果中午前确定缩小后的范围，我应该今天能完成。

快速复习：

- **by noon** = 最迟中午
- **on Friday** = 周五当天
- **before Friday** = 周五之前，不包括周五

Future if：

> **If we keep the current deadline, we’ll need to reduce the scope.**

不是：

> ❌ If we will keep the current deadline...

# 5–17 min | Office Communication & Meetings

## 5–9 min | 场景 1：PM 想今天再加一个功能

**PM:**  
Can we add saved filters before today’s release?

**You:**  
I see the value, but I have one concern.

**PM:**  
What’s the concern?

**You:**  
If we add it now, we’ll have very little time for regression testing.

**PM:**  
What do you suggest?

**You:**  
Could we keep today’s release focused on the core search flow and add saved filters on Friday?

**PM:**  
Would that be safer?

**You:**  
Yes. If we keep the smaller scope, I should be able to finish testing before the release.

这里最好用的结构是：

> **I see the value, but I have one concern.**

> **If we ___, the risk is ___.**

> **Could we ___ instead?**

这不是“拒绝需求”，而是把**代价和替代方案**讲清楚。

### Reusable Pattern

> **I see why we want ___. My concern is ___. Could we ___ instead?**

例如：

> I see why we want to include analytics now. My concern is that the event names still aren’t final. Could we ship the UI first and add analytics tomorrow instead?

---

## 9–13 min | 场景 2：你不同意技术方案，但不想让讨论变成人身对抗

**Teammate:**  
I think we should put all the state in one global store.

**You:**  
I can see why that would make sharing data easier, but I’m not sure we need that much global state here.

**Teammate:**  
What would you do instead?

**You:**  
I’d keep the page-level state local and only move the shared user data into the global store.

**Teammate:**  
Why?

**You:**  
It keeps the dependency smaller and makes the component easier to reason about. If we later need to share more state, we can move it then.

实用表达：

> **I can see why you’d choose that.**

> **I’m not sure we need ___ here.**

> **I’d prefer ___ because ___.**

> **What if we ___ instead?**

这些句子表达的是“我不同意这个方案”，但重点始终放在**方案本身**，不是“你错了”。

---

## 13–15 min | 场景 3：时间不能同时满足，就把选择摆出来

**Manager:**  
We need the full feature and we still want to release on Friday.

**You:**  
I understand. With the current scope, though, I don’t think we can do both safely.

**Manager:**  
What are the options?

**You:**  
We could either release the core flow on Friday and add the advanced settings next week, or keep the full scope and move the release.

**Manager:**  
Let’s keep Friday and reduce the scope.

**You:**  
Sounds good. I’m still waiting for the backend confirmation. If I get it by noon, I should be able to finish the core flow today.

直接记：

> **I don’t think we can do both safely.**

> **We could either ___ or ___.**

> **Which trade-off would you prefer?**

## 15–17 min | 2-minute Oral Substitution Drill

不要默读，连续开口替换。

### Pattern 1

> **I see the point, but I have one concern.**

替换：

- I see the value, but I’m worried about testing time.
- I understand the goal, but there’s one risk.
- I can see why we want this, but the dependency isn’t ready.
- That makes sense, but I’d like to flag one concern.

### Pattern 2

> **Could we reduce the scope for this release?**

替换：

- move this part to next week
- ship the core flow first
- keep the current behaviour for now
- test this with a smaller group first

### Pattern 3

> **If we agree on the smaller scope by noon, I should be able to finish today.**

替换：

- get backend confirmation by 2 p.m. / finish integration today
- keep the current design / test before Friday
- move analytics to next week / release on Friday
- get approval before lunch / merge this afternoon

# 17–23 min | Colleague Small Talk & Socializing

## 17–20 min | 场景 1：同事想去很远的地方吃午饭，你觉得时间不够

**Colleague:**  
Want to try that new place at Marina Bay for lunch?

**You:**  
I’m up for trying it, but I’m a bit worried about the time.

**Colleague:**  
You have a meeting?

**You:**  
Yeah, at 1:30. What if we go somewhere nearby today and try Marina Bay on Friday instead?

**Colleague:**  
That works.

自然表达：

> **I’m up for it, but...**  
> 我愿意，不过……

> **I’m a bit worried about the time.**  
> 我有点担心时间来不及。

> **What if we ___ instead?**  
> 要不我们改成……？

---

## 20–23 min | 场景 2：同事想把晚饭提前，但你赶不上

**Colleague:**  
Can we move dinner from 7 to 6?

**You:**  
Six might be difficult for me. I’m still waiting to see whether my last meeting ends on time.

**Colleague:**  
Would 6:30 work?

**You:**  
That should be better. If my meeting finishes before 6, I should be able to get there by 6:30.

**Colleague:**  
Perfect.

这里继续练：

> **Six might be difficult for me.**

比：

> **No, I can’t.**

更柔和，也给对方留下继续协商的空间。

# 23–30 min | Restaurant / Shopping / Ride-hailing

## 23–25 min | Restaurant：店员建议的替代品你不太想要

**Staff:**  
The grilled fish is sold out. Would you like the fried fish instead?

**You:**  
I’d prefer something lighter. Is there another grilled option?

**Staff:**  
We have grilled chicken.

**You:**  
That sounds better. I’ll go with that.

很好用：

> **I’d prefer something ___.**

> **Is there another option?**

> **That sounds better.**

不需要直接说：

> I don’t want that.

当然这句话语法没错，只是这里用“偏好 + 替代方案”更自然。

---

## 25–27 min | Shopping：店员推荐的型号超出预算

**Staff:**  
This model has better battery life, but it’s $200 more.

**You:**  
It looks good, but I’d rather stay within my budget.

**Staff:**  
What budget are you working with?

**You:**  
Around $800. Is there something similar in that range?

**Staff:**  
Yes, this model is closer.

**You:**  
Great. Could I compare the two?

实用结构：

> **It looks good, but I’d rather stay within my budget.**

> **Is there something similar in that range?**

> **Could I compare the two?**

---

## 27–30 min | Ride-hailing：司机建议的上车点对你不方便

**Driver:**  
Can you walk to the main road? It’s easier for me to stop there.

**You:**  
I can, but I have a large bag with me. Would Pickup Point B work instead?

**Driver:**  
Yes, I can stop there.

**You:**  
Great. I’m still waiting for the lift. I should be there in about three minutes.

如果对方提议对你不方便：

> **That might be difficult for me because ___.**

> **Would ___ work instead?**

核心仍然是：**说明原因 + 给可执行替代方案。**

# 30–35 min | Practical Singapore Life Errands

## 30–33 min | 场景 1：维修时间和你的安排冲突

**Staff:**  
The technician can come tomorrow between 2 and 5 p.m.

**You:**  
That window is a little difficult for me because I have meetings from 2 to 4.

**Staff:**  
Would the morning work?

**You:**  
Yes. Could we do before noon instead?

**Staff:**  
We should be able to arrange that.

**You:**  
Great. If the morning slot is confirmed by this afternoon, I can make sure someone is home.

实用句：

> **That window is a little difficult for me.**

> **Could we do before noon instead?**

> **If that’s confirmed by this afternoon, I can ___.**

---

## 33–35 min | 场景 2：柜台要求你再跑一次，你想问有没有线上替代方案

**Staff:**  
You’ll need to come back with the original document.

**You:**  
I understand. Before I make another trip, could I check whether there’s any online option?

**Staff:**  
For this document, we need to see the original in person.

**You:**  
Got it. I’m still waiting for the original to arrive. If I receive it by Thursday, should I be able to come in on Friday?

**Staff:**  
Yes.

这里不是争论规则，而是礼貌确认有没有更方便的替代方案：

> **Before I ___, could I check whether there’s another option?**

> **Is there any way to do this online instead?**

> **If not, when would be the best time to come back?**

# 35–38 min | Common Grammar Fixes

今天只纠正确实有问题的表达。

### 1

❌ **I don’t agree this approach.**  
✅ **I don’t agree with this approach.**

固定结构：**agree with + 人 / 观点 / 做法**。

---

### 2

❌ **I suggest to reduce the scope.**  
✅ **I suggest reducing the scope.**  
✅ **I suggest we reduce the scope.**

suggest 后面常用动名词，或者 suggest + 从句。

---

### 3

❌ **If we will keep the Friday deadline, we need to reduce the scope.**  
✅ **If we keep the Friday deadline, we need to reduce the scope.**

Future if 条件从句通常用一般现在时。

---

### 4

❌ **I’m still waiting the backend decision.**  
✅ **I’m still waiting for the backend decision.**

固定结构：**wait for + 人 / 事物**。

---

### 5

❌ **I should can finish the smaller scope today.**  
✅ **I should be able to finish the smaller scope today.**

should 后不能直接接 can。

下面三句都正确，只是意思不同：

> **We need a decision by Friday.** = 最迟周五需要决定

> **We’ll release it on Friday.** = 周五当天发布

> **We need to finish testing before Friday.** = 周五之前完成测试

# 38–40 min | Final Speaking Challenge

## 第 1 分钟：Workplace Challenge

只看关键词，自己说 45–60 秒：

**new request → see the value → concern → testing → two options → waiting → by noon → should be able to**

参考版本：

> I see the value in adding saved filters to this release, but I have one concern. If we add them now, we’ll have very little time for regression testing. I think we have two realistic options: either keep Friday’s release and move saved filters to next week, or keep the full scope and move the release date. I’m still waiting for the backend confirmation. If we agree on the smaller scope by noon, I should be able to finish the core flow today and test it properly before Friday.

## 第 2 分钟：Everyday Challenge

关键词：

**technician → 2 to 5 → difficult → meetings → morning → before noon → confirm by afternoon**

参考版本：

> Hi, the 2 to 5 p.m. technician window is a little difficult for me because I have meetings from 2 to 4. Would a morning appointment work instead? Before noon would be ideal. If the morning slot can be confirmed by this afternoon, I can make sure someone is home to let the technician in.

# Day 33 Compact Review

|---|---|
| 礼貌提出异议 | **I see the point, but I have one concern.** |
| 说明风险 | **My concern is that...** |
| 不完全认同方案 | **I’m not sure we need ___ here.** |
| 给偏好和理由 | **I’d prefer ___ because ___.** |
| 提替代方案 | **Could we ___ instead?** |
| 给两个选择 | **We could either ___ or ___.** |
| 让对方选取舍 | **Which trade-off would you prefer?** |
| 还在等待 | **I’m still waiting for the backend confirmation.** |
| 条件化承诺 | **If we agree by noon, I should be able to finish today.** |
| 最迟周五 | **by Friday** |
| 周五当天 | **on Friday** |
| 周五之前 | **before Friday** |
| 日常委婉拒绝 | **That might be difficult for me because ___.** |
| 日常换方案 | **Would ___ work instead?** |

> **I see the point, but I have one concern.**

> **My concern is that we won’t have enough time to test it properly.**

> **Could we reduce the scope for this release?**

> **We could either ship the core flow now or move the full feature to Friday.**

> **I’m still waiting for the backend confirmation.**

> **If we agree on the smaller scope by noon, I should be able to finish today.**
