# Day 67 | Let me check and get back to you: respond confidently without guessing

### 今日主题：被当场问住时，怎样自然地承认还不确定、查清事实，并给出明确回复时间

今天的新技能是 **acknowledge the question → separate known facts from unknowns → say how you'll check → commit to a follow-up**（接住问题 → 区分已知与未知 → 说明核实方法 → 约定回复）。昨天练的是把复杂内容讲简单；今天练的是：**对方突然追问一个你暂时不知道的细节，不编答案，也不只说 “I don't know”。**

> **That's a good question. Let me double-check.** 这个问题问得好，我再核对一下。
>
> **I don't have that information in front of me.** 我手头暂时没有这项信息。
>
> **I can confirm the UI is ready, but I still need to check the API status.** 我能确认 UI 已准备好，但 API 状态还要核实。
>
> **I'll get back to you by 3 p.m.** 我最迟下午三点回复你。
>
> **If I can't confirm it by then, I'll send you a status update.** 如果到时还确认不了，我会先同步进度。

**get back to someone** = 核实后回复某人；**double-check** = 再核对；**off the top of my head** = 不查资料、凭当下记忆。今天重点区分 **I don't know yet（尚未知道）** 与 **I haven't checked yet（尚未核实）**；也区分 **答复截止时间** 和 **事情完成时间**。不承诺自己无法控制的结果。

旧句型简短循环：**I'm still waiting for / should be able to / by、on、before / if + 一般现在时**。所有办公室和新加坡生活情境均为模拟；重要规定、价格、账户状态以官方渠道为准。

**严格 40 分钟：0–5（5）+ 5–17（12）+ 17–23（6）+ 23–30（7）+ 30–35（5）+ 35–37（2）+ 37–38（1）+ 38–40（2）= 40。** 每段的朗读、替换、自由表达与核对均包含在段内。

## 0–5 min | Warm-up：不确定，也能回答得专业

**0–2 min｜四句各读三遍，剩余时间连说：**

> **Let me check that before I give you an answer.** 我先核对一下再答复。
>
> **I can confirm the frontend is ready.** 我可以确认前端已经准备好了。
>
> **I'm still waiting for the backend update.** 我还在等后端的消息。
>
> **I'll get back to you by 3 p.m., even if there's no final answer.** 即使还没最终结果，我也最迟三点回复进度。

**2–4 min｜每轮一分钟；先分角色朗读，再遮住 You：**

**PM:** Is the new feature ready for QA?

**You:** The frontend build is ready, but I haven't confirmed the latest API status.

**PM:** Can you check?

**You:** Yes. I'll ask the API owner and get back to you by 2 p.m.

第二轮替换 **feature → upload flow**、**API status → test-data status**、**2 p.m. → 4 p.m.**。保持“已知事实 + 待核实项 + 回复时间”。

**4–5 min｜中文转英文，先说再核对：**

“我现在不想猜。” → **I'd rather check than guess.**

“我还在等 QA 的回复。” → **I'm still waiting for QA's reply.**

“如果他们中午前回复，我应该能最迟四点确认测试安排。” → **If they reply by noon, I should be able to confirm the test plan by 4 p.m.**

## 5–17 min | Office Communication & Meetings

### 5–9 min | Scene 1：PM 临时问上线状态，不要替后端保证

**PM:** Can we say the upload feature is fully ready?

**You:** I can confirm the frontend build is ready, but I haven't verified the latest API status.

**PM:** Do you think the integration will pass?

**You:** I don't want to guess. Let me check with the API owner and QA first.

**PM:** When can you update us?

**You:** I'll share what I know by 3 p.m., even if verification is still pending.

**PM:** What are you working on meanwhile?

**You:** I'm checking the client-side error states. I'm still waiting for the API confirmation. If it arrives by noon, I should be able to complete an integration check by 4 p.m.

**5–7 min：**分角色朗读两轮；第二轮遮住 You。**7–8 min：**脱稿回答：What is confirmed? What is still unknown? What will be communicated at 3 p.m.? **8–9 min：**40 秒口述 + 20 秒自检：

> **I can confirm ___. I haven't confirmed ___ yet. I'll check with ___ and get back to you by ___. If ___, I should be able to ___ by ___.**

**fully ready** = 全部准备就绪；**verification pending** = 等待验证。**I'll update you by 3** 不表示“一定三点前解决”。

### 9–13 min | Scene 2：会议上有人问精确数字，你手头没有数据

**Lead:** How much did the new loading state improve the completion rate?

**You:** I don't have the verified number in front of me, so I'd rather not quote one from memory.

**Designer:** Do we have a report?

**You:** We have an internal test summary, but I need to check its sample size and date before drawing a conclusion.

**Lead:** When can we review it?

**You:** I'll check the approved report after the meeting and share a short summary by tomorrow afternoon.

**Designer:** What if the data is inconclusive?

**You:** I'll say that clearly and recommend what additional evidence we need, rather than presenting an estimate as a measured result.

**9–11 min：**读两轮；第二轮替换 **completion rate → loading time**、**sample size → test conditions**。**11–12 min：**按 **question → no verified number → source → follow-up → uncertainty** 复述。**12–13 min：**脱稿说：

> **I don't have the verified ___ in front of me. I'll check ___ and get back to you by ___. If the evidence isn't conclusive, I'll explain ___ rather than guessing.**

**inconclusive** = 尚不足以下结论；**quote a number** = 引用一个数字。没有核实的估算，不要包装成实测结论。

### 13–15 min | Scene 3：Code Review 中被追问实现细节

**Reviewer:** Does this hook cancel the request when the component unmounts?

**You:** I'm not completely sure about that path. Let me check the cleanup logic before answering.

**Reviewer:** Could you add a test if necessary?

**You:** Yes. I'll inspect the implementation first, then add or update the relevant test based on what I find.

**Reviewer:** When will you follow up?

**You:** I'll reply on the PR by tomorrow. If I find an issue, I'll explain the impact and the proposed fix.

**13–14 min：**朗读，重点说 **I'm not completely sure / Let me check / I'll reply on the PR**。**14–15 min：**40 秒复述 **question → uncertain detail → inspection → evidence → reply**，20 秒重复：**I'll verify the behaviour before making a claim.**

### 15–17 min | Timed oral substitution：12 轮 × 10 秒

**15:00–15:40｜A. 表达需要核实（4 轮）**

模板：**I can confirm ___, but I still need to check ___.**

1. the UI is ready / the API status
2. the PR is open / the review result
3. the build is available / the QA sign-off
4. the event is sent / the analytics report

**15:40–16:20｜B. 承诺可控的回复（4 轮）**

模板：**I'll check ___ and get back to ___ by ___.**

1. the contract / QA / noon
2. the test report / the PM / 3 p.m.
3. the PR comments / the reviewer / tomorrow
4. the approved specification / the designer / Friday

**16:20–17:00｜C. 条件句和期限（4 轮）**

模板：**If ___, I should be able to ___ ___.**

1. the API owner replies by noon / confirm the status / by 4
2. QA responds on Monday / update the ticket / on Tuesday
3. the report arrives today / share the answer / before Friday
4. the review finishes by Thursday / reply to the team / on Friday

每轮 **3 秒看提示 + 7 秒完整说句子**，共 120 秒。**by Friday** = 最迟周五；**on Friday** = 周五当天；**before Friday** = 周五之前。

## 17–23 min | Colleague Small Talk & Socializing

### 17–20 min | Scene 4：同事问周末哪里好玩，不熟悉也能接话

**Colleague:** Do you know if that museum is open on Sunday?

**You:** I'm not sure off the top of my head. Let me check the official opening hours.

**Colleague:** No rush. I'm just thinking about going.

**You:** Sounds fun. What kind of exhibitions do you like?

**Colleague:** Mostly technology and design.

**You:** Nice. I'll send you the official link once I've checked it.

**17–18 min：**读两轮。**18–19 min：**替换 **museum → sports centre**、**Sunday → Saturday**。**19–20 min：**40 秒脱稿说 **uncertainty → how to check → friendly question → next reply**；20 秒复读。这里不用编造实际营业时间。

### 20–23 min | Scene 5：同事约饭，你暂时不能确定

**Colleague:** A few of us are having lunch at 12:30. Coming?

**You:** I'd love to, but I'm still waiting to see when my meeting ends.

**Colleague:** Could you let us know before we leave?

**You:** Sure. I'll confirm by noon, even if I can't join.

**Colleague:** Great. We can decide on the seats then.

**You:** Thanks! If my meeting finishes on time, I should be able to join you at 12:30.

**20–21 min：**朗读。**21–22 min：**替换 **lunch → coffee**、**12:30 → 3 p.m.**、**noon → 2 p.m.**。**22–23 min：**40 秒说 **interest → uncertainty → reply deadline → conditional plan**，20 秒自检。**confirm by noon** 指“中午前给答复”，也可以答复“去不了”。

## 23–30 min | Restaurant / Shopping / Ride-hailing

### 23–25 min | Restaurant：对配料没把握，先请店员查证

**You:** Excuse me, does this dish contain peanuts?

**Staff:** I'm not sure. Let me check the ingredient information.

**You:** Thank you. Could you also check whether there's a risk of cross-contact?

**Staff:** I'll ask the kitchen and explain what we can confirm.

**You:** I appreciate it. I'll wait for a clear answer before ordering.

**23–24 min：**朗读。**24–25 min：**替换 **peanuts → shellfish**。练 **specific question → staff checks → clarify risk → wait for answer**。如果有严重食物过敏，不能仅凭不确定回答或推测决定安全性。

### 25–27 min | Shopping：库存或保修范围不明确

**You:** Is this keyboard available in the colour shown online?

**Staff:** Let me check the live stock information.

**You:** Thanks. Could you also confirm the warranty terms for this exact model?

**Staff:** I'll refer to the official product details.

**You:** Great. I don't need an answer immediately; I'd prefer an accurate one.

**25–26 min：**朗读。**26–27 min：**替换 **keyboard → monitor**、**colour → size**，练 **precise question → verification source → no pressure to guess**。

### 27–30 min | Ride-hailing：预计上车时间不确定，如何通知同伴

**Colleague:** Will the car arrive in five minutes?

**You:** The app currently shows an estimate, but I can't guarantee the exact arrival time.

**Colleague:** Should we head downstairs now?

**You:** Let me check the latest pickup information. We should follow the app's designated point.

**Colleague:** Okay. Keep me updated.

**You:** If the estimate changes, I'll let you know. Let's avoid asking the driver to stop somewhere unsafe.

**27–28 min：**读两轮。**28–29 min：**替换 **five minutes → ten minutes**、**downstairs → the pickup level**。**29–30 min：**40 秒脱稿说 **current estimate → uncertainty → safe next check → update**，20 秒检查：预计时间不是保证时间。

## 30–35 min | Practical Singapore Errands

### 30–33 min | Scene 9：银行申请处理中，要求核实而非听猜测

**You:** Hi, my application status hasn't changed, and I'm not sure whether any documents are missing.

**Support:** Please check the status and document requirements in the bank's official channel.

**You:** I've checked the status, but I don't see a clear explanation. Could you verify what the next required step is?

**Support:** Please use the bank's verified support process for your application.

**You:** Understood. If the status can't be confirmed today, how should I follow up using my existing reference number?

**Support:** Please follow the official enquiry instructions.

**You:** Thank you. I'll wait for verified information before resubmitting anything.

**30–31 min：**朗读。**31–32 min：**按 **status unclear → official verification → follow-up channel → avoid duplicate** 复述。**32–33 min：**替换 **account application → debit card request**，练三句：**Could you verify the current status? / What is the next required step? / How should I follow up?** 受理不等于批准；不要假定当天可以领取实体卡。

### 33–35 min | Scene 10：手机服务异常，请客服确认调查进度

**You:** Hi, I'm following up on a mobile data issue. I'm still waiting for a technical update.

**Support:** Please check your case status through the provider's official channel.

**You:** Thanks. Could you confirm whether the investigation is still open?

**Support:** Please follow the status information and official support guidance.

**You:** Got it. If there's no final answer today, I'd appreciate a status update and the correct way to follow up.

**33–34 min：**朗读。**34–35 min：**40 秒脱稿说 **existing case → what's unknown → request status → next contact**，20 秒自检。不向未知来电、网站或聊天对象透露密码、OTP。

## 35–37 min | Accurate Grammar Corrections

**35–36 min｜先独立修改前三句，再核对：**

1. ❌ **I'll get back to you until 3 p.m.** → ✅ **I'll get back to you by 3 p.m.**（by 表示最迟某时；until 表示持续到某时，不适合这里的回复承诺）
2. ❌ **Let me to check it first.** → ✅ **Let me check it first.**（let + 人 + 动词原形）
3. ❌ **I don't have the information in my hand now.** → ✅ **I don't have the information in front of me right now.** / ✅ **I don't have the information on hand right now.**（这里指手头掌握的资料，优先用自然搭配；原句并非在所有字面情境下都不合语法）

**36–37 min｜复习两句：**

4. ❌ **I'm still waiting the test results.** → ✅ **I'm still waiting for the test results.**
5. ❌ **If QA will reply today, I should able to update you before Friday.** → ✅ **If QA replies today, I should be able to update you before Friday.**（普通未来 if 从句用一般现在时；should be able to）

**正确替代，不算语法错误：** **Let me check / Let me double-check / I'll look into it** 都自然；**I'll get back to you / I'll follow up with you** 都正确；**I don't know yet** 也是正确句子，只是可以补上核实计划。新加坡办公英语中可能听到 **I'll revert to you**，但 **I'll get back to you** 跨地区更清晰。**I'll reply by Friday / on Friday / before Friday** 都正确，时间含义不同。

## 37–38 min | Compact Review

**37:00–37:30：**遮住右栏，看中文快速口译。**37:30–38:00：**每句换一个工程或生活场景。

| 目的 | 可复用英语 |
|---|---|
| 接住问题 | **That's a good question.** |
| 暂时不猜 | **I'd rather check than guess.** |
| 区分已知和未知 | **I can confirm ___, but I still need to check ___.** |
| 说明核实来源 | **I'll check with ___ / the official source.** |
| 承诺回复 | **I'll get back to you by ___.** |
| 未有结论也更新 | **If it's still pending, I'll send a status update.** |
| 等待依赖 | **I'm still waiting for ___.** |
| 条件与期限 | **If they reply by noon, I should be able to confirm it by 4.** |

口诀：**Know → Don't know yet → Check → Follow up.**

## 38–40 min | Final Speaking Challenges

### 38–39 min | Workplace：40 秒脱稿 + 15 秒参考核对 + 5 秒自检

提示：**PM asks if upload feature is ready → frontend ready → API/QA not confirmed → don't guess → ask owners → update by 3 even if pending → if API by noon → integration check by 4**。

**38:00–38:40：**不看参考，向 PM 汇报。**38:40–38:55：**快速核对。**38:55–39:00：**检查是否区分事实、未知项和回复承诺。

> **I can confirm the frontend build for the upload feature is ready, but I haven't verified the latest API status or QA result yet. I'd rather check than guess. I'll follow up with the relevant owners and update you by 3 p.m., even if some checks are still pending. I'm still waiting for the API confirmation. If it arrives by noon, I should be able to complete an integration check by 4 p.m.**

### 39–40 min | Everyday：40 秒脱稿 + 15 秒参考核对 + 5 秒自检

提示：**bank application unclear → documents? → don't assume → official verification → existing reference → request next step and follow-up route**。

**39:00–39:40：**不看参考，向银行官方客服提问。**39:40–39:55：**对照参考。**39:55–40:00：**检查是否没有把“尚未明确”说成“已批准或被拒”。

> **Hi, I'm following up on an account application. The status hasn't changed, and I'm not sure whether any documents are missing. Could you verify the current status and tell me what I should do next? I have the existing reference number. If there's no final answer today, could you explain how I should follow up through the official channel? I'd prefer to check before submitting anything again. Thank you.**

**40 分钟完成。今天最重要的一句：Let me check and get back to you by ___. If it's still pending, I'll send an update.**
