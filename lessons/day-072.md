# Day 72 | What changed since the last check? Compare before and after

### 今日主题：发现情况变了，先比较“之前与现在”，再判断影响和下一步

今天的新技能是 **state what was true before → describe what's different now → check the impact → agree on a next action**（说清之前的状态 → 描述现在的差异 → 核实影响 → 确认下一步）。昨天练 **Just a heads-up** 提前提醒变化；今天进一步练习：别人问“到底变了什么？”时，能用事实和对比回答，不把时间上的先后直接当成因果关系。

> **What changed since the last check?** 上次检查之后发生了什么变化？
>
> **It worked in the previous build, but it fails in the current one.** 上一个构建版本可以运行，但当前版本失败了。
>
> **The main difference is the response format.** 主要区别是响应格式。
>
> **Let's compare the two cases under the same conditions.** 我们在相同条件下比较两种情况吧。
>
> **We noticed the change, but we haven't confirmed the cause.** 我们观察到了变化，但还没确认原因。

**previous / current** = 之前的／当前的；**regression** = 原本可用、后来失效的回归问题；**before and after** = 变化前后；**baseline** = 对比基线。关键区别：**The issue appeared after the update** 只说明时间先后，不自动证明 **the update caused the issue**。

复习句型 **I'm still waiting for / should be able to / by、on、before / 未来 if 条件句**；不重复长篇语法讲解。以下工作和新加坡生活对话均为模拟，真实状态以记录、官方渠道和可验证的信息为准。

**总计恰好 40 分钟：0–5（5）+ 5–17（12）+ 17–23（6）+ 23–30（7）+ 30–35（5）+ 35–37（2）+ 37–38（1）+ 38–40（2）= 40。** 所有朗读、替换、准备和自检均包含在对应时间内。

## 0–5 min | Warm-up：一句“之前”，一句“现在”

**0–2 min｜四句各朗读三遍，剩余时间连起来说：**

> **It worked yesterday, but it isn't working now.** 昨天还能用，现在不能用了。
>
> **Has anything changed since then?** 从那以后有什么变化吗？
>
> **The old version still works.** 旧版本仍然可以运行。
>
> **Let's check what's different before guessing why.** 先弄清差异，再推测原因。

**2–4 min｜第一分钟分角色朗读，第二分钟遮住 You 再回答：**

**QA:** The search page is slower than it was yesterday.

**You:** Is that on the same device and test build?

**QA:** Same device, but a newer build.

**You:** Thanks. Let's compare the two builds under the same test conditions before deciding what caused it.

第二轮替换 **search page → upload page**、**slower → less responsive**。注意只确认“有差异”，不要直接说“新版代码导致变慢”。

**4–5 min｜先口译，剩余时间核对并再说一遍：**

“上次测试后有什么变化？” → **What changed since the last test?**

“我还在等之前的测试数据。” → **I'm still waiting for the previous test results.**

“如果中午前拿到，我应该能最迟四点完成对比。” → **If I get them by noon, I should be able to finish the comparison by 4 p.m.**

## 5–17 min | Office Communication & Meetings

### 5–9 min | Scene 1：AI 流式输出在新构建版本里出现回归

**QA:** Streaming worked in the previous build, but it sometimes stops in the latest one.

**You:** Thanks for flagging it. Were both tests run on the same device and network?

**QA:** Same device, but I need to check the network conditions.

**You:** Okay. Let's record the build versions and compare the client events using approved test data.

**QA:** Do you think the latest change caused it?

**You:** It's possible, but we haven't confirmed that. We should compare the behaviour before and after under the same conditions.

**QA:** When can you share a finding?

**You:** I'm still waiting for the earlier test logs. If they arrive by noon, I should be able to share an initial comparison by 4 p.m.

**5–7 min：**读两轮，第二轮只看 QA 的台词回答。**7–8 min：**脱稿回答：What changed? What conditions must match? Is the cause confirmed? **8–9 min：**40 秒口述，20 秒自检：

> **Previously, ___. Now, ___. One difference is ___. We haven't confirmed ___ yet. I'm still waiting for ___. If ___, I should be able to ___ by ___.**

**initial comparison** = 初步对比，不等于最终根因分析。只使用团队批准的日志和测试数据。

### 9–13 min | Scene 2：需求会议里比较新版设计与原计划

**PM:** Can we still use the original estimate for the profile screen?

**You:** Could we first review what changed in the latest design?

**Designer:** We added an optional section and changed the validation message.

**You:** So the original scope had one form section. The new version has an additional section and updated validation copy. Is that accurate?

**Designer:** Yes. The API contract hasn't changed.

**PM:** Does that affect the estimate?

**You:** It might. I'll compare the implementation effort with the original scope and list any difference rather than give a number immediately.

**PM:** When can we review it?

**You:** If I receive the final design on Monday, I should be able to share the revised estimate by Tuesday.

**9–11 min：**朗读两轮；第二轮替换 **optional section → confirmation step**、**validation message → error message**。**11–12 min：**按照 **original scope → new changes → unchanged dependency → possible impact** 复述。**12–13 min：**60 秒脱稿说：

> **Compared with the original design, ___ has changed, while ___ remains the same. That may affect ___. I'll check the difference before updating the estimate.**

**remains the same** = 保持不变。不要因为“有变动”就自动认定“必须延期”。

### 13–15 min | Scene 3：Code Review 中用前后行为描述回归

**Reviewer:** Why did you add a regression test for this form?

**You:** Before the change, pressing Enter submitted the form. After the refactor, it no longer did.

**Reviewer:** Was that behaviour intentional?

**You:** No. The expected keyboard behaviour hasn't changed. The test checks that it still works.

**Reviewer:** Does the test cover every input method?

**You:** Not yet. It covers the agreed Enter-key case, and I'll document any other cases that need checking.

**13–14 min：**朗读，重读 **Before / After / expected behaviour**。**14–15 min：**40 秒总结 **previous behaviour → new failure → expected behaviour → test scope**，20 秒重复：**The new test guards against the regression; it doesn't verify every possible case.**

### 15–17 min | Timed Oral Substitution：12 轮 × 10 秒

**15:00–15:40｜A. 说清前后差异（4 轮）**

模板：**Previously, ___. Now, ___.**

1. the page loaded quickly / it takes longer
2. the button was enabled / it stays disabled
3. the message was short / it has more details
4. the build passed QA / it still needs verification

**15:40–16:20｜B. 请求可比的证据（4 轮）**

模板：**Could we compare ___ under the same conditions?**

1. the two builds
2. the API responses
3. the loading times
4. the mobile layouts

**16:20–17:00｜C. 条件与期限（4 轮）**

模板：**If ___, I should be able to ___ ___.**

1. the logs arrive by noon / compare the builds / by 4
2. QA replies on Monday / update the report / on Tuesday
3. the design arrives today / check the differences / before Friday
4. the review finishes by Thursday / share the summary / on Friday

每轮 **3 秒看提示 + 7 秒完整大声说**，恰好 120 秒。**by Friday** = 最迟周五；**on Friday** = 周五当天；**before Friday** = 周五之前。

## 30–35 min | Practical Singapore Errands

### 30–33 min | Scene 9：银行申请状态发生变化，先问具体含义

**You:** Hi, my account application showed “Submitted” before, but now it shows “Under review”.

**Support:** Please refer to the bank's official status explanations.

**You:** Could you explain what has changed and whether any action is required from me?

**Support:** Please check the instructions linked to the current application status.

**You:** Does “Under review” mean a decision has been made?

**Support:** Please rely on the bank's official decision and notification status.

**You:** Understood. I won't treat a status change as approval. I'll keep the reference and follow up through the official channel.

**30–31 min：**朗读。**31–32 min：**按 **previous status → current status → action required? → official confirmation** 复述。**32–33 min：**替换成 **debit-card request**，说三句：**The status used to show ___. / Now it shows ___. / What does this change mean?** 状态文字仅为模拟，不代表某家银行真实的状态字段或处理进度。

### 33–35 min | Scene 10：电信套餐更新后，核实与原套餐的差异

**You:** Hi, I'm comparing my previous mobile plan with the newly offered one.

**Staff:** What would you like to check?

**You:** Could you show me what's changed in the data allowance, contract terms and total charges?

**Staff:** Please review the official plan summaries for both options.

**You:** Thanks. I'm still waiting for the written terms. If they arrive today, I should be able to compare the two plans before Friday.

**33–34 min：**朗读。**34–35 min：**40 秒复述 **old plan → new plan → meaningful differences → written proof**，20 秒自检。费用及漫游条件以运营商正式条款为准。

## 35–37 min | Accurate Grammar Corrections

**35–36 min｜先说正确句，再核对：**

1. ❌ **What has change since yesterday?** → ✅ **What has changed since yesterday?**（现在完成时：has + 过去分词 changed）
2. ❌ **Did the API changed?** → ✅ **Did the API change?**（did 后接动词原形）
3. ❌ **This version different from the old one.** → ✅ **This version is different from the old one.**（different 是形容词，需要 is）

**36–37 min｜复习两句：**

4. ❌ **I'm still waiting the earlier results.** → ✅ **I'm still waiting for the earlier results.**
5. ❌ **If the logs will arrive today, I should able to compare them by Friday.** → ✅ **If the logs arrive today, I should be able to compare them by Friday.**（普通未来 if 从句用一般现在时；should be able to）

**正确替代表达，不算错误：** **What changed? / What's changed? / Has anything changed?** 都正确；**Compared with the previous build / Compared to the previous build** 都常见；**It worked before / It used to work** 都自然，但 **used to** 更强调过去习惯或状态。**I'll check by Friday / on Friday / before Friday** 都正确，只是时间含义不同。

### 38–39 min | Workplace：40 秒脱稿 + 15 秒对照 + 5 秒自检

I'll check the official instructions and keep my reference number for follow-up. Thank you.**
