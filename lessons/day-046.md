# Day 46 | Walk me through it: explain steps and confirm what happens next

### 今日主题：步骤一多就容易听漏？学会让对方一步步讲清楚

今天的新技能是 **ask for steps → follow the sequence → confirm the checkpoint → agree on the next action**（请求步骤 → 按顺序操作 → 核对关键节点 → 明确下一步）。适合前端 Bug 复现、QA 交接，以及新加坡自助点餐、预约和取件。

> **Could you walk me through the steps?** 能一步步带我过一下流程吗？
>
> **What should I do first?** 我第一步应该做什么？
>
> **What happens after that?** 然后会发生什么？
>
> **So I should check the result before moving on, right?** 所以继续之前要先检查结果，对吗？
>
> **If I get stuck, who should I contact?** 如果卡住了，该联系谁？

新词：**walk someone through**（带某人一步步了解）、**reproduce a bug**（复现问题）、**checkpoint**（检查节点）、**get stuck**（卡住）。复习贯穿 **I'm still waiting for / should be able to / by、on、before / 未来 if 条件句**。所有系统、商家和服务流程均为口语模拟；真实操作以官方说明为准。

**计时恰好 40 分钟：0–5（5）+ 5–17（12）+ 17–23（6）+ 23–30（7）+ 30–35（5）+ 35–37（2）+ 37–38（1）+ 38–40（2）= 40 分钟。** 朗读、口述、替换和自检均包含在对应时段内。

---

## 0–5 min | Warm-up：先把顺序说清楚

**0–2 min｜四句各朗读三遍：**

> **First, open the test page.** 第一步打开测试页面。
>
> **Then, sign in with a test account.** 然后用测试账号登录。
>
> **After that, check the result.** 接着查看结果。
>
> **Finally, share what you found.** 最后反馈你的发现。

**2–4 min｜两轮一分钟对话：**

**Colleague:** Can you check this issue?

**You:** Sure. Could you walk me through the steps?

**Colleague:** First open the test page, then tap Generate.

**You:** Got it. What should I see after tapping Generate?

第一轮朗读并换角色；第二轮把 **test page → settings page**，**Generate → Save**，遮住 You 的台词再说。

**4–5 min｜中文口译后核对：**

“我还在等测试版本。” → **I'm still waiting for the test build.**

“如果今天收到，我应该能最迟周五完成检查。” → **If I get it today, I should be able to finish checking by Friday.**

“下一步是什么？” → **What's the next step?**

## 5–17 min | Office Communication & Meetings

### 5–9 min | Scene 1：让 QA 一步步说明 Bug 复现方法

**QA:** The Generate button sometimes gets stuck, but I can't reproduce it every time.

**You:** Could you walk me through the exact steps?

**QA:** First, open the test build. Then sign in with a test account. After that, tap Generate twice.

**You:** Does it get stuck after the second tap?

**QA:** That's what happened on my phone. I haven't confirmed it on desktop.

**You:** Got it. I'll follow the same steps and record what happens.

**QA:** Could you add the steps to the ticket?

**You:** Sure. If I can reproduce it today, I should be able to update the ticket before 5 p.m.

**5–7 min：**分角色朗读两轮；第二轮遮住 You 的话。**7–8 min：**脱稿回答：What are the three steps? When might the issue appear? What is still unconfirmed? **8–9 min：**口述 40–50 秒：

> **First, ___. Then, ___. After that, ___. I'll check whether ___. If ___, I should be able to ___ before ___.**

**提醒：**“在一台手机出现过”不等于“所有手机都有问题”。**reproduce consistently** = 稳定复现。

### 9–13 min | Scene 2：在会议里解释测试交接顺序

**Lead:** Can you explain what happens after the UI fix is ready?

**You:** First, I'll put the fix in a test build. Once the build passes the automated checks, I'll share it with QA.

**Lead:** What should QA check?

**You:** They should follow the original bug steps and check whether the issue still happens.

**Lead:** Can we release it immediately if that test passes?

**You:** Not automatically. We should confirm the remaining checks and get the required release approval first.

**Lead:** When can you hand it over?

**You:** I'm still waiting for the API update. If it arrives by noon, I should be able to hand over the build by 4 p.m.

**9–11 min：**朗读两轮；第二轮将 **UI fix → loading-state fix**。**11–12 min：**只看 **build → automated checks → QA → approval** 复述顺序。**12–13 min：**脱稿说：

> **Once ___ is ready, I'll ___. After ___, QA can ___. Before release, we still need ___.**

**once** 在这里表示“一旦……完成”；**hand over** = 移交给下一个负责人。练习不代表真实团队的发布规定。

### 13–15 min | Scene 3：没听懂某一步时，不要假装会了

**Engineer:** Open the Network tab, find the request, and compare the response.

**You:** Sorry, I got the first step, but I'm not sure what comes after that.

**Engineer:** Find the request triggered by the button, then check its response.

**You:** Thanks. Should I look at the status code first or the response body?

**Engineer:** Start with the status code, then check the response body.

**You:** Got it. I'll try that and share what I see.

**13–14 min：**朗读；记住 **I'm not sure what comes after that.**（后面那步我不确定）。**14–15 min：**用 **where to look → which request → what to inspect first → next action** 复述 40 秒，剩余时间重说关键问题。

### 15–17 min | Timed oral substitution：12 轮 × 10 秒

**15:00–15:40｜A. 请求下一步（4 轮）**

模板：**Could you walk me through ___? What should I do first?**

1. the test setup
2. the bug reproduction steps
3. the release checklist
4. the new onboarding flow

**15:40–16:20｜B. 说明操作顺序（4 轮）**

模板：**First, ___. Then, ___.**

1. open the page / tap Save
2. sign in / open Settings
3. check the status code / read the response
4. run the tests / share the result

**16:20–17:00｜C. If + 期限（4 轮）**

模板：**If ___, I should be able to ___ ___.**

1. the build arrives by noon / finish testing / by 4
2. QA replies on Tuesday / update the ticket / on Wednesday
3. the API works today / prepare the demo / before Friday
4. I get approval by Thursday / share the build / on Friday

每轮 **3 秒看提示 + 7 秒开口说完整句**，共 120 秒。**by Friday** = 最迟周五；**on Friday** = 周五当天；**before Friday** = 周五之前。

## 17–23 min | Colleague Small Talk & Socializing

### 17–20 min | Scene 4：请同事说明怎么到聚餐地点

**Colleague:** We're having lunch at the food court near the station.

**You:** Sounds good. Could you walk me through how to get there from the office?

**Colleague:** Sure. First, go downstairs. Then follow the signs towards the station.

**You:** Got it. What should I look for after that?

**Colleague:** I'll send you a location pin so you can check the exact entrance.

**You:** Perfect. If I get lost, I'll message you.

**17–18 min：**朗读两轮。**18–19 min：**把 **food court → café**、**station → mall**，重新问一次。**19–20 min：**遮稿按 **accept → ask for route → confirm landmark → fallback** 说 40 秒。

**location pin** = 地图定位点。不要把这段虚构路线当成真实导航。

### 20–23 min | Scene 5：请同事教你参加周末活动

**Colleague:** A few of us are playing badminton this weekend. Want to join?

**You:** I'd love to. I've never joined this group before. How does it usually work?

**Colleague:** We confirm the time in the group chat and split into pairs at the court.

**You:** Do I need to bring anything?

**Colleague:** Just check the plan in the group chat first.

**You:** Sounds easy enough. If I'm free on Saturday, I'll confirm by Friday.

**20–21 min：**朗读。**21–22 min：**替换成 **board games / bring a game**。**22–23 min：**自由说 **interest → ask how it works → prepare → confirm by when**，最后 15 秒重说最顺的一句。

## 23–30 min | Restaurant / Shopping / Ride-hailing

### 23–25 min | Restaurant：第一次用自助点餐机

**You:** Hi, I've never used this ordering kiosk before. Could you show me how it works?

**Staff:** Please follow the instructions on the screen.

**You:** Okay. Should I check the order summary before paying?

**Staff:** Yes, make sure the items are correct.

**You:** Thanks. What should I do if the payment doesn't go through?

**Staff:** Please ask a staff member for help.

**23–24 min：**朗读。**24–25 min：**改为 **drinks kiosk / choose the size**，练 **first → before paying → if something fails**。实际机器操作以屏幕说明为准。

### 25–27 min | Shopping：询问自助结账下一步

**You:** Excuse me, I scanned the item, but I'm not sure what to do next.

**Staff:** Please check the instructions on the checkout screen.

**You:** Should I confirm the item list before paying?

**Staff:** Yes, check that everything is correct.

**You:** Got it. If I see an error, I'll ask for help rather than try random options.

**25–26 min：**朗读。**26–27 min：**换成 **wrong price on screen**，先说现象，再问 **What should I do next?**。不自行假定自助收银机的具体按钮。

### 27–30 min | Ride-hailing：找不到指定上车点

**Driver:** I'm at the pickup point shown in the app.

**You:** I'm near the mall entrance. Could you tell me what landmark I should look for?

**Driver:** Please check the pickup instructions in the app.

**You:** Okay. I'll check the signs first, then follow the route shown.

**Driver:** Thanks.

**You:** If I still can't find it, I'll send you a message through the app.

**27–28 min：**朗读两轮。**28–29 min：**替换 **mall entrance → office lobby**，**pickup point → taxi stand**。**29–30 min：**脱稿说 **where I am → what to look for → first/then → if lost**，40 秒口述加 20 秒自检。遵守实际平台及安全上车要求。

## 30–35 min | Practical Singapore Errands

### 30–33 min | Scene 9：线上预约后，下一步是什么？

**You:** Hi, I've completed an appointment request, but I'm not sure what happens next.

**Staff:** Please check the instructions and status in the official portal.

**You:** Should I wait for a confirmation before going in person?

**Staff:** Follow the confirmation requirements shown for your appointment.

**You:** Okay. If I don't receive any confirmation, where can I find the support contact?

**Staff:** Please use the official support information.

**You:** Thanks. I'll check the status first and contact support if needed.

**30–31 min：**朗读。**31–32 min：**按 **submitted → check status → confirmation → support** 复述。**32–33 min：**替换成 **bank appointment**，说出三个问题：**What's next? / Do I need to wait for confirmation? / Where can I get help?** 不把虚构流程当成实际办理规则。

### 33–35 min | Scene 10：取包裹时自提柜打不开

**You:** Hi, I've entered the collection code, but the locker didn't open.

**Support:** Please check the instructions in your collection message.

**You:** I checked the code once. Should I confirm the locker number before trying again?

**Support:** Please follow the service's instructions.

**You:** Understood. If it still doesn't work, what's the next support step?

**33–34 min：**朗读。**34–35 min：**脱稿说 **what I did → what failed → what to verify → who to contact**，最后 10 秒自检。不要向陌生人透露 OTP 或账户密码。

## 35–37 min | Accurate Grammar Corrections

**35–36 min｜先口头改前三句，再核对：**

1. ❌ **Can you walk through me the steps?** → ✅ **Can you walk me through the steps?**（walk + 人 + through + 事情）
2. ❌ **After click Save, check the result.** → ✅ **After clicking Save, check the result.** / **After you click Save, check the result.**（after 后可接动名词或完整从句）
3. ❌ **If the build will arrive today, I'll test it.** → ✅ **If the build arrives today, I'll test it.**（普通未来条件句用 if + 一般现在时）

**36–37 min｜复习两句：**

4. ❌ **I'm still waiting the test build.** → ✅ **I'm still waiting for the test build.**
5. ❌ **I should able to finish by Friday.** → ✅ **I should be able to finish by Friday.**

**正确替代，不是语法错误：** **First / Firstly** 都可以表示“首先”，口语里 **First** 更简洁；**Then / After that** 都能表示“接着”；**After clicking Save / After you click Save** 都正确。说 **When the build arrives, I'll test it** 表示预期会到；说 **If the build arrives, I'll test it** 更强调条件。

## 37–38 min | Compact Review

**37:00–37:30：**遮住右栏，把中文说成英文。**37:30–38:00：**看英文，为每句想一个自己的使用场景。

| 目的 | 复用句型 |
|---|---|
| 请求分步说明 | **Could you walk me through the steps?** |
| 问第一步 | **What should I do first?** |
| 问下一步 | **What happens after that?** |

| 确认检查节点 | **Should I check ___ before moving on?** |
| 卡住时求助 | **If I get stuck, who should I contact?** |

## 38–40 min | Final Speaking Challenges

### 38–39 min | Workplace：50 秒自由说 + 10 秒自检

提示：**QA can't always reproduce bug → ask exact steps → open build → sign in → tap Generate twice → check second tap → API pending → if ready today → ticket before 5**。

参考（先说后看）：

> **Could you walk me through the exact steps to reproduce the bug? So first I open the test build, then sign in with a test account, and after that I tap Generate twice. Should I check whether it gets stuck after the second tap? I'm still waiting for the API update. If it arrives today, I should be able to repeat the test and update the ticket before 5 p.m.**

自检：是否讲清 **顺序、关键检查点、依赖和截止时间**？

### 39–40 min | Everyday：50 秒自由说 + 10 秒自检

提示：**appointment request submitted → not sure next step → check portal → confirmation? → if none → support contact → no guessing**。

参考（先说后看）：

> **Hi, I've submitted an appointment request, but I'm not sure what happens next. Could you walk me through the next steps? Should I check the status in the official portal first? Do I need to wait for confirmation before visiting? If I don't receive one, where can I find the official support contact? Thanks, I'll check the instructions before taking any further action.**

自检：有没有 **问步骤、确认条件、避免猜测**？

**40 分钟完成。今天记住：Could you walk me through the steps? What should I do first, and what happens after that?**
