# Day 36 | Explaining a temporary workaround and the long-term fix

### Theme: 临时绕过问题不等于彻底解决——讲清当前可做什么、有什么限制、何时再更新

今天的新能力是区分 **workaround（临时替代办法）** 和 **permanent fix（长期修复）**。工程师在处理线上故障时需要这样说；在新加坡遇到预约、送货或服务暂时不可用时，也能用同样的沟通框架。

核心顺序：**problem → temporary option → limitation → permanent solution → next update**。

> **For now, we can use the previous version.**  
> 目前可以先使用旧版本。

> **That's a workaround, not a permanent fix.**  
> 这只是临时办法，不是彻底修复。

> **The trade-off is that some features won't be available.**  
> 代价是部分功能暂时不能用。

> **I'm still waiting for the backend fix.**  
> 我还在等后端修复。

> **If the fix passes testing, we should be able to release it by Friday.**  
> 如果修复通过测试，我们应该最迟周五能发布。

> **I'll keep you posted once we have a confirmed timeline.**  
> 时间确认后我会继续同步。

**严格计时：0–5 + 5–17 + 17–23 + 23–30 + 30–35 + 35–37 + 37–38 + 38–40 = 40 分钟。** 所有复述、纠错和参考答案均包含在相应时段内。

---

## 0–5 min | Warm-up：把“临时方案”和“最终方案”分开说

### 0–2 min | Read aloud

每句大声读两遍：

> **For now, we can turn off the new feature.**  
> 现在可以先关掉新功能。

> **That should keep the main flow working.**  
> 这样应该能让主流程继续运行。

> **It's only a temporary workaround.**  
> 这只是临时办法。

> **We still need to fix the root cause.**  
> 我们仍需解决根因。

> **I'll update the team by 3 p.m.**  
> 我最迟下午三点更新团队。

### 2–4 min | Three-part response

情境：新的图片上传功能不稳定。按三个步骤说：

1. **Temporary option:** For now, we can use the old uploader.
2. **Limitation:** The trade-off is that bulk upload won't be available.
3. **Next step:** We'll restore the new uploader once the fix passes testing.

第二轮将 **old uploader / bulk upload** 换成 **previous checkout flow / saved cards**，不看英文说完整三句。

### 4–5 min | Recall

将中文立即说成英语：

1. 这只是临时解决办法。
2. 我还在等最终修复。
3. 如果今天测试通过，我们应该能在周五发布。

参考：

> **This is just a temporary workaround.**  
> **I'm still waiting for the final fix.**  
> **If testing passes today, we should be able to release it on Friday.**

注意 **on Friday** 是周五当天；**by Friday** 是最迟周五。

# 5–17 min | Office Communication & Meetings

## 5–9 min | 场景 1：线上问题暂时无法彻底修复

**PM:** Users are still reporting problems with image upload. What can we do today?

**You:** The permanent fix isn't ready yet, but we have a workaround.

**PM:** What is it?

**You:** We can switch back to the previous uploader for now. That should let users upload one image at a time.

**PM:** What's the downside?

**You:** Bulk upload won't be available until we restore the new version.

**PM:** When can we do that?

**You:** I'm still waiting for the backend fix. If it passes testing today, we should be able to restore the new uploader on Friday.

**5–7 min：**分角色朗读两轮，第二轮只读 You。  
**7–8 min：**遮住 You 的台词，回答：What's the workaround? What's the downside? What's still pending?  
**8–9 min：**用 35–45 秒向 PM 独立汇报，必须包括 temporary / limitation / permanent。

可复用：

> **The permanent fix isn't ready yet, but we can ___.**

> **The downside is that ___.**

> **Once ___ is ready, we'll ___.**

**workaround** 不是“已修复”的同义词；要明确告知限制。

## 9–13 min | 场景 2：技术会议中评估回滚还是继续等待

**Tech Lead:** Should we leave the feature enabled while we investigate?

**You:** I wouldn't recommend that. The errors affect the checkout flow.

**Tech Lead:** What would you suggest?

**You:** We could roll back the latest change and keep investigating in staging.

**Tech Lead:** Would rolling back lose user data?

**You:** I haven't confirmed that yet. We need to check the data impact before making the change.

**Tech Lead:** Good point. What's next?

**You:** I'll check with the backend owner. If we confirm there's no data-loss risk, we can decide whether to roll back.

**9–11 min：**朗读，并找出已知事实和未知风险。  
**11–12 min：**替换 **checkout flow** 为 **login flow**，替换 **data-loss risk** 为 **session impact**，复述建议。  
**12–13 min：**只看 **impact → option → risk → verify**，做 40 秒说明。

核心句：

> **We could roll back the latest change.**  
> 我们可以回滚最新改动。

> **We need to check ___ before ___.**  
> 在……之前，我们需要检查……。

**rollback** 不一定零风险，不应承诺未经验证的“完全无影响”。

## 13–15 min | 场景 3：主动约定下一次更新，而不是消失

**Manager:** If we use the workaround, when will we hear from you again?

**You:** I'll send a status update by 4 p.m., even if the permanent fix isn't ready.

**Manager:** What will you include?

**You:** Whether the workaround is holding up, what remains blocked, and the next expected checkpoint.

**Manager:** Okay. Please keep the support team informed too.

**You:** Will do. If anything changes before 4, I'll update them sooner.

**13–14 min：**朗读对话。  
**14–15 min：**用自己的话说出三项更新内容：**current result / remaining blocker / next checkpoint**。

> **Even if the fix isn't ready, I'll send an update by 4.**  
> 即使修复还没好，我也会在四点前同步。

这是今天很实用的新结构：**even if** 强调“即便某条件没有满足，也会做这件事”。

## 15–17 min | Two-minute oral substitution drill

**15:00–15:40 | Temporary option：**每轮约十秒。

> **For now, we can use the previous version.**

替换为 **disable bulk upload / use the manual process / show a simpler form / pause the rollout**。

**15:40–16:20 | Limitation：**每轮约十秒。

> **The trade-off is that bulk upload won't be available.**

替换为 **users need one extra step / the page may load more slowly / the old layout will remain / automatic emails will be delayed**。

**16:20–17:00 | Conditional ETA：**每轮约十秒。

> **If the fix passes testing, we should be able to release it by Friday.**

替换为 **QA signs off today → release on Friday / the API is ready by noon → finish integration today / approval arrives before lunch → update the page this afternoon / monitoring looks normal → remove the workaround on Monday**。

# 17–23 min | Colleague Small Talk & Socializing

## 17–20 min | 场景 1：原计划因天气变化，临时换活动

**Colleague:** Are we still going for a walk after work?

**You:** I think it might rain. We could grab coffee nearby instead.

**Colleague:** That works. Do you still want to go for the walk another day?

**You:** Definitely. Coffee can be our backup plan for today.

**Colleague:** Shall we decide by 5?

**You:** Sounds good. If the weather clears up before 5, we can stick to the original plan.

**17–18 min：**朗读。  
**18–19 min：**将 **walk / coffee** 换成 **outdoor dinner / indoor food court**，练一次邀请。  
**19–20 min：**不看稿，用 30 秒说清 **original plan → backup plan → decision time**。

> **We could ___ instead.** = 我们可以改成……  
> **Let's keep ___ as a backup.** = 把……留作备选。  
> **We can stick to the original plan.** = 我们可以按原计划进行。

## 20–23 min | 场景 2：同事来不了聚餐，你帮他保留参与感

**Colleague:** I might be late for dinner. My meeting has been pushed back.

**You:** No worries. We can order first if you're okay with that.

**Colleague:** That would help. Could someone save me a seat?

**You:** Sure. I'm still waiting for the final headcount, but I'll let the organiser know.

**Colleague:** Thanks!

**You:** If you can get here by 7:30, you should still be able to join us for most of dinner.

**20–21 min：**分角色读。  
**21–22 min：**将 **dinner** 换为 **team coffee**，练习提出临时安排。  
**22–23 min：**遮稿复述：对方问题、你的替代办法、预计时间。

不要把社交安排说成过度正式的项目汇报；**No worries** 在此很自然。

# 23–30 min | Restaurant / Shopping / Ride-hailing

## 23–25 min | Restaurant：想点的菜没有了，问替代选择

**Staff:** Sorry, the grilled fish is sold out.

**You:** No problem. Is there something similar that's grilled rather than fried?

**Staff:** We have grilled chicken.

**You:** That works. Is it served with the same side dishes?

**Staff:** Yes, it is.

**You:** Great, I'll go with that.

**23–24 min：**朗读。  
**24–25 min：**换成 **iced tea is unavailable → iced lemon water**，询问价格或配菜的差别。

> **Is there something similar?** = 有类似的选择吗？  
> **What's different about it?** = 有哪些不同？

## 25–27 min | Shopping：缺货时先买替代款，但不放弃确认差异

**Staff:** The smaller charger is out of stock. This one is available.

**You:** Could I use this as a temporary replacement?

**Staff:** It should work with your device, but it's larger.

**You:** Does it have the same charging specification?

**Staff:** Let me check the label.

**You:** Thanks. I'd like to confirm compatibility before I buy it.

**25–26 min：**朗读。  
**26–27 min：**换成 **phone case / different model**，问清兼容性和限制。

示例不代表任何具体产品保证兼容；必须按实际型号和规格确认。

## 27–30 min | Ride-hailing：司机不能停原地点，换上车点

**Driver:** I can't stop at the main entrance. Could you come to the taxi stand?

**You:** Sure. Is that the taxi stand beside the car park?

**Driver:** Yes. I'll wait there.

**You:** Thanks. I'm still waiting for the lift. I should be there in about three minutes.

**Driver:** Okay.

**You:** If that pickup point becomes unavailable too, please message me through the app before you move.

**27–28 min：**朗读。  
**28–29 min：**把 taxi stand 换为 **sheltered pickup point**，复述新位置。  
**29–30 min：**独立说 30–45 秒：原地点不可用、替代地点、到达时间、司机再变化时如何通知。

上车前仍需按平台核对车辆与司机信息。

# 30–35 min | Practical Singapore Life Errands

## 30–33 min | 场景 1：维修需要等零件，先问临时方案

**Technician:** The replacement part won't arrive until next week.

**You:** Is there a safe temporary option we can use in the meantime?

**Technician:** For now, please leave the faulty unit switched off.

**You:** Understood. So we shouldn't use it until the part is replaced?

**Technician:** That's right.

**You:** Could you confirm the next appointment once the part arrives?

**Technician:** Yes, we'll contact you.

**30–31 min：**朗读。  
**31–32 min：**用 **temporary option → safety limitation → follow-up** 复述三句。  
**32–33 min：**练习把设备换成 **water heater**；不要自行提出不安全的绕过方案，临时使用方式应遵守专业人员指示。

> **In the meantime** = 在这段等待期间。  
> **Is there a safe temporary option?** = 有安全的临时安排吗？

## 33–35 min | 场景 2：线上申请系统暂时不可用

**You:** Hi, the online portal isn't letting me submit my document. Is there another way to submit it?

**Staff:** You can try again later. If it's urgent, contact the relevant service desk.

**You:** Understood. Does submitting it later affect the deadline?

**Staff:** Please check the deadline and submission instructions on your application.

**You:** Thanks. I'm still waiting for the portal to work again. If it isn't available by tomorrow, I'll contact the service desk before the deadline.

**33–34 min：**朗读。  
**34–35 min：**遮稿完成四句：说明故障、问替代渠道、确认截止日期、说明下一步。

实际机构是否接受其他渠道、是否延长期限，必须以官方答复为准。

# 35–37 min | Accurate Grammar Corrections

**35–36 min：**先口头纠正前三句，再看答案。

1. ❌ **It's only temporary solution.**  
   ✅ **It's only a temporary solution.**  
   单数可数名词 **solution** 在这里需要冠词。

2. ❌ **We can use the old version until the fix will be ready.**  
   ✅ **We can use the old version until the fix is ready.**  
   表示将来的时间从句中，**until** 后通常用一般现在时。

3. ❌ **I'm still waiting the backend fix.**  
   ✅ **I'm still waiting for the backend fix.**  
   **wait for + 事物**。

**36–37 min：**纠正后两句，并读三种正确的时间表达。

4. ❌ **If the tests will pass, we'll release it.**  
   ✅ **If the tests pass, we'll release it.**  
   普通未来条件句的 **if** 从句通常用一般现在时。

5. ❌ **We should can restore it on Friday.**  
   ✅ **We should be able to restore it on Friday.**

下面三句都正确：

> **We'll restore it by Friday.** = 最迟周五恢复。  
> **We'll restore it on Friday.** = 周五当天恢复。  
> **We'll restore it before Friday.** = 周五之前恢复。

# 37–38 min | Compact Review

**37:00–37:30：**遮住英文，根据左列开口。**37:30–38:00：**看英文，想一个对应场景。

| 目的 | 直接说 |
|---|---|
| 当前临时办法 | **For now, we can ___.** |
| 强调不是彻底修复 | **It's a workaround, not a permanent fix.** |
| 说明代价 | **The trade-off is that ___.** |
| 需要解决根因 | **We still need to fix the root cause.** |
| 提出回滚 | **We could roll back the latest change.** |
| 确认风险 | **We need to check ___ before ___.** |
| 等待后端 | **I'm still waiting for the backend fix.** |
| 条件化发布时间 | **If testing passes, we should be able to release it by Friday.** |
| 即使没修完也更新 | **Even if it isn't ready, I'll send an update by 4.** |
| 生活里的备选方案 | **Let's keep ___ as a backup.** |
| 维修安全 | **Is there a safe temporary option in the meantime?** |
| 三种时间区别 | **by Friday / on Friday / before Friday** |

最重要的区别：**A workaround reduces the impact; a permanent fix addresses the underlying problem.** 临时方案降低影响，最终修复解决底层问题。

# 38–40 min | Final Speaking Challenges

## 38–39 min | Workplace：解释回退方案

**38:00–38:50：**只看关键词，连续说 40–50 秒：**upload issue → previous uploader → one image at a time → bulk upload unavailable → waiting for backend → if testing passes → Friday**。

参考：

> **We're seeing errors with the new image uploader. For now, we can switch back to the previous version so users can upload one image at a time. The trade-off is that bulk upload won't be available. This is a workaround, not a permanent fix. I'm still waiting for the backend change. If the fix passes testing, we should be able to restore the new uploader on Friday. I'll send another update by 4 p.m., even if the fix isn't ready.**

**38:50–39:00：**自检：有没有说清限制，而不只是介绍好处？

## 39–40 min | Everyday：维修零件暂时缺货

**39:00–39:50：**看关键词说 40–50 秒：**part unavailable → safe temporary option → don't use unit → appointment → once part arrives → confirmation**。

参考：

> **I understand the replacement part won't arrive until next week. Is there a safe temporary option we can use in the meantime? If the unit needs to stay switched off, that's fine; I'd rather follow the safety instructions. Could you confirm the next appointment once the part arrives? I'd also appreciate an update if the delivery date changes. That way I can plan around the repair.**

**39:50–40:00：**自检：有没有问清临时安排是否安全，以及谁负责后续确认？

**40 分钟结束。** 今天要能自然说出：**“For now, we can..., but the trade-off is... We're still working on the permanent fix.”**
