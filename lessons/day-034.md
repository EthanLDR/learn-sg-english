# Day 34 | Picking up a conversation and confirming what has changed

### Theme: 隔了一段时间再接着聊，先对齐现状，再确认下一步

**收录说明：本课于 2026 年 10 月 6 日（新加坡时间）恢复网站更新时新编。它接在已收录的 Day 33 后面，不是 10 月 1–5 日原课程的补档，也不表示那些天已经完成学习。**

今天练习：项目讨论隔了几天、同事从休假回来、预约有变化时，如何自然地把话接起来，不凭旧印象继续推进。

核心顺序：**where we left off → what has changed → what is still pending → the next step**。

- 接上上次的话题：**Can we pick up where we left off?**
- 简短回顾：**Last time, we agreed to keep the first release small.**
- 确认变化：**Has anything changed since then?**
- 确认仍然有效的安排：**Are we still aiming for Friday?**
- 分清未决事项：**The only thing still pending is the API confirmation.**
- 确认下一步：**Just to confirm, I’ll handle the UI and you’ll check the API.**

继续复习：**I’m still waiting for... / should be able to / by / on / before / future if**。

计时建议：每个对话先分角色读一遍，再遮住 You 的台词自己回答。替换练习要开口，最后两分钟尽量不看参考答案。

---

## 0–5 min | Warm-up：用三句话把讨论接起来

### 0–2 min | Read aloud

每句读两遍，重点读清大写词；斜线只表示停顿，不需要念出来。

> Can we PICK UP / where we LEFT OFF?  
> 我们能接着上次的内容聊吗？

> Last TIME, / we agreed to keep the first release SMALL.  
> 上次我们同意先做一个范围较小的版本。

> Has anything CHANGED / since THEN?  
> 从那之后有什么变化吗？

> Are we STILL aiming for FRIDAY?  
> 我们仍然以周五为目标吗？

> I’m still WAITING for / the final API confirmation.  
> 我还在等最后的 API 确认。

### 2–4 min | Three-sentence restart

连续说三句，不要逐字翻译：

> Last time, we agreed to finish the core flow first. Has anything changed since then? If the scope is still the same, I should be able to finish by Friday.

替换内容再说两遍：

- finish the core flow → test the mobile layout
- the scope → the design
- by Friday → before the demo

### 4–5 min | Quick recall

把下面三个意思各说一句：

1. 我们接着上次的讨论聊吧
2. 上次讨论之后，有什么变化吗？
3. 我还在等设计确认

参考：

1. Can we pick up where we left off?
2. Has anything changed since our last discussion?
3. I’m still waiting for design confirmation.

**pick up where we left off** 是“从上次停下的地方继续”，不是重新从头开始。

# 5–17 min | Office Communication & Meetings

## 5–9 min | 场景 1：周会重新讨论一个暂停过的需求

**PM:**  
Can we go back to the saved-filters feature?

**You:**  
Sure. Can we quickly recap where we left off? Last time, we agreed to ship the core search flow first.

**PM:**  
That’s right. The core flow is live now, so we can start saved filters.

**You:**  
Got it. Has anything changed in the requirements since then?

**PM:**  
Yes. We only need one saved filter per user for the first version.

**You:**  
That makes the scope clearer. Are we still using the same API contract?

**PM:**  
I’ll confirm with the backend team.

**You:**  
Thanks. If we get that confirmed by noon, I should be able to give you an updated estimate this afternoon.

这里的关键不是立刻说 “I can finish today”，而是先确认旧条件是否仍然成立。

### Reusable patterns

> **Last time, we agreed to ___. Is that still the plan?**

> **Has anything changed in ___ since then?**

> **If we get ___ confirmed by ___, I should be able to ___.**

注意两个承诺不同：

- **give you an estimate** = 给你工期估算
- **finish the feature** = 完成功能

还没确认依赖时，可以承诺先给估算，不必直接承诺完成。

### 30-second role switch

现在你扮演 PM，用两句话解释变化：

> The core flow is live now. We only need one saved filter per user for the first version.

然后切回工程师，追问 API 是否也有变化。

## 9–13 min | 场景 2：同事休假回来，给他一个清楚的简报

**Colleague:**  
I’m back today. Could you catch me up on the checkout work?

**You:**  
Of course. The UI is done, and the main flow has passed testing. The only thing still pending is the timeout behaviour.

**Colleague:**  
Wasn’t that already fixed?

**You:**  
The original issue was fixed, but QA found a separate case on slower connections.

**Colleague:**  
What do you need from me?

**You:**  
Could you check whether the retry response includes an error code? I’ll handle the message shown in the UI.

**Colleague:**  
Sure. I’ll check it this morning.

**You:**  
Great. Just to confirm, you’ll check the API response, and I’ll update the UI once we know the result.

这里区分：

> **Could you catch me up on ___?**  
> 你能告诉我我错过了哪些进展吗？

> **Let me give you a quick update.**  
> 我来简单同步一下。

> **The only thing still pending is ___.**  
> 唯一还没确定／完成的是……

pending 可以指等确认、等处理或未完成。最好加上具体事项，避免只说 “It’s pending”。

### 45-second speaking drill

不看对话，按三个点给简报：

1. 已完成：UI and main-flow testing
2. 未完成：timeout behaviour
3. 分工：API response / UI message

参考开头：

> Here’s a quick update. The UI is done...

---

## 13–15 min | 场景 3：确认会议结论，避免各自理解不同

**Manager:**  
Let’s keep Friday as the target, but leave the advanced settings for later.

**You:**  
Just to make sure I’ve understood: we’re keeping the core flow in Friday’s release and moving the advanced settings to the next one. Is that right?

**Manager:**  
Yes. We still need QA to confirm the test plan.

**You:**  
Understood. I’m still waiting for that confirmation. If it comes through today, I should be able to finish testing before Friday.

**Manager:**  
Sounds good.

**You:**  
I’ll post the agreed scope and owners in the project thread after this meeting.

这是口语练习中的示例承诺。实际工作中只说自己确实能做到的动作。

可复用：

> **Just to make sure I’ve understood, ___. Is that right?**

> **What’s still outstanding?**

> **Who’s taking care of ___?**

**outstanding** 在这里指“尚未处理完的”，不是“优秀的”。

---

## 15–17 min | Two-minute oral substitution drill

### 第 1 分钟：回顾 + 确认

套用：

> **Last time, we agreed to ___. Is that still the plan?**

依次替换：

- test on staging before release
- keep the current design
- review the API contract together
- move the advanced settings to the next release

### 第 2 分钟：条件 + 下一步

套用：

> **If I get ___ by ___, I should be able to ___.**

依次替换：

- design confirmation / noon / update the page this afternoon
- the test results / Thursday / confirm the Friday release
- the error code / 2 p.m. / finish the error message today
- the final scope / tomorrow / give you a reliable estimate

说完后追问自己：这里承诺的是完成、确认，还是给估算？把动词说准确。

# 17–23 min | Colleague Small Talk & Socializing

## 17–20 min | 场景 1：同事回来，轻松地把聊天接起来

**You:**  
Hey, welcome back! How was your break?

**Colleague:**  
Good, thanks. It was nice to switch off for a few days.

**You:**  
Glad to hear it. Did you manage to get some rest?

**Colleague:**  
Yeah. Anything interesting happen while I was away?

**You:**  
Nothing too dramatic. A few of us tried a new lunch place nearby.

**Colleague:**  
Was it good?

**You:**  
Pretty good. We could go again sometime if you’re keen.

自然表达：

> **How was your break?**

> **Did you manage to get some rest?**

> **Anything interesting happen while I was away?**

> **If you’re keen, we could ___.**

“if you’re keen” 是自然的邀请方式，意思是“如果你有兴趣”。不需要为了听起来像新加坡英语而刻意添加 lah。

练习：把 lunch place 换成 café、walking route、weekend activity，各邀请一次。只用虚构练习信息，不必透露同事的私人情况。

---

## 20–23 min | 场景 2：几天前约过午饭，当天再确认

**You:**  
Are we still on for lunch at 12:30?

**Colleague:**  
Yes, but could we make it 12:45? My meeting might run over.

**You:**  
That works for me. Same place?

**Colleague:**  
Actually, the others would prefer somewhere closer to the office.

**You:**  
No problem. Let’s decide in the group chat before noon.

**Colleague:**  
Great. I’ll send a suggestion.

> **Are we still on for ___?**  
> 我们约好的……还照常吗？

> **Could we make it 12:45?**  
> 能改成 12:45 吗？

> **Same place?**  
> 还是同一个地方吗？

口语里 **Are we still on for lunch?** 比 “Is our lunch appointment still valid?” 自然得多；后者能理解，但日常约饭太正式。

遮住 You 的台词，再完成一轮：午饭改成 coffee，时间从 3:00 改成 3:15。

# 23–30 min | Restaurant / Shopping / Ride-hailing

## 23–25 min | Restaurant：确认订位变化

**You:**  
Hi, I’m calling about a booking for four at 7 p.m. Could I check whether it’s possible to change it to five people?

**Staff:**  
Let me check. Yes, we can do five, but the table will be indoors.

**You:**  
That’s fine. Is the time still 7 p.m.?

**Staff:**  
Yes.

**You:**  
Great. Just to confirm, that’s five people at 7, indoors. Thank you.

结构：

> **I’m calling about ___.**

> **Could I check whether it’s possible to ___?**

> **Just to confirm, that’s ___.**

练习：把 five people 换成 three people；把 indoors 换成 outside。这里的座位和变更政策都是练习情境，实际要由餐厅确认。

---

## 25–27 min | Shopping：回来取预留商品，确认是不是同一款

**You:**  
Hi, I spoke to someone earlier about a blue backpack. I was told one could be held until this evening.

**Staff:**  
Do you know which model it was?

**You:**  
Yes, the smaller one with the side pocket. Could you check whether it’s still available?

**Staff:**  
We have one here.

**You:**  
Thanks. Is this the same model we discussed? The strap looks different.

**Staff:**  
This is the newer version.

**You:**  
Got it. Could you show me what’s changed before I decide?

可以直接用：

> **I spoke to someone earlier about ___.**

> **Is this the same ___ we discussed?**

> **Could you show me what’s changed?**

**before I decide** 表示决定之前先确认，不是已经同意购买。

---

## 27–30 min | Ride-hailing：上车点变了，重新对齐位置

**Driver:**  
I can’t stop at the main entrance. Can you come to Pickup Point B?

**You:**  
Sure. Just to confirm, is that the covered pickup area beside the car park?

**Driver:**  
Yes, that’s the one.

**You:**  
Got it. I’m still waiting for the lift. I should be there in about three minutes.

**Driver:**  
Okay. I’m in the left-hand lane.

**You:**  
Thanks. I’ll check the car details in the app when I get there.

这里练两件事：

1. 用显眼地标确认位置，而不是只说 “I’m here”
2. 位置变化后复述新安排

替换练习：covered pickup area → side entrance / taxi stand / entrance beside the café。

安全提醒：实际上车前按平台提示核对车辆和司机信息；不需要在聊天里公开个人身份信息。

# 30–35 min | Practical Singapore Life Errands

## 30–33 min | 场景 1：维修预约前，确认零件和时段

**You:**  
Hi, I’m following up on the repair appointment. Last time, you mentioned that a replacement part was needed.

**Staff:**  
Yes. The part has arrived.

**You:**  
Great. Are we still scheduled for Thursday morning?

**Staff:**  
The technician is now available from 1 to 3 p.m. instead.

**You:**  
Thanks for letting me know. That time doesn’t work for me. Is there another morning slot?

**Staff:**  
We can offer Friday from 9 to 11.

**You:**  
Friday morning works. Could you send me the updated appointment details?

实用结构：

> **Last time, you mentioned that ___.**

> **Are we still scheduled for ___?**

> **Could you send me the updated details?**

注意：**scheduled for Friday** 是被安排在周五；**confirmed by Friday** 是最迟周五确认，意思不同。

遮住台词，尝试用 30 秒讲清楚：原计划、变化、你能接受的新时段。

---

## 33–35 min | 场景 2：补交材料后，问还缺什么

**You:**  
Hi, I uploaded the requested document yesterday. Could you check whether it’s been received?

**Staff:**  
Yes, I can see it here.

**You:**  
Thanks. Is anything else still outstanding?

**Staff:**  
No, that’s everything we need for now.

**You:**  
Understood. What happens next, and when would be a good time to check again?

**Staff:**  
We’ll review it and contact you if we need anything else. You can check again next week.

练习重点：

> **Has it been received?**

> **Is anything else still outstanding?**

> **What happens next?**

这段只是办事口语示例，不是任何机构的真实材料要求或处理时限。

# 35–38 min | Common Grammar Fixes

### 1 | 回顾过去，通常用过去时

❌ **Last time, we agree to keep the scope small.**  
✅ **Last time, we agreed to keep the scope small.**

这里说的是上一次已经发生的讨论，用 **agreed**。

### 2 | 询问从过去到现在的变化

❌ **Has anything change since then?**  
✅ **Has anything changed since then?**

结构：**has + 过去分词**。change 的过去分词是 changed。

> **Did anything change yesterday?**

这句也正确，问的是昨天那个已经结束的时间段。不要把所有 did 都当成错。

### 3 | 间接疑问句用陈述语序

❌ **Could you check whether is it still available?**  
✅ **Could you check whether it is still available?**

直接问：

> **Is it still available?**

嵌入 could you check whether 后面：

> **Could you check whether it is still available?**

### 4 | 复习 wait for 和 should be able to

❌ **I’m still waiting the confirmation.**  
✅ **I’m still waiting for confirmation.**

❌ **I should can finish today.**  
✅ **I should be able to finish today.**

### 5 | 条件与时间要说准确

❌ **If the scope will stay the same, I’ll finish by Friday.**  
✅ **If the scope stays the same, I should be able to finish by Friday.**

普通的未来条件句中，if 从句通常用一般现在时。这里 should be able to 还保留了“按目前情况应该能完成”的余地。

- **by Friday**：最迟周五；涉及具体截止时刻时再明确几点
- **on Friday**：周五当天
- **before Friday**：周五之前

# 38–40 min | Final Speaking Challenge

## 第 1 分钟：Workplace restart

只看关键词，讲 45–60 秒：

**last discussion → smaller scope → what changed → one pending item → who does what → by noon → estimate**

参考版本：

> Can we quickly pick up where we left off? Last time, we agreed to keep the first release small. Has anything changed in the requirements since then? The UI is ready, but I’m still waiting for the API confirmation. Just to confirm, you’ll check the response with the backend team, and I’ll handle the UI message. If we get the contract confirmed by noon, I should be able to give you an updated estimate this afternoon. Are we still aiming for Friday?

## 第 2 分钟：Everyday confirmation

关键词：

**repair appointment → part arrived → original morning slot → changed → alternative → written confirmation**

参考版本：

> Hi, I’m following up on the repair appointment. Last time, you mentioned that we were waiting for a replacement part. Has it arrived? I’d also like to check whether we’re still scheduled for Thursday morning. If the time has changed, could we find another morning slot? Friday morning would work for me. Once we agree on the time, could you send me the updated details?

自检三个点：

- 有没有区分“上次的结论”和“现在确认的新情况”？
- 有没有把尚未确定的事项说出来？
- 有没有清楚说明下一步、负责人或时间？

如果只剩 20 秒，优先说清楚变化和下一步，不必把全部背景重讲一遍。
