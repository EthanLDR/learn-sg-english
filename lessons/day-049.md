# Day 49 | Let's narrow it down: find out when a problem happens

### 今日主题：遇到问题，先缩小范围，再决定怎么处理

今天的新技能是 **describe → compare → rule out → agree on a next check**（描述现象 → 比较正常和异常情况 → 排除可能原因 → 确认下一步）。工程师排查 Bug、和 QA 对齐时特别实用；在新加坡遇到手机卡、支付、打车或预约问题时，也能避免一上来就猜原因。

> **It works on web, but fails on mobile.** Web 正常，移动端不行。
>
> **Does it happen every time or only sometimes?** 每次都会发生，还是偶尔？
>
> **Let's check whether it's related to the network.** 我们查一下是否和网络有关。
>
> **We haven't confirmed the cause yet.** 我们还没有确认原因。
>
> **What's the simplest thing we can check first?** 最容易先检查的是什么？

**重点区别：** **It fails on mobile** 是观察；**The network caused it** 是归因。没有证据时用 **It might be related to ...**，不要把猜测说成事实。复习 **I'm still waiting for / should be able to / by、on、before / 未来 if 条件句**。以下对话中的系统和服务流程均为口语模拟，实际以官方说明为准。

**准确计时 40 分钟：0–5（5）+ 5–17（12）+ 17–23（6）+ 23–30（7）+ 30–35（5）+ 35–37（2）+ 37–38（1）+ 38–40（2）= 40。** 每段的朗读、替换、自检都算入时间。

---

## 0–5 min | Warm-up：先说观察，不急着猜原因

**0–2 min｜四句各朗读三遍：**

> **What exactly isn't working?** 具体哪里不能正常使用？
>
> **It works sometimes, but not every time.** 有时正常，但不是每次都行。
>
> **Does it happen on Wi-Fi or mobile data?** 用 Wi-Fi 时发生，还是用移动数据时发生？
>
> **Let's check one thing at a time.** 我们一次检查一个因素。

**2–4 min｜两轮一分钟对话：**

**QA:** The upload failed again.

**You:** Does it fail every time?

**QA:** No, only with large files.

**You:** Got it. Let's compare a small file with a large one.

第一分钟分角色读；第二分钟换成 **login / a new account / an existing account**，说出 **It works with ___, but fails with ___.**

**4–5 min｜中文口译，随后核对：**

“我还在等错误日志。” → **I'm still waiting for the error logs.**

“如果中午前拿到，我应该能最迟四点给出初步结论。” → **If I get them by noon, I should be able to share an initial finding by 4 p.m.**

“我们还不知道是不是网络问题。” → **We don't know whether it's a network issue yet.**

## 5–17 min | Office Communication & Meetings

### 5–9 min | Scene 1：AI 图片上传失败，先找触发条件

**QA:** The image upload fails sometimes.

**You:** Does it happen on both web and mobile?

**QA:** I've only seen it on mobile so far.

**You:** Does it happen with every image, or mainly with larger ones?

**QA:** Mostly larger ones. Small images seem fine.

**You:** That's useful. Let's try the same image on both platforms and compare the results.

**QA:** Should we call it a mobile bug?

**You:** Not yet. We haven't confirmed the cause. I'm still waiting for the request logs.

**QA:** When can you update the ticket?

**You:** If the logs arrive by noon, I should be able to share our findings by 4 p.m.

**5–7 min：**分角色读两轮；第二轮遮住 You 的台词。**7–8 min：**脱稿回答：Where has QA observed the issue? Which images seem fine? What's still unknown? **8–9 min：**用 40–50 秒说：

> **So far, we've seen ___, but ___ seems to work. Let's compare ___ and ___. I'm still waiting for ___. If ___, I should be able to ___ by ___.**

**so far** = 到目前为止；**request logs** = 请求日志。观察到移动端出错，不代表根因一定在移动端。

### 9–13 min | Scene 2：会议中用对照法缩小问题范围

**Lead:** Why is the new settings page slow?

**You:** We're not sure yet. It loads normally with a test account, but it's slower with an account that has more data.

**Lead:** Could it be the rendering code?

**You:** Possibly, but let's not assume that. Could we compare the API time and the rendering time?

**Lead:** Good idea. Which should we check first?

**You:** Let's record both timings for the same steps, then see where the difference appears.

**Lead:** What if the API time is normal?

**You:** Then we can focus on the client side. If the API is slow, we'll look into that path first.

**9–11 min：**朗读两轮；第二轮换成 **search results page / short query / long query**。**11–12 min：**只看 **works → fails → two possible areas → evidence** 复述。**12–13 min：**脱稿说：

> **It works when ___, but slows down when ___. It might be related to ___, but we should compare ___ with ___ before deciding.**

**rendering time** = 前端渲染耗时；**client side** = 客户端侧。排查顺序是练习示例，不代表已发现真实根因。

### 13–15 min | Scene 3：和后端同事对齐下一步

**Backend engineer:** I couldn't reproduce the timeout in my environment.

**You:** Interesting. Are we using the same endpoint and test data?

**Backend engineer:** The endpoint is the same, but the data may be different.

**You:** Let's start with the same sample data and compare the requests.

**Backend engineer:** I'll prepare the sample.

**You:** Thanks. If you send it on Thursday, I should be able to rerun the test on Friday.

**13–14 min：**朗读；重点说 **Are we using the same ...?**。**14–15 min：**按 **difference → controlled comparison → owner → next test** 脱稿说 40 秒，再重读关键句 20 秒。

### 15–17 min | Timed oral substitution：12 轮，每轮 10 秒

**15:00–15:40｜A. 问触发范围（4 轮）**

模板：**Does it happen ___ or only ___?**

1. on both platforms / on mobile
2. every time / sometimes
3. with all images / with large images
4. on Wi-Fi / on mobile data

**15:40–16:20｜B. 比较正常与异常（4 轮）**

模板：**It works ___, but fails ___.**

1. on web / on mobile
2. with small files / with large files
3. with a test account / with an existing account
4. before login / after login

**16:20–17:00｜C. 条件与期限（4 轮）**

模板：**If ___, I should be able to ___ ___.**

1. the logs arrive by noon / share findings / by 4
2. QA replies on Monday / rerun the test / on Tuesday
3. I get the sample data today / narrow down the issue / before Friday
4. the API is ready by Thursday / check the flow / on Friday

每轮 **3 秒看关键词 + 7 秒完整说出句子**。**by Friday** 最迟周五；**on Friday** 周五当天；**before Friday** 周五之前。

## 17–23 min | Colleague Small Talk & Socializing

### 17–20 min | Scene 4：同事说某家店“总是排很久”

**Colleague:** That noodle place always has a long queue.

**You:** Even outside lunchtime?

**Colleague:** Actually, I usually go around noon.

**You:** Ah, maybe we could try a little earlier.

**Colleague:** Good idea. We can see whether the queue is shorter.

**You:** If it's still crowded, let's grab something nearby.

**17–18 min：**朗读。**18–19 min：**替换为 **coffee shop / after work / in the morning**，比较不同时间。**19–20 min：**遮稿说 **claim → ask when → propose small check → backup**，40 秒表达 + 20 秒重读。

**always** 表示“总是”；聊天中对方可能只是夸张说法。问 **Even outside lunchtime?** 是自然的补充信息，不需要当场纠正同事。

### 20–23 min | Scene 5：周末活动天气不稳定

**Colleague:** The weather might be bad this weekend.

**You:** Has the plan changed, or are we still deciding?

**Colleague:** We're still deciding.

**You:** Shall we check the forecast before confirming?

**Colleague:** Sure. We can decide on Friday.

**You:** Great. If the outdoor plan doesn't work, we could meet for coffee instead.

**20–21 min：**朗读。**21–22 min：**换成 **cycling / indoor badminton**。**22–23 min：**脱稿按 **what's confirmed → what's uncertain → when to check → alternative** 说 40 秒；最后 20 秒检查 if 从句。

## 23–30 min | Restaurant / Shopping / Ride-hailing

### 23–25 min | Restaurant：付款没有成功提示

**You:** Excuse me, I tried to pay, but I didn't see a confirmation.

**Staff:** Did the payment screen show an error?

**You:** No, it just went back to the order page. Could we check the order status before I try again?

**Staff:** Please show me the order reference.

**You:** Sure. I'd rather verify the status than risk paying twice.

**23–24 min：**朗读。**24–25 min：**换成 **self-service kiosk / no receipt**，练 **what happened → what didn't appear → safe next check**。付款状态不明时，先通过官方交易记录或商家确认，避免重复支付。

### 25–27 min | Shopping：商品只在某个连接方式下工作

**You:** Hi, this keyboard connects by cable, but Bluetooth isn't working for me.

**Staff:** Have you checked the setup instructions?

**You:** I have. Could we check whether the demo unit connects to another device?

**Staff:** Let's check what testing is available.

**You:** Thanks. That may help us narrow down the problem.

**25–26 min：**朗读。**26–27 min：**换成 **monitor / HDMI / another input**，说出两个对照条件；实际测试以店内规则为准。

### 27–30 min | Ride-hailing：司机和乘客看到的位置不同

**Driver:** The app says you're at Pickup Point C.

**You:** My screen shows Point B. Could we check whether we're looking at the same booking?

**Driver:** Please check the booking details in the app.

**You:** Okay. I'll confirm the pickup point shown on my side before moving.

**Driver:** Thanks.

**You:** If it still doesn't match, I'll use the app's support or messaging options.

**27–28 min：**朗读两轮。**28–29 min：**替换 **Point C / Point B → Exit A / Exit D**。**29–30 min：**脱稿说 **two different observations → check the same booking → safe next action**，40 秒表达 + 20 秒自检。不要求司机在非指定地点临时停车。

## 30–35 min | Practical Singapore Errands

### 30–33 min | Scene 9：手机卡能打电话但不能上网

**You:** Hi, I can make calls with this SIM, but mobile data isn't working.

**Support:** Are you using Wi-Fi right now?

**You:** Yes. Websites load on Wi-Fi, but not when I switch to mobile data.

**Support:** Please check the data settings and your plan's official instructions.

**You:** Understood. Where can I check whether mobile data is active on my plan?

**Support:** Please use the provider's official app or support channel.

**You:** Thanks. I'll check the status before changing any settings.

**30–31 min：**朗读。**31–32 min：**按 **what works → what fails → what to verify → official source** 复述。**32–33 min：**改成 **roaming while overseas**，问 **Is roaming active on my plan? / Where can I verify the setting? / What should I check next?** 具体漫游费率与开通方式以运营商为准。

### 33–35 min | Scene 10：预约确认邮件没到

**You:** Hi, I submitted an appointment request, but I haven't received an email.

**Support:** Please check the status in the official portal.

**You:** The request appears there, but it still says “pending.” Does that mean the appointment isn't confirmed yet?

**Support:** Please follow the status explanation shown in the portal.

**You:** Got it. I'll verify the status before submitting another request.

**33–34 min：**朗读。**34–35 min：**不看稿说 **request visible → email missing → status pending → next check**，最后 10 秒自检。**pending** 不等于 confirmed。

## 35–37 min | Accurate Grammar Corrections

**35–36 min｜先自己改三句，再核对：**

1. ❌ **Does it happens every time?** → ✅ **Does it happen every time?**（does 后用动词原形）
2. ❌ **It works in web, but not in mobile.** → ✅ **It works on the web, but not on mobile.**（常用搭配：on the web / on mobile）
3. ❌ **If I will get the logs, I'll check them.** → ✅ **If I get the logs, I'll check them.**（普通未来条件句用 if + 一般现在时）

**36–37 min｜两句复习：**

4. ❌ **I'm still waiting the results.** → ✅ **I'm still waiting for the results.**
5. ❌ **I should able to finish by Friday.** → ✅ **I should be able to finish by Friday.**

**正确替代，不是语法错误：** **Does it happen every time? / Is it happening every time?** 都正确，前者问一般规律，后者强调当前反复发生的情况。**It might be the network / It could be the network** 都能表达不确定猜测。**Finish by Friday / finish on Friday** 都正确，但时间含义不同。

**37:00–37:30：**遮住英文，根据中文口译。**37:30–38:00：**看英文，每句说一个自己的替换例子。

| 描述现象 | **It works ___, but fails ___.** |

## 38–40 min | Final Speaking Challenges

### 38–39 min | Workplace：50 秒自由说 + 10 秒自检

提示：**image upload → fails sometimes → mobile so far → small files okay → large files fail → compare same image on web and mobile → logs pending → if noon → findings by 4**。

先说 50 秒，再核对参考：

> **The image upload fails sometimes, but we haven't confirmed the cause yet. So far, we've only seen the issue on mobile. Small images seem to work, while larger images sometimes fail. I'd like to compare the same image on web and mobile and check the request logs. I'm still waiting for those logs. If they arrive by noon, I should be able to share an initial finding by 4 p.m.**

最后 10 秒自检：有没有区分 **观察与猜测、对照条件、下一步和期限**？

### 39–40 min | Everyday：50 秒自由说 + 10 秒自检

提示：**SIM → calls work → Wi-Fi works → mobile data fails → check plan status → official app → don't change settings at random**。

先说 50 秒，再核对参考：

> **Hi, I need help with my SIM. I can make calls, and websites work on Wi-Fi, but mobile data isn't working. I haven't confirmed whether it's a setting or a plan issue. Could you tell me where to check whether mobile data is active? I'll review the official instructions before changing anything. If the issue is still there, I'll contact support with the details. Thank you!**

最后 10 秒自检：是否说清 **什么能用、什么不能用、还不确定什么、下一步做什么**？

**40 分钟完成。今天最重要的一句：It works ___, but fails ___. Let's check one thing at a time.**
