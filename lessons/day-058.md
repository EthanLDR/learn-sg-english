# Day 58 | These two don't match: clarify discrepancies without blame

### 今日主题：两份信息对不上，怎样礼貌指出差异、核对来源，再决定下一步

今天的新技能是 **notice a mismatch → describe both versions → verify the source → agree on a correction**（发现不一致 → 说清两边分别写了什么 → 核实依据 → 确认如何处理）。昨天学的是“按顺序走流程”；今天练的是**流程中遇到两种说法时，不急着指责谁错了**。

> **These two values don't match.** 这两个数值对不上。
>
> **The document says Friday, but the calendar says Thursday.** 文件写周五，日历写周四。
>
> **Am I looking at the latest version?** 我看到的是最新版本吗？
>
> **Could we check which one is correct?** 我们能核实一下哪个才对吗？
>
> **Let's confirm the source before changing anything.** 修改前先确认权威来源。

**mismatch** = 不匹配；**discrepancy** = 信息、金额或记录之间的差异；**source of truth** = 团队约定的权威信息来源。**There seems to be a mismatch** 比 **You gave me the wrong information** 更中性。今天顺带复习 **I'm still waiting for / should be able to / by、on、before / if + 一般现在时**。所有场景均为模拟，不代表真实公司或新加坡机构的规则。

**总计严格 40 分钟：0–5（5）+ 5–17（12）+ 17–23（6）+ 23–30（7）+ 30–35（5）+ 35–37（2）+ 37–38（1）+ 38–40（2）= 40。** 朗读、替换、核对和自由表达都包含在对应时间段内。

## 0–5 min | Warm-up：先陈述两个事实

**0–2 min｜四句各朗读三遍，然后连起来说：**

> **I noticed a small difference.** 我发现一点不一致。
>
> **The ticket says one thing, but the design says another.** 任务单和设计稿写得不一样。
>
> **Could we compare the two versions?** 能对照一下两个版本吗？
>
> **I don't want to make assumptions.** 我不想凭猜测下结论。

**2–4 min｜两轮各一分钟，先读后遮住 You：**

**Colleague:** The demo is on Thursday, right?

**You:** That's what the calendar says, but the team message says Friday.

**Colleague:** Oh, I might have missed an update.

**You:** No worries. Let's check the latest invite before telling everyone.

第二轮改成 **demo → UI review**、**Thursday → Tuesday**、**Friday → Wednesday**，再自行补一句 **I'll confirm once we've checked.**

**4–5 min｜中文口译，再核对：**

“我还在等更新后的设计稿。” → **I'm still waiting for the updated design.**

“如果中午前收到，我应该能最迟四点确认差异。” → **If it arrives by noon, I should be able to confirm the difference by 4 p.m.**

“我们可以先确认哪份才是最新版吗？” → **Could we first confirm which version is the latest?**

## 5–17 min | Office Communication & Meetings

### 5–9 min | Scene 1：API 字段和文档对不上

**Backend engineer:** The image API is ready for integration.

**You:** Thanks. I noticed a mismatch between the sample response and the API document.

**Backend engineer:** Which part doesn't match?

**You:** The sample uses image_url, but the document lists imageUrl. Which field should the UI use?

**Backend engineer:** Let me check the latest contract.

**You:** Great. I'll avoid changing the mapping until we confirm the correct field.

**Backend engineer:** I'll update you when I've checked.

**You:** Thanks. I'm still waiting for that confirmation. If it arrives by noon, I should be able to update the mapping by 4 p.m.

**5–7 min：**读两轮；第二轮遮住 You，只看 Backend engineer 的台词回答。**7–8 min：**脱稿答：Which two sources differ? What exact fields appear? Why wait before changing the mapping? **8–9 min：**用 40–50 秒说：

> **I noticed a mismatch between ___ and ___. One says ___, but the other says ___. Could we confirm which is current? I'm still waiting for ___. If ___, I should be able to ___ by ___.**

**mapping** = 将 API 数据映射到前端所需字段。这里不假设任何一方一定错了；先查团队认可的最新接口契约。

### 9–13 min | Scene 2：设计稿和验收说明不一致

**PM:** Can you finish the settings page today?

**You:** I can work on it, but I found one difference we should resolve first.

**Designer:** What's different?

**You:** The approved ticket says the Save button stays visible. The latest mockup shows it only at the bottom.

**Designer:** I see. The mockup may not reflect the final decision.

**You:** Could we check the decision record and agree on the expected behaviour?

**PM:** Yes. Let's confirm it before you make the change.

**You:** Thanks. I'll update the UI after we agree, then link the decision in the ticket.

**9–11 min：**读两轮；第二轮把 **Save button → error message**、**stays visible → appears after submission**，说明不同之处。**11–12 min：**只看 **ticket → mockup → difference → source → next step** 复述。**12–13 min：**脱稿说：

> **The ticket says ___, whereas the mockup shows ___. I don't want to assume either is final. Could we check ___ and agree on ___ before I change the UI?**

**whereas** = 而、相比之下；这里用 **but** 也完全正确。**approved ticket** 和 **latest mockup** 可能代表不同维度，仍需核实哪条决定适用。

### 13–15 min | Scene 3：会议里两个截止日期冲突

**Lead:** QA expects the build on Friday.

**You:** Can I flag one discrepancy? The release checklist says the build is due on Thursday.

**Lead:** Good catch. Which date was confirmed most recently?

**You:** I'm not sure. Could we check the meeting notes before updating the plan?

**Lead:** Yes. Let's confirm the date with QA.

**You:** I'll keep the task open and update the ticket once the deadline is confirmed.

**13–14 min：**朗读，练 **Can I flag one discrepancy?**（可以指出一个差异吗？）。**14–15 min：**40 秒复述 **two dates → ask which is current → confirm with owner → update record**，20 秒重读：**Let's confirm before updating the plan.**

### 15–17 min | Timed oral substitution：12 轮 × 10 秒

**15:00–15:40｜A. 指出两个来源的差异（4 轮）**

模板：**The ___ says ___, but the ___ says ___.**

1. ticket / Thursday / calendar / Friday
2. document / imageUrl / sample / image_url
3. mockup / Save / ticket / Submit
4. chat / 3 p.m. / invite / 4 p.m.

**15:40–16:20｜B. 礼貌核实（4 轮）**

模板：**Could we check ___ before ___?**

1. the latest contract / updating the mapping
2. the approved mockup / changing the layout
3. the meeting notes / moving the review
4. the actual total / making another payment

**16:20–17:00｜C. 条件与期限（4 轮）**

模板：**If ___, I should be able to ___ ___.**

1. the contract arrives by noon / fix the mapping / by 4
2. QA replies on Monday / update the ticket / on Tuesday
3. the decision is confirmed today / finish the UI / before Friday
4. the review ends by Thursday / share the summary / on Friday

每轮 **3 秒读提示 + 7 秒完整大声说**，共 120 秒。**by Friday** = 最迟周五；**on Friday** = 周五当天；**before Friday** = 周五之前。

### 17–20 min | Scene 4：同事约饭，群消息与定位时间不一致

**Colleague:** Are we meeting at the food court at 12:30?

**You:** I thought so, but the latest message says 12:45.

**Colleague:** Maybe the time changed.

**You:** Could we check the group chat before heading over?

**Colleague:** Sure. I'll look for the most recent update.

**You:** Thanks. Once we confirm the time, I'll meet you there.

**17–18 min：**朗读两轮。**18–19 min：**换成 **coffee / 3:00 / 3:15**，练不责怪对方地指出差异。**19–20 min：**按 **two times → neutral question → check → friendly closing** 脱稿说 40 秒，最后 20 秒复读。

**I thought so, but ...** = 我原本也这么以为，不过……；**most recent update** = 最近一次更新。

### 20–23 min | Scene 5：周末活动的地点有两个版本

**Colleague:** See you at the sports hall on Saturday!

**You:** Looking forward to it! Just to check, which entrance are we using?

**Colleague:** Isn't it the main entrance?

**You:** The group message mentions the side entrance, so I wanted to confirm.

**Colleague:** Good point. I'll ask the organiser.

**You:** Thanks. If the location is confirmed by Friday, I'll check the directions before leaving.

**20–21 min：**朗读。**21–22 min：**替换 **sports hall → cinema**、**main entrance → lobby entrance**。**22–23 min：**按 **interest → discrepancy → ask organiser → plan** 说 40 秒，20 秒检查 **if + 一般现在时**。

## 23–30 min | Restaurant / Shopping / Ride-hailing

### 23–25 min | Restaurant：收据金额和点餐页面不一致

**You:** Excuse me, could you help me check this receipt?

**Staff:** Sure. What's the issue?

**You:** The order screen showed one total, but the receipt shows a different amount.

**Staff:** Let me compare the order details and any applicable charges.

**You:** Thank you. I'd like to understand the difference before making another payment.

**23–24 min：**朗读。**24–25 min：**换成 **one item missing from receipt**，说 **what you expected → what you see → request a check**。金额不同不一定是收费错误，先核对税费、选项及订单记录。

### 25–27 min | Shopping：货架价格与结账价格不同

**You:** Hi, I noticed the shelf label and the checkout price don't match.

**Staff:** Could you show me which item you're referring to?

**You:** Yes, it's this model. Could we check the product code and the current price?

**Staff:** Let's verify the label and the register details.

**You:** Thanks. I'll wait for the confirmed price before deciding.

**25–26 min：**读对话。**26–27 min：**替换 **price → warranty period**，练 **two sources → exact product → verify → decide**。标价与结账价不同时，不先断言原因或优惠适用性。

### 27–30 min | Ride-hailing：司机和乘客的上车点显示不同

**Driver:** My app shows Pickup Point A.

**You:** Thanks. My booking shows Pickup Point B, so the two locations don't match.

**Driver:** Please check the latest pickup instructions.

**You:** I will. Could we confirm the booking details through the app?

**Driver:** Sure.

**You:** If the locations still differ, I'll use in-app support rather than ask you to stop somewhere unsafe.

**27–28 min：**朗读两轮。**28–29 min：**替换 **Pickup Point A/B → Level 1/Level 2**。**29–30 min：**40 秒脱稿说 **two displays → verify booking → safe next step**；20 秒自检。以平台最新指引与安全上车点为准。

## 30–35 min | Practical Singapore Errands

### 30–33 min | Scene 9：手机套餐账单与原先查看的费用不同

**You:** Hi, I'd like to clarify a charge on my mobile bill.

**Support:** What seems different?

**You:** The monthly fee I saw in the plan summary doesn't match the amount on this bill.

**Support:** Please check the billing period and itemised charges in the official app.

**You:** Understood. Could you explain which line items account for the difference?

**Support:** Please use the provider's official billing support if you still need clarification.

**You:** Thanks. I'll compare the dates and charges before assuming there's an error.

**30–31 min：**朗读。**31–32 min：**用 **plan summary → bill → billing period → line items → official channel** 复述。**32–33 min：**换成 **home internet bill**，说三句：**These totals don't match. / Could we check the billing period? / Where can I see the itemised charges?** 实际费用以合同、账单和官方说明为准。

### 33–35 min | Scene 10：在线预约日期与邮件日期不同

**You:** Hi, my appointment page shows Tuesday, but the confirmation email says Wednesday.

**Support:** Please check the latest status in the official portal.

**You:** Could you help me identify which confirmation is current?

**Support:** Please use the official instructions or contact the responsible service channel.

**You:** Thanks. I'm still waiting for the status to update. I'll confirm the date before travelling to the appointment.

**33–34 min：**朗读。**34–35 min：**40 秒脱稿按 **portal → email → mismatch → official verification → next action** 复述，20 秒自检。不要仅根据旧邮件猜测实际预约日期。

## 35–37 min | Accurate Grammar Corrections

**35–36 min｜先独立修改前三句，再核对：**

1. ❌ **These two numbers doesn't match.** → ✅ **These two numbers don't match.**（复数主语用 don't）
2. ❌ **There is a different between the two versions.** → ✅ **There is a difference between the two versions.**（名词用 difference，形容词用 different）
3. ❌ **Could you explain me the difference?** → ✅ **Could you explain the difference to me?**（explain something to someone）

**36–37 min｜复习两句：**

4. ❌ **I'm still waiting the updated file.** → ✅ **I'm still waiting for the updated file.**
5. ❌ **If the confirmation will arrive today, I should able to finish by Friday.** → ✅ **If the confirmation arrives today, I should be able to finish by Friday.**（普通未来 if 从句用一般现在时；should be able to）

**正确替代，不算错误：** **These don't match / There's a mismatch / I noticed a discrepancy** 都自然；**Could we check which is correct? / Could we confirm the latest version?** 都正确；**I'll reply by Friday / on Friday / before Friday** 都正确，时间含义不同。**The document says X** 是自然表达，不必机械改成 **It is written in the document that X**。

If I still can't explain the amount, I'll contact the provider through its official support channel. Thank you.**
