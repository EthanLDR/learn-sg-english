# Day 78 | What makes you say that? Explain your reasoning with evidence

### 今日主题：别人问你为什么这样判断时，用事实、推断和验证计划说明理由

今天练 **claim → evidence → limitation → next check**（判断 → 证据 → 局限 → 下一步验证）。昨天练方案取舍；今天练让自己的建议有说服力，尤其是 AI Agent 评估和技术会议中的追问。

> **What makes you say that?** 你为什么这么判断？
>
> **I'm basing that on the test results.** 我的判断基于测试结果。
>
> **That suggests a possible issue, but it doesn't prove the cause.** 这提示可能有问题，但并不能证明原因。
>
> **As far as I can tell, the issue is limited to this case.** 据我目前判断，问题仅出现在这个场景。
>
> **What would change your mind?** 什么证据会让你改变看法？

**based on** = 基于；**suggest** = 提示（不一定证明）；**sample size** = 样本量；**so far** = 到目前为止。问 What makes you say that? 时语气要好奇而非质问。以下场景和数字均为虚构练习，不代表真实项目、商家或机构的情况。

**严格 40 分钟：0–5（5）+ 5–17（12）+ 17–23（6）+ 23–30（7）+ 30–35（5）+ 35–37（2）+ 37–38（1）+ 38–40（2）= 40。** 阅读、准备、朗读、替换及核对均计入对应时段。

## 0–5 min | Warm-up：判断不能只有结论

**0–2 min：**四句各朗读三遍，剩余时间连起来说。重读 evidence、suggests、yet。

> **Here's why I think so.** 这就是我这么想的原因。
>
> **Based on what we've seen so far, I'd test it again.** 根据目前观察到的情况，我会再测试一次。
>
> **We don't have enough evidence yet.** 我们暂时没有足够证据。
>
> **I could be wrong. Let's check.** 我可能判断错了，我们核实一下吧。

**2–4 min：**每轮一分钟；先分角色读，再遮住 You，把 slow search 换成 delayed notifications，调整理由。

**Lead:** Do you think the slow search is a client-side issue?

**You:** It's possible. The delay appears before the results are rendered.

**Lead:** Does that prove it's on the client?

**You:** No. We need timing data from both sides before drawing a conclusion.

**4–5 min：**先口译，再核对。

“我还在等性能测试结果。” → **I'm still waiting for the performance test results.**

“如果中午前拿到，我应该能最迟四点给出初步判断。” → **If I get them by noon, I should be able to share an initial assessment by 4 p.m.**

“你为什么这么判断？” → **What makes you say that?**

## 5–17 min | Office Communication & Meetings

### 5–9 min | Scene 1：AI Agent 评估中解释为什么暂不扩大上线范围

**PM:** Do you think the agent is ready for a wider rollout?

**You:** I'd recommend more evaluation first.

**PM:** What makes you say that?

**You:** In our sample, the agent completed most tasks, but it sometimes selected the wrong tool when the request was ambiguous.

**Lead:** How confident are you that this is a common problem?

**You:** Not very confident yet. Our sample is small. The result suggests a risk, but we don't know how often it occurs.

**PM:** What would you check next?

**You:** I'd test more ambiguous requests using approved cases. I'm still waiting for the expanded evaluation dataset. If it's ready by noon, I should be able to share an initial assessment by 4 p.m.

**5–7 min：**分角色朗读两轮，第二轮遮住 You。**7–8 min：**回答 What's the recommendation? What's the evidence? What's the limitation? **8–9 min：**40 秒脱稿，20 秒自检。

> **I'd recommend ___. I'm basing that on ___. However, ___. We need to check ___ before deciding.**

**ambiguous** = 有歧义的；**wider rollout** = 扩大上线范围；**assessment** = 评估判断。只用获准的测试数据，不把小样本结果当成整体成功率。

### 9–13 min | Scene 2：会议上区分观察到的现象和推断

**Lead:** The new tool handler seems slower. Do we know why?

**You:** We observed longer response times in the latest test run.

**Backend engineer:** Could it be the external service?

**You:** That's one possibility, but we haven't isolated the cause. I'd compare the tool execution time with the model response time.

**Lead:** What would change your assessment?

**You:** If the tool execution time stays stable across comparable runs, I'd investigate the other stages instead.

**Lead:** When can we review the findings?

**You:** If the traces arrive on Monday, I should be able to share a comparison by Tuesday.

**9–11 min：**朗读两轮；第二轮把 response time 换成 error rate，比较两个环节的错误记录。**11–12 min：**按 observation → hypothesis → evidence needed → update 复述。**12–13 min：**40 秒自由输出，20 秒核对。

> **What we observed is ___. One possible explanation is ___. To confirm that, we need ___.**

**isolate the cause** = 隔离并定位原因；**trace** = 调用链追踪记录；**hypothesis** = 待验证的假设。

### 13–15 min | Scene 3：Code Review 中追问技术建议的依据

**Reviewer:** I think this function needs a cache.

**You:** Could you explain what led you to that conclusion?

**Reviewer:** I noticed repeated calls with identical inputs in the test trace.

**You:** That's useful evidence. Could we also check whether those responses are safe to reuse?

**Reviewer:** Good point. Let's verify the freshness requirements first.

**You:** Great. I'll document the findings before we decide.

**13–14 min：**朗读，重读 identical inputs、safe to reuse。**14–15 min：**40 秒脱稿提出一个技术追问，20 秒复读：**Could you explain what led you to that conclusion?**

**freshness** = 数据新鲜度；有重复调用不代表所有结果都适合缓存。

### 15–17 min | Timed Oral Substitution：12 轮 × 10 秒

**15:00–15:40｜A. 说明判断依据（4 轮）**

模板：**I'm basing that on ___.**

1. the evaluation results
2. the test logs
3. the latest design
4. the written confirmation

**15:40–16:20｜B. 说明证据的局限（4 轮）**

模板：**That suggests ___, but it doesn't prove ___.**

1. a timing issue / the root cause
2. a possible regression / which change caused it
3. a billing difference / that there's an error
4. a delivery delay / that the parcel is lost

**16:20–17:00｜C. 条件与期限（4 轮）**

模板：**If ___, I should be able to ___ ___.**

1. the dataset arrives by noon / review the cases / by 4
2. QA replies on Monday / update the report / on Tuesday
3. the documents arrive today / check the terms / before Friday
4. the traces arrive by Thursday / share the findings / on Friday

每轮 3 秒看提示 + 7 秒大声说，共 120 秒。**by Friday** 最迟周五；**on Friday** 周五当天；**before Friday** 周五之前。

## 17–23 min | Colleague Small Talk & Socializing

### 17–20 min | Scene 4：同事推荐午饭地点，自然追问理由

**Colleague:** You should try the fish soup at that food court.

**You:** Oh, really? What do you like about it?

**Colleague:** The broth is good, and the portions are generous.

**You:** Sounds nice. Have you been there recently?

**Colleague:** Yes, I went last week.

**You:** Great! I might try it today. Is it usually crowded at lunchtime?

**17–18 min：**朗读两轮。**18–19 min：**换成 spicy noodles、flavour、portion size。**19–20 min：**40 秒脱稿，从回应推荐到询问亲身体验，20 秒复读。

**What do you like about it?** 比直接问 Why? 更容易开启轻松聊天。

### 20–23 min | Scene 5：和同事交流对新加坡通勤的印象

**Colleague:** I find taking the MRT more convenient than driving to work.

**You:** What makes it more convenient for you?

**Colleague:** I live near a station, so I don't have to worry about parking.

**You:** That makes sense. My experience might be different depending on where I live.

**Colleague:** True. Are you comparing different neighbourhoods?

**You:** Yes. I'd like to try the commute during peak hours before deciding.

**20–21 min：**朗读。**21–22 min：**换成 taking the bus、walking distance，调整理由。**22–23 min：**40 秒说个人观察、追问和自己的验证计划，20 秒自检。

**That makes sense.** = 这样就说得通了；不代表所有人的情况都相同。

**Staff:** Sure, we can compare the two models.

**25–26 min：**朗读。**26–27 min：**换成 more energy-efficient，询问 energy rating 和 operating costs。区分销售推荐、可核实规格和保修承诺。

### 27–30 min | Ride-hailing：解释为什么选择某个下车点

**You:** I'd prefer the main entrance because it looks closer to where I'm going.

**Driver:** Is your destination in that building?

**You:** As far as I can tell, yes. Let me double-check the building name in the app.

## 30–35 min | Practical Singapore Errands

### 30–33 min | Scene 9：银行卡未收到，说明怀疑邮寄地址有误的依据

**You:** Hi, I haven't received my debit card. I think it may have been sent to an outdated address.

**Staff:** What makes you think that?

**You:** The address I saw in my account details was my previous mailing address.

**Staff:** We can check the relevant records after verification.

**You:** Thank you. I haven't confirmed where the card was delivered. Could you check the dispatch status and explain the options for securing or replacing the card?

**Staff:** We'll review the available options for your account.

**You:** Thanks. I'd also like to confirm my current mailing address through the appropriate process.

**30–31 min：**朗读。**31–32 min：**换成 a returned delivery notification，重新说明依据。**32–33 min：**40 秒脱稿向柜台说明观察、推断和希望核实的内容，20 秒自检。

**dispatch status** = 寄送状态；**outdated address** = 已过时的地址。若怀疑卡寄错，及时通过银行官方渠道询问停用或补发措施；不预设具体银行政策。

### 33–35 min | Scene 10：租房交接时，说明为什么对一项收费有疑问

**You:** Hi, I'd like to clarify this charge in the payment summary.

**Agent:** What seems to be the issue?

**You:** Based on the agreement I received, I wasn't expecting this additional amount.

**Agent:** Let's check the relevant clause and the calculation.

**You:** Thanks. I'm still waiting for the itemised breakdown. If I receive it today, I should be able to review it before Monday.

**33–34 min：**朗读。**34–35 min：**40 秒换成 a utility charge，说明书面依据并请求核对，20 秒自检。实际费用以合同及适用规定为准。

## 35–37 min | Accurate Grammar Corrections

**35–36 min：**先口头纠正前三句，再核对。

1. ❌ **What makes you to say that?** → ✅ **What makes you say that?**（主动语态 make + 宾语 + 动词原形）
2. ❌ **My conclusion is based in the results.** → ✅ **My conclusion is based on the results.**（这里表示判断依据，用 based on）
3. ❌ **We don't have enough evidences yet.** → ✅ **We don't have enough evidence yet.**（此处 evidence 为不可数名词）

**36–37 min：**复习两句。

4. ❌ **I'm still waiting the traces.** → ✅ **I'm still waiting for the traces.**
5. ❌ **If the dataset will arrive today, I should able to review it by Monday.** → ✅ **If the dataset arrives today, I should be able to review it by Monday.**（普通未来条件句用 if + 一般现在时；should be able to）

**正确替代，不算错误：** What makes you say that? / Why do you think so? 都正确；I'm basing that on the results / That's based on the results 都自然。Evidence suggests… / The results indicate… 都可用于表达证据支持的判断。By Monday / on Monday / before Monday 都正确，时间含义不同。

## 37–38 min | Compact Review

**37:00–37:30：**遮住英文，选四句中译英。**37:30–38:00：**任选三句替换为自己的工作或生活情境。

| 目的 | 可复用英语 |
|---|---|
| 追问理由 | **What makes you say that?** |
| 说明依据 | **I'm basing that on ___.** |
| 表达目前判断 | **As far as I can tell, ___.** |
| 说明局限 | **We don't have enough evidence yet.** |
| 区分提示和证明 | **That suggests ___, but it doesn't prove ___.** |

口诀：**Claim → Evidence → Limitation → Next check.**
