# Day 68 | Could you walk me through it? Follow instructions without missing a step

### 今日主题：遇到陌生流程时，怎样请对方一步步说明、确认前置条件，并判断事情是否真正完成

今天的新技能是 **ask for the steps → check the prerequisite → repeat the sequence → verify completion**（请对方说明步骤 → 核对前置条件 → 复述顺序 → 确认完成）。昨天练“暂时不知道时，先核实再答复”；今天练“听到了说明，但不确定怎样实际操作”。重点不是假装听懂，而是用简短问题避免漏步骤。

> **Could you walk me through the steps?** 可以带我一步步过一下流程吗？
>
> **What do I need to do first?** 我首先需要做什么？
>
> **Do I need to complete anything beforehand?** 我需要提前完成什么吗？
>
> **So first I check the build, then I run the tests. Is that right?** 所以先检查构建，再运行测试，对吗？
>
> **How can I tell when it's done?** 我怎么判断它已经完成？

**walk someone through something** = 带某人一步步理解或操作；**prerequisite** = 前置条件；**in order** = 按顺序；**confirmation** = 确认信息。注意 **submitted（已提交）**、**processed（已处理）** 和 **approved（已批准）** 不一定相同。本课不会假设新加坡银行、政府或平台的具体办理步骤；真实操作以官方页面指引为准。

继续自然复习 **I'm still waiting for / should be able to / by、on、before / if + 一般现在时**。所有对话均为练习示例；工作中使用获批环境，不公开内部凭据或真实客户数据。

**精确 40 分钟：0–5（5）+ 5–17（12）+ 17–23（6）+ 23–30（7）+ 30–35（5）+ 35–37（2）+ 37–38（1）+ 38–40（2）= 40。** 朗读、替换、口述及核对都计入各自时段。

## 0–5 min | Warm-up：不懂流程时，先问顺序

**0–2 min｜四句各朗读三遍，余下时间连成一段：**

> **I've never done this before.** 我以前没操作过这个。
>
> **Could you walk me through it?** 能带我过一遍吗？
>
> **Let me repeat the steps to make sure I've got them right.** 我复述一下步骤，确认没有理解错。
>
> **What should I check at the end?** 最后应该检查什么？

**2–4 min｜每轮一分钟；第一轮分角色读，第二轮遮住 You：**

**Colleague:** Have you used this test dashboard before?

**You:** Not yet. Could you show me where to start?

**Colleague:** First select the approved test environment, then open the latest run.

**You:** Got it. So I select the environment first and open the run afterward. How do I know I'm viewing the correct build?

第二轮替换 **test dashboard → design handoff page**、**latest run → latest approved design**，保留“先做什么—再做什么—如何核实”。

**4–5 min｜中文转英文，然后核对：**

“我还在等访问权限。” → **I'm still waiting for access.**

“如果今天拿到权限，我应该能最迟周四完成检查。” → **If I get access today, I should be able to finish the check by Thursday.**

“可以先解释一下第一步吗？” → **Could you explain the first step?**

## 5–17 min | Office Communication & Meetings

### 5–9 min | Scene 1：第一次接手 AI 功能的 QA 测试流程

**QA:** Could you verify the new AI response screen in the test environment?

**You:** Sure. I haven't used this test workflow before. Could you walk me through it?

**QA:** First, make sure you're on the approved test build. Then open the sample conversation and check the loading, success and error states.

**You:** So I confirm the build first, then check those three states. Do I need any special test data?

**QA:** Use only the approved sample conversation linked in the ticket.

**You:** Thanks. How should I record the results?

**QA:** Add the findings and build version to the ticket.

**You:** Got it. I'm still waiting for access. If it's granted by noon, I should be able to finish the first pass by 4 p.m.

**5–7 min：**分角色读两轮，第二轮遮住 You。**7–8 min：**脱稿回答：What comes first? Which states are checked? Where do the findings go? **8–9 min：**40 秒按模板口述，20 秒自检：

> **First I'll ___. Then I'll ___. I'll use ___ and record ___. I'm still waiting for ___. If ___, I should be able to ___ by ___.**

**first pass** = 第一轮检查，不代表全部测试通过；**approved test data** = 获准使用的测试数据。

### 9–13 min | Scene 2：API 联调前，先问清环境与操作顺序

**Backend engineer:** The endpoint is available for integration testing.

**You:** Great. Before I start, are there any prerequisites?

**Backend engineer:** You need access to the approved staging environment and the current API contract.

**You:** I'm still waiting for staging access. Once I have it, should I check the response format before wiring it into the UI?

**Backend engineer:** Yes. Compare the sample response with the contract and report any differences.

**You:** Understood. I'll verify the response first, update the mapping, and run the UI checks afterward.

**Backend engineer:** Exactly. Please don't share credentials in the ticket.

**You:** Of course. I'll use the approved access process and record only the relevant test findings.

**9–11 min：**朗读两轮；第二轮替换 **endpoint → upload endpoint**、**response format → error response**。**11–12 min：**按 **prerequisites → contract → mapping → UI checks** 脱稿复述。**12–13 min：**回答一个新问题：**What could go wrong if I skip the first step?**（如果跳过第一步可能有什么问题？）用 30 秒说原因，30 秒复述正确顺序。

**Once I have it, I'll…** = 一旦拿到，我就……；指未来时，**once** 从句通常用一般现在时。

### 13–15 min | Scene 3：会议结束时复述行动顺序

**Lead:** Let's make sure the release checklist is clear.

**You:** Could I run through the steps to check my understanding?

**Lead:** Please do.

**You:** First QA completes the agreed checks. Then the release owner reviews the evidence. Only after approval do we follow the approved deployment process. Is that correct?

**Lead:** Yes. Don't treat a completed test as release approval.

**You:** Understood. I'll document the sequence and owners in the ticket.

**13–14 min：**朗读并重读 **First / Then / Only after approval**。**14–15 min：**40 秒不看稿总结 **checks → owner review → approval → deployment**；20 秒补一句：**Testing complete doesn't automatically mean approved for release.**

### 15–17 min | Timed Oral Substitution：12 轮 × 10 秒

**15:00–15:40｜A. 请求说明流程（4 轮）**

模板：**Could you walk me through ___?**

1. the QA workflow
2. the design handoff
3. the API testing steps
4. the release checklist

**15:40–16:20｜B. 复述顺序（4 轮）**

模板：**So first I ___, then I ___. Is that right?**

1. check the build / run the tests
2. review the contract / update the mapping
3. select the item / confirm the price
4. open the official portal / check the status

**16:20–17:00｜C. 旧句型：条件与期限（4 轮）**

模板：**If ___, I should be able to ___ ___.**

1. access arrives by noon / run the first test / by 4
2. QA replies on Monday / update the ticket / on Tuesday
3. the instructions arrive today / complete the form / before Friday
4. the review finishes by Thursday / send the summary / on Friday

每轮 **3 秒看提示 + 7 秒说完整句**，共 120 秒。**by Friday** = 最迟周五；**on Friday** = 周五当天；**before Friday** = 周五之前。

**Colleague:** Want to join us for lunch at the hawker centre?

**You:** Sure! I've never been to that one. How does our lunch plan work?

**Colleague:** We'll meet in the lobby, walk over together, then find seats.

**You:** Got it. So we meet in the lobby first. Are we ordering separately?

**Colleague:** Yes, everyone can choose their own food.

**You:** Sounds good. If my call ends before 12:30, I'll meet you downstairs.

**17–18 min：**朗读两轮。**18–19 min：**替换 **hawker centre → café**、**lobby → main entrance**。**19–20 min：**40 秒脱稿说 **accept → where first → what next → condition**，20 秒复读。

**How does it work?** 是问流程的自然口语；和熟悉的同事交流不用过分正式。

**Colleague:** Of course. We'll explain the rules before we start.

**You:** Thanks. Is there anything I should bring beforehand?

**Colleague:** Just yourself. We'll confirm the venue in the group chat.

**You:** Great. I'm still waiting for my Friday schedule. I'll confirm before Thursday evening.

**20–21 min：**朗读。**21–22 min：**替换 **board-game night → badminton session**、**example round → warm-up routine**。**22–23 min：**40 秒脱稿说 **interest → ask for example → prerequisites → confirmation**，20 秒自检。对方在模拟对话里的回答不代表真实活动规则。

## 23–30 min | Restaurant / Shopping / Ride-hailing

### 23–25 min | Restaurant：自助点餐屏幕不熟悉

**You:** Hi, could you show me how to place an order on this screen?

**Staff:** Please follow the options shown. Choose the dish, review any add-ons, then check the total.

**You:** So I review the total before paying. How do I know the order went through?

**Staff:** Check the confirmation displayed by the ordering system.

**You:** Thank you. I'll confirm the order status before trying again.

**23–24 min：**朗读。**24–25 min：**替换成 **self-service drink kiosk**，练 **select → review → confirm**。页面未响应时，先核实订单与支付状态，避免重复支付。

### 25–27 min | Shopping：现场自提设备，问清领取和检查顺序

**You:** I'm here to collect a repaired device. Could you walk me through the collection process?

**Staff:** Please check your service reference and the collection instructions.

**You:** Should I inspect the device and review the paperwork before acknowledging receipt?

**Staff:** Please follow the store's stated handover procedure.

**You:** Understood. I'll check what I'm signing for first.

**25–26 min：**朗读。**26–27 min：**替换 **repaired device → online order**、**service reference → order reference**。练 **reference → inspect → acknowledge**，以门店实际要求为准。

### 27–30 min | Ride-hailing：第一次使用商场指定上车区

**You:** I've never used that pickup area. Could you show me how to get there?

**Colleague:** Let's follow the signs and the directions in the app.

**You:** So we check the pickup level first, then follow the marked route. Right?

**Colleague:** Yes. We'll check the booking details when we arrive.

**You:** If the location changes, we'll follow the app's updated instructions, not ask the driver to stop somewhere unsafe.

**27–28 min：**朗读两轮。**28–29 min：**替换 **another level → outside the mall**、**marked route → designated exit**。**29–30 min：**40 秒脱稿说 **ask directions → repeat steps → verify booking → safe fallback**，20 秒自检。

## 30–35 min | Practical Singapore Errands

### 30–33 min | Scene 9：线上地址更新，问清官方步骤和完成标志

**You:** Hi, I need to update an address, but I'm not sure which official process applies to my record.

**Support:** Please check the relevant agency's official instructions for your type of record.

**You:** Could you walk me through where to find the requirements and whether I need any documents beforehand?

**Support:** Please refer to the official eligibility, document and submission guidance.

**You:** Understood. After submitting, what confirmation should I look for to know whether the update is complete?

**Support:** Please check the status definitions and follow-up steps in the official service.

**You:** Thanks. I won't assume that submitting the form means the address has already changed.

**30–31 min：**朗读。**31–32 min：**按 **right authority → prerequisites → submit → completion proof** 复述。**32–33 min：**换成 **bank contact-address update**，说三句：**Which process applies? / What do I need beforehand? / How do I confirm completion?** 新加坡不同机构的地址变更规则可能不同，不把练习对话当作官方流程。

### 33–35 min | Scene 10：手机套餐开通后，确认是否真正生效

**You:** Hi, I've submitted a request to change my mobile plan. Could you explain how to check its status?

**Support:** Please use the provider's official account and billing instructions.

**You:** Is there a difference between the request being received and the new plan becoming active?

**Support:** Please follow the provider's official status definitions.

**You:** Thanks. I'm still waiting for confirmation. If the status updates today, I should be able to check the plan details before tomorrow.

**33–34 min：**朗读。**34–35 min：**40 秒脱稿说 **request sent → activation status → official confirmation → next check**，20 秒自检。实际费用、生效日期以运营商正式说明为准。

## 35–37 min | Accurate Grammar Corrections

**35–36 min｜先自己改前三句，再核对：**

1. ❌ **Could you explain me the first step?** → ✅ **Could you explain the first step to me?**（explain something to someone）
2. ❌ **What I should do first?** → ✅ **What should I do first?**（直接疑问句：should 在主语之前）
3. ❌ **After I will get access, I'll run the test.** → ✅ **After I get access, I'll run the test.**（普通未来时间从句用一般现在时）

**36–37 min｜复习两句：**

4. ❌ **I'm still waiting the instructions.** → ✅ **I'm still waiting for the instructions.**
5. ❌ **If the access will arrive today, I should able to finish by Friday.** → ✅ **If access is granted today, I should be able to finish by Friday.**（普通未来 if 从句用现在时；should be able to）

**正确替代，不算错误：** **Could you walk me through it? / Can you show me how it works?** 都自然；**What should I do first? / What's the first step?** 都正确；**After I get access / Once I have access** 都正确。**I'll finish by Friday / on Friday / before Friday** 都正确，但时间含义不同。间接问句 **Could you tell me what I should do first?** 也是正确语序，不要误改。

## 38–40 min | Final Speaking Challenges

### 38–39 min | Workplace：40 秒独立说 + 15 秒对照 + 5 秒自检

提示：**new AI screen QA workflow → approved build first → sample conversation → loading/success/error → record findings → access pending → if noon → first pass by 4**。

**38:00–38:40：**不看参考，向 QA 复述完整操作。**38:40–38:55：**快速核对参考的关键短语。**38:55–39:00：**确认顺序、数据来源和完成标准都明确。

> **Could you walk me through the QA workflow? Let me check that I've got it right. First I confirm the approved test build. Then I use the sample conversation to check the loading, success and error states. I'll record the findings in the ticket. I'm still waiting for access. If it's granted by noon, I should be able to finish the first pass by 4 p.m.**

### 39–40 min | Everyday：40 秒独立说 + 15 秒对照 + 5 秒自检

提示：**address update → unsure which official process → prerequisites and documents → submission → completion status → don't assume submitted means changed**。

**39:00–39:40：**不看参考，向官方客服确认流程。**39:40–39:55：**扫读参考的关键步骤。**39:55–40:00：**检查是否区分提交和完成。

> **Hi, I need to update an address, but I'm not familiar with the process. Could you show me where to find the official steps? I'd like to check which documents I need beforehand. After submitting, how can I confirm the update is complete? I understand that a submission acknowledgement doesn't necessarily mean the change has taken effect. Thank you.**

**40 分钟完成。今天最重要的一句：Could you walk me through the steps? Let me repeat them to make sure I've got them right.**
