# Day 47 | Just following up: check status and close the loop

### 今日主题：消息发出后，怎样礼貌跟进、更新进度并确认事情真正完成

今天的新技能是 **check in → share status → set the next update → close the loop**（礼貌询问 → 说明状态 → 约定下次更新 → 最终确认）。对前端 / 全栈工程师尤其有用：**sent**（发出了）不等于 **received**（对方收到了）；**in progress**（进行中）不等于 **done**（完成了）。在新加坡预约、取餐、打车时也是如此。

> **Just following up on the API request.** 跟进一下之前的 API 请求。
>
> **Have you had a chance to check it?** 你有空看过了吗？
>
> **I'm still waiting for confirmation.** 我还在等确认。
>
> **I'll get back to you by 3 p.m.** 我最迟下午三点回复你。
>
> **I'll confirm once it's done.** 完成后我会确认通知你。

**语气重点：**不需要连发 “Any update?”。先交代事情，再礼貌提问，最后说清你自己的下一步。**follow up on something** = 跟进某件事；**follow up with someone** = 向某人跟进；**close the loop** = 把结果反馈给相关人，让事情有始有终。

本课继续少量复习 **I'm still waiting for / should be able to / by、on、before / if + 一般现在时**，新加 **once / when + 一般现在时** 表示未来“一旦 / 当……时”。所有项目、人物和服务情境均为模拟练习；具体平台流程以实际说明为准。

**严格 40 分钟：0–5（5）+ 5–17（12）+ 17–23（6）+ 23–30（7）+ 30–35（5）+ 35–37（2）+ 37–38（1）+ 38–40（2）= 40。** 跟读、角色扮演、替换、自检全部计入。

## 0–5 min | Warm-up：跟进不是催促

**0–2 min｜四句各读三遍：**

> **Just checking whether you've seen my message.** 想确认一下你有没有看到我的消息。
>
> **No rush. I just wanted to check the status.** 不急，我只是想确认进度。
>
> **I haven't heard back yet.** 我还没有收到回复。
>
> **I'll let you know as soon as I have an update.** 一有进展我就告诉你。

**2–4 min｜两个一分钟对话循环：**

**Colleague:** Did QA confirm the fix?

**You:** Not yet. I'm still waiting for their feedback.

**Colleague:** When can we expect an update?

**You:** I'll follow up with QA and get back to you by 3 p.m.

第一分钟读两遍并交换角色；第二分钟把 **QA → backend**、**fix → API response**、**3 p.m. → 4 p.m.**，遮住 You 的台词再说。

**4–5 min｜中文口译，然后核对：**

“想跟进一下测试结果。” → **Just following up on the test results.**

“如果今天拿到反馈，我应该能最迟周五完成。” → **If I get the feedback today, I should be able to finish by Friday.**

“确认完成后我会通知你。” → **I'll let you know once it's confirmed.**

## 5–17 min | Office Communication & Meetings

### 5–9 min | Scene 1：向后端同事礼貌追问 API 状态

**You:** Hi, just following up on the API response for the settings page. Have you had a chance to check it?

**Backend engineer:** I've found the issue, but the fix isn't ready yet.

**You:** Thanks for the update. Do you have an estimated time for the next check?

**Backend engineer:** I should know more after the afternoon test.

**You:** Got it. I'm still waiting for the API before I can finish the UI integration.

**Backend engineer:** I'll message you when the test is done.

**You:** Thanks. If I get the updated API by 3 p.m., I should be able to finish the integration by 5 p.m. I'll confirm once I've tested it.

**5–7 min：**分角色读两轮；第二轮遮住 You 的话。**7–8 min：**不看稿回答：What has been found? What is not ready? What will you confirm after testing? **8–9 min：**口述 40–50 秒：

> **Just following up on ___. I'm still waiting for ___. If I get it by ___, I should be able to ___ by ___. I'll confirm once ___.**

**提示：** **estimated time** 是预估时间，不是硬性承诺；**next check** 是下一次查看状态的时间，不一定是修好时间。

### 9–13 min | Scene 2：会议结束，确保行动项有人跟进

**Lead:** We have three action items: update the UI, check the API, and confirm the test result.

**You:** Let me check the owners. I'll handle the UI. Who's following up on the API?

**Engineer:** I'll take the API item.

**You:** Great. And who will confirm the test result?

**QA:** I will. I'll share the result on Thursday.

**You:** Thanks. I'll send a short summary after the meeting.

**Lead:** Please keep everyone posted if anything changes.

**You:** Sure. I'll follow up with the owners and post one final update when the items are closed.

**9–11 min：**朗读两轮；第二轮将 **UI → upload screen**、**Thursday → Friday**。**11–12 min：**只看 **owner → next update → final confirmation** 复述会议结论。**12–13 min：**脱稿说：

> **I'll take care of ___. ___ will handle ___. We're expecting an update on ___. I'll send a summary and confirm when everything is done.**

**action item** = 行动项；**owner** = 负责人；**keep everyone posted** = 让大家及时知道进展。

### 13–15 min | Scene 3：自己没有新结果，也要给靠谱回复

**PM:** Any news on the mobile issue?

**You:** Not yet. I don't have a confirmed result, so I don't want to guess.

**PM:** When will you check again?

**You:** QA is reviewing it now. I'll follow up by 2 p.m.

**PM:** Could you update the ticket either way?

**You:** Sure. Even if it's still pending, I'll post the latest status and the next action.

**13–14 min：**朗读，注意 **either way** = 无论结果怎样。**14–15 min：**40 秒脱稿回答 **status → what is unknown → next check → communication**；最后 20 秒重复：

> **I don't have a confirmed answer yet, but I'll update you by ___.**

### 15–17 min | Timed oral substitution：12 轮，每轮 10 秒

**15:00–15:40｜A. 礼貌跟进（4 轮）**

模板：**Just following up on ___. Have you had a chance to check it?**

1. the API request
2. the design review
3. the test results
4. the access request

**15:40–16:20｜B. 承诺下一次更新（4 轮）**

模板：**I'm still waiting for ___. I'll get back to you ___.**

1. QA feedback / by 3 p.m.
2. the mockups / on Thursday
3. approval / before Friday
4. the API logs / by noon

**16:20–17:00｜C. 条件与结果确认（4 轮）**

模板：**If ___, I should be able to ___ ___. I'll confirm once it's done.**

1. the API arrives by noon / finish testing / by 4
2. QA replies on Monday / send the summary / on Tuesday
3. approval arrives today / prepare the build / before Friday
4. the design is ready by Thursday / update the page / on Friday

每轮 **3 秒看提示 + 7 秒完整说句子**，恰好 120 秒。**by Friday** = 最迟周五；**on Friday** = 周五当天；**before Friday** = 周五以前。

## 17–23 min | Colleague Small Talk & Socializing

### 17–20 min | Scene 4：确认午餐约定是否还有效

**You:** Hey, just checking—are we still on for lunch at 12:30?

**Colleague:** Yes! I'm just finishing a meeting.

**You:** No worries. Shall we meet at the office lobby?

**Colleague:** That works. I'll message you when I'm downstairs.

**You:** Sounds good. If my call runs late, I'll let you know before 12:30.

**17–18 min：**读两轮。**18–19 min：**替换 **lunch → coffee**、**12:30 → 3 p.m.**、**office lobby → café entrance**。**19–20 min：**遮稿说 **check plan → confirm place → give a next update**，40 秒口述、20 秒重说关键句。

**Are we still on for ...?** = 我们之前约的……还照常吗？常用且不生硬。

### 20–23 min | Scene 5：同事邀请后，暂时不能答复

**Colleague:** Are you joining the walk on Saturday?

**You:** I'd like to, but I haven't checked my schedule yet.

**Colleague:** No problem. When will you know?

**You:** I should be able to confirm by Friday evening.

**Colleague:** Great. Just drop a message in the group chat.

**You:** Will do. Thanks for checking in!

**20–21 min：**朗读。**21–22 min：**把 **walk → team dinner**、**Saturday → Friday**、**Friday evening → Thursday evening**。**22–23 min：**脱稿完成 **show interest → explain uncertainty → promise a clear reply**，最后 15 秒再读一句 **I'll confirm by ___.**

## 23–30 min | Restaurant / Shopping / Ride-hailing

### 23–25 min | Restaurant：点餐后迟迟没收到取餐通知

**You:** Excuse me, I'm just checking on my order. I haven't received a pickup notification yet.

**Staff:** Could you show me your order number?

**You:** Sure, it's A-18. Can you check whether it's still being prepared?

**Staff:** Let me check the order status.

**You:** Thanks. I'll wait for confirmation before collecting it.

**23–24 min：**朗读。**24–25 min：**换成 **drink order / B-12**，练 **check status → provide number → wait for confirmation**。不要推断餐点已经丢失或做错。

### 25–27 min | Shopping：确认预订商品能不能取

**You:** Hi, I'm following up on an item I reserved.

**Staff:** Do you have the reservation confirmation?

**You:** Yes. I'd like to check whether it's ready for collection.

**Staff:** Please let me check the status.

**You:** Thanks. If it isn't ready yet, when would be a good time to check again?

**25–26 min：**朗读。**26–27 min：**换成 **monitor / order reference**，重说 **reservation → collection status → next check**。是否支持预留、何时能取以实际商家说明为准。

### 27–30 min | Ride-hailing：司机还没有确认位置

**You:** Hi, just checking whether you can see the pickup point in the app.

**Driver:** Yes, I can see Pickup Point B.

**You:** Great. I'm near the lift lobby, but I haven't reached B yet.

**Driver:** Please follow the pickup instructions.

**You:** Got it. I should be there in about three minutes. I'll message you if I have trouble finding it.

**27–28 min：**朗读两轮。**28–29 min：**将 **Pickup Point B → Pickup Point A**、**three → five**。**29–30 min：**脱稿说 **check location → say current status → ETA → follow-up if needed**，40 秒口述加 20 秒自检。以平台指定、安全的上车位置为准。

## 30–35 min | Practical Singapore Errands

### 30–33 min | Scene 9：手机服务申请后确认是否已开通

**You:** Hi, I'm following up on my mobile service request. I've submitted the form, but I haven't received confirmation yet.

**Staff:** Please check the status through the provider's official channel.

**You:** Okay. Does the request status show whether the service is active?

**Staff:** Please follow the activation instructions for your plan.

**You:** Understood. If the status is still pending tomorrow, where should I ask for help?

**Staff:** You can use the support contact listed in the official app.

**You:** Thanks. I'll check there before submitting another request.

**30–31 min：**朗读。**31–32 min：**按 **submitted → no confirmation → check status → support** 复述。**32–33 min：**替换成 **home internet request**，独立问 **Has it been received? / Is it active yet? / Where should I follow up?** 实际激活方式以运营商规定为准。

### 33–35 min | Scene 10：预约提交了，但还没收到确认

**You:** Hello, I submitted an appointment request yesterday, but I'm still waiting for confirmation.

**Support:** Please check the appointment status in the official portal.

**You:** I will. If it's still pending, should I wait or contact support?

**Support:** Please follow the instructions shown for that status.

**You:** Thanks. I'll check the status first and won't submit a duplicate request without checking.

**33–34 min：**朗读。**34–35 min：**脱稿用 **what I submitted → what's missing → status check → safe next step** 说 40 秒，最后 20 秒核对。不要把“已提交”误认为“预约成功”。

## 35–37 min | Accurate Grammar Corrections

**35–36 min｜先自己改三句，再核对：**

1. ❌ **I'm following up the API request.** → ✅ **I'm following up on the API request.**（follow up on + 事情）
2. ❌ **I'll get back to you when I will hear from QA.** → ✅ **I'll get back to you when I hear from QA.**（这里 when 引导未来时间从句，用一般现在时）
3. ❌ **Has QA reply yet?** → ✅ **Has QA replied yet?**（现在完成时：has + 过去分词）

**36–37 min｜复习两句：**

4. ❌ **I'm still waiting the confirmation.** → ✅ **I'm still waiting for the confirmation.**
5. ❌ **I should able to send it by Friday.** → ✅ **I should be able to send it by Friday.**

**正确替代，不算语法错误：** **Have you had a chance to look at it? / Did you get a chance to look at it?** 都自然；**Just following up on... / I wanted to check on...** 都可用于礼貌跟进；**I'll get back to you by Friday / I'll reply on Friday** 都正确，但时间含义不同。**I'll let you know when I hear back** 与 **I'll let you know once I hear back** 都正确。

## 38–40 min | Final Speaking Challenges

### 38–39 min | Workplace：50 秒脱稿说 + 10 秒自检

提示：**API request → follow up politely → backend checking → QA pending → if updated API by 3 → integration by 5 → confirm after test**。

参考（先练再看）：

> **Hi, just following up on the API request for the settings page. Have you had a chance to check it? Thanks for the update. I'm still waiting for the updated API and QA confirmation. If I get the API by 3 p.m., I should be able to finish the UI integration by 5 p.m. I'll test it and confirm the result once it's done. If anything changes, I'll keep the team posted.**

自检：有没有**礼貌跟进、准确状态、条件式期限、最终确认**？

### 39–40 min | Everyday：50 秒脱稿说 + 10 秒自检

提示：**appointment request submitted → no confirmation → official portal → pending? → support → don't submit twice**。

参考（先练再看）：

> **Hello, I'm just following up on an appointment request I submitted yesterday. I'm still waiting for confirmation. Could you tell me where to check the status in the official portal? If it's still pending, should I wait or contact support? I'll check the instructions first before submitting anything again. Thank you for your help.**

自检：有没有区分**已提交**与**已确认**？有没有问清下一步？
