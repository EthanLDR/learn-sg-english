# Day 56 | What does done look like? Define success before you start

### 今日主题：接到任务或办理事情时，先问清楚“怎样才算完成”

今天的新技能是 **clarify the outcome → agree on a check → verify the result → confirm completion**（明确目标 → 约定检查方式 → 验证结果 → 确认完成）。昨天练的是把决定写下来；今天进一步练：**记录了任务，不等于完成了任务**。

> **What does done look like for this task?** 这件事做到什么程度才算完成？
>
> **How will we know it worked?** 我们怎样确认它生效了？
>
> **What should I expect to see?** 我应该看到什么结果？
>
> **Does this meet the acceptance criteria?** 这符合验收标准吗？
>
> **I'll confirm once I've checked the result.** 我检查结果后会确认。

工程词汇：**acceptance criteria**（验收标准）、**expected result**（预期结果）、**actual result**（实际结果）、**edge case**（边界情况）。日常生活不必说 acceptance criteria，换成 **What should happen next? / How do I know it's confirmed?** 更自然。

少量回顾 **I'm still waiting for / should be able to / by、on、before / 未来 if 条件句**。所有项目、对话及新加坡办事流程均为模拟练习，真实要求以公司规范或服务机构官方说明为准。

**严格 40 分钟：0–5（5）+ 5–17（12）+ 17–23（6）+ 23–30（7）+ 30–35（5）+ 35–37（2）+ 37–38（1）+ 38–40（2）= 40。** 每段朗读、替换、核对与自由表达均在规定时间内完成。

---

## 0–5 min | Warm-up：把“做完”说得更具体

**0–2 min｜四句各读三遍，剩余时间连起来说：**

> **What's the expected result?** 预期结果是什么？
>
> **What should happen after I tap Save?** 我点击保存后应该发生什么？
>
> **Let's test the normal flow and one edge case.** 我们测试正常流程和一个边界情况。
>
> **I'll let you know once I've verified it.** 我验证后会告诉你。

**2–4 min｜两轮各一分钟；第一轮跟读，第二轮遮住 You：**

**Lead:** Can you finish the upload flow today?

**You:** I can work on it. What would count as done?

**Lead:** Users should see a success message after a valid upload.

**You:** Got it. Should we also check what happens when the upload fails?

第二轮将 **upload → profile update**、**success message → updated profile**。最后自己补一句 **I'll confirm after testing both cases.**

**4–5 min｜中文口译后核对：**

“我还在等测试账号。” → **I'm still waiting for the test account.**

“如果今天拿到，我应该能最迟周五完成验证。” → **If I get it today, I should be able to finish verification by Friday.**

“我们怎么确认这件事真的完成了？” → **How will we know it's actually done?**

## 5–17 min | Office Communication & Meetings

### 5–9 min | Scene 1：前端任务的验收标准不够清楚

**PM:** Could you finish the image upload flow?

**You:** Sure. Before I start, could we clarify what done looks like?

**PM:** A user should be able to upload a valid image and see a preview.

**You:** Got it. What should happen if the file is too large?

**PM:** Show a clear message instead of leaving the page stuck.

**You:** So we need a successful upload, a preview, and a clear error state. Is that the full scope?

**PM:** Yes, for this version. QA still needs to verify it.

**You:** Thanks. I'm still waiting for the test account. If I get it by noon, I should be able to share a test build by 4 p.m.

**5–7 min：**分角色朗读两轮；第二轮只看 PM 的话说 You 的回答。**7–8 min：**脱稿回答：What are the three expected behaviours? Who still needs to verify? **8–9 min：**连续说 40–50 秒：

> **Before I start, what does done look like for ___? Should ___ happen when ___? So the expected results are ___ and ___. If ___, I should be able to ___ by ___.**

**验收标准要可验证。**“Make it better” 太笼统；“Show an error message for an oversized file” 才能实际检查。测试通过与发布批准依然是不同步骤。

### 9–13 min | Scene 2：会议上把模糊目标变成可检查结果

**Lead:** We need to improve the loading experience.

**You:** What problem are we trying to solve: users waiting too long, or users not knowing what's happening?

**Designer:** Mainly the second one. The screen looks frozen during generation.

**You:** Then could we agree on an expected behaviour? Maybe a visible loading state while the request is running.

**Lead:** That sounds reasonable. How would we verify it?

**You:** Let's test the loading, success, and failure states. We should also confirm that the loading state disappears when the request ends.

**Designer:** I'll share the approved wording.

**You:** Great. I'm still waiting for that wording. I'll update the UI once it's ready and ask QA to check the agreed cases.

**9–11 min：**朗读两轮；第二轮替换 **generation → search**、**loading state → progress indicator**。**11–12 min：**按 **problem → expected behaviour → three states → verification** 脱稿复述。**12–13 min：**口述 40–50 秒：

> **We want to solve ___. A successful result would be ___. We can check it by testing ___, ___, and ___. I'll ask QA to confirm the result.**

**loading / success / failure states** = 加载、成功、失败状态；**expected behaviour** = 预期行为。说清目标能减少返工，但具体实现仍需评审。

### 13–15 min | Scene 3：QA 说“可以了”，确认指的是哪一种“完成”

**QA:** The main flow passed in the latest build.

**You:** Good news. Did the large-file error case pass as well?

**QA:** Not yet. We're checking it this afternoon.

**You:** Thanks for clarifying. So the happy path has passed, but the full verification is still pending.

**QA:** Exactly. I'll update the ticket when the second case is done.

**You:** Great. I'll keep the task open until the agreed checks are complete.

**13–14 min：**朗读，重点区分 **happy path**（正常成功路径）与 **full verification**（完整验证）。**14–15 min：**40 秒按 **what passed → what hasn't → who verifies → when to close** 复述；最后 20 秒重复 **The main flow passed, but the full check is still pending.**

### 15–17 min | Timed oral substitution：12 轮，每轮 10 秒

**15:00–15:40｜A. 问什么叫完成（4 轮）**

模板：**What does done look like for ___?**

1. the upload flow
2. the settings page
3. the API integration
4. the onboarding screen

**15:40–16:20｜B. 询问可观察的结果（4 轮）**

模板：**What should happen when ___? We should see ___.**

1. the upload succeeds / a preview
2. the request fails / a clear error
3. the user saves changes / a confirmation
4. the search returns no items / an empty state

**16:20–17:00｜C. 条件与期限（4 轮）**

模板：**If ___, I should be able to ___ ___.**

1. the account arrives by noon / run the checks / by 4
2. QA replies on Monday / close the ticket / on Tuesday
3. the copy arrives today / finish the UI / before Friday
4. the API is ready by Thursday / verify the flow / on Friday

每轮 **3 秒看提示 + 7 秒大声说完整句子**，恰好 120 秒。**by Friday** = 最迟周五；**on Friday** = 周五当天；**before Friday** = 周五之前。

## 17–23 min | Colleague Small Talk & Socializing

### 17–20 min | Scene 4：同事邀请午餐，确认计划是否已敲定

**Colleague:** We're thinking of trying a new hawker centre for lunch.

**You:** Sounds good! Have we decided on the place and time yet?

**Colleague:** The place is set, but we're still choosing a time.

**You:** Got it. What time should I be ready if we go together?

**Colleague:** We'll confirm in the group chat before noon.

**You:** Perfect. If the time works for me, I'll join you.

**17–18 min：**朗读两轮。**18–19 min：**换成 **coffee / 3 p.m. / café entrance**，重新问哪些细节已确定。**19–20 min：**遮稿说 **interest → confirmed detail → missing detail → conditional reply**，40 秒表达、20 秒复读。

**Have we decided on ... yet?** 很适合轻松聊天，既不会显得催促，也能问清安排。

### 20–23 min | Scene 5：周末约运动，确认怎样才算报名成功

**Colleague:** Want to join badminton this Saturday?

**You:** I'd love to. Is there a limit on the number of players?

**Colleague:** We need to check the court booking first.

**You:** No problem. How will I know if my place is confirmed?

**Colleague:** We'll send the final player list in the group chat.

**You:** Thanks. I'm still waiting to confirm my schedule. If I'm free, I'll reply by Friday.

**20–21 min：**朗读。**21–22 min：**替换成 **board games / available seats / final list**。**22–23 min：**按 **interest → capacity → confirmation signal → reply deadline** 独立说 40 秒；20 秒检查语气。

## 23–30 min | Restaurant / Shopping / Ride-hailing

### 23–25 min | Restaurant：订单到底成功提交了吗？

**You:** Excuse me, I tapped Place Order, but I didn't see a confirmation.

**Staff:** Do you have an order number?

**You:** Not yet. How can I check whether the order went through?

**Staff:** Please check the order status or ask us to verify it.

**You:** Thanks. I'll confirm the existing order before trying again, so I don't order twice.

**23–24 min：**朗读。**24–25 min：**换成 **a drink order / no pickup number**，练 **action → expected sign → actual sign → safe check**。确认状态前不要重复下单或支付。

### 25–27 min | Shopping：购买前验证最重要的功能

**You:** I'm considering this monitor. My main requirement is connecting it to my laptop.

**Staff:** What connection does your laptop use?

**You:** USB-C. Could we check the official specifications to see whether this model supports the setup I need?

**Staff:** Let's review the connection details.

**You:** Great. I'll confirm compatibility before buying.

**25–26 min：**朗读。**26–27 min：**换成 **keyboard / Bluetooth compatibility**，练 **my requirement → how to verify → decision**。接口存在不保证所有视频、充电和扩展功能都支持，以具体规格为准。

### 27–30 min | Ride-hailing：确认行程究竟算不算结束

**Driver:** We've reached the destination shown in the app.

**You:** Thanks. Could I check the trip status in the app before I leave?

**Driver:** Sure.

**You:** It still shows the trip in progress. I'll follow the app's instructions and check again.

**Driver:** Okay.

**You:** If the status doesn't update, I'll use the platform's support channel rather than assume the trip has ended.

**27–28 min：**分角色读两轮。**28–29 min：**替换 **trip status → final fare**，练 **expected → actual → next check**。**29–30 min：**40 秒脱稿说 **what should happen → what's shown → safe next step**；20 秒自检。行程结束与收费以平台实际记录为准。

## 30–35 min | Practical Singapore Errands

### 30–33 min | Scene 9：银行开户申请已提交，怎样确认真正完成？

**You:** Hi, I've submitted an account application. How will I know when it's approved?

**Staff:** Please check the application status through the bank's official channels.

**You:** Thanks. Is an application reference number the same as approval?

**Staff:** Please refer to the status explanation and official confirmation.

**You:** Understood. I'll check what the status means instead of assuming submission is approval.

**Staff:** You can follow the bank's instructions for any next steps.

**You:** Great. Where should I check if I'm still waiting for confirmation?

**30–31 min：**朗读。**31–32 min：**按 **submitted → reference number → approval status → next action** 复述。**32–33 min：**换成 **debit card request**，问三句：**Has my request been received? / How will I know it's approved? / What should I expect next?** 不假设可当天领取或一定寄送；以银行实际说明为准。

### 33–35 min | Scene 10：手机套餐开通后，验证是否真的可用

**You:** Hi, the app shows my mobile plan as active, but I'd like to check whether everything is working.

**Support:** What have you tested so far?

**You:** Calls work, but I'm still waiting for mobile data to connect.

**Support:** Please follow the provider's official checks for data service.

**You:** Okay. What result should I expect after those checks?

**Support:** Use the official guidance and support channel if the issue continues.

**You:** Thanks. I'll report what works and what doesn't, rather than say the whole plan is broken.

**33–34 min：**朗读。**34–35 min：**脱稿说 40 秒 **status → working feature → failing feature → expected result → support**；20 秒自检。实际服务开通、费用及漫游设置以运营商官方说明为准。

## 35–37 min | Accurate Grammar Corrections

**35–36 min｜先自己改三句，再核对：**

1. ❌ **How we will know it worked?** → ✅ **How will we know it worked?**（直接问句：will + 主语）
2. ❌ **What should happens after I save?** → ✅ **What should happen after I save?**（should 后用动词原形）
3. ❌ **If QA will confirm it, I'll close the ticket.** → ✅ **If QA confirms it, I'll close the ticket.**（普通未来条件句：if + 一般现在时）

**36–37 min｜复习两句：**

4. ❌ **I'm still waiting the test account.** → ✅ **I'm still waiting for the test account.**
5. ❌ **I should able to finish it by Friday.** → ✅ **I should be able to finish it by Friday.**

**正确替代，不是语法错误：** **What does done look like? / How will we know it's done?** 都自然；**What should happen next? / What am I supposed to see next?** 都正确，后者更口语；**I'll check it on Friday / by Friday / before Friday** 都正确，但时间含义不同。

## 38–40 min | Final Speaking Challenges

### 38–39 min | Workplace：50 秒独立说 + 10 秒自检

提示：**image upload task → define done → valid upload shows preview → large file shows clear error → QA verification pending → test account pending → if noon → build by 4**。

先脱稿说 50 秒，再核对参考：

> **Before I start the image upload task, could we clarify what done looks like? For a valid image, the user should see a preview after uploading. If the file is too large, the app should show a clear error message instead of getting stuck. We should test both cases, and QA still needs to verify them. I'm still waiting for the test account. If I get it by noon, I should be able to share a test build by 4 p.m. I'll confirm once the checks are complete.**

最后 10 秒自检：是否说出 **成功标准、失败标准、验证人、依赖、期限**？

### 39–40 min | Everyday：50 秒独立说 + 10 秒自检

提示：**bank application → submitted → reference number → not necessarily approved → official status → next steps → no assumption**。

先脱稿说 50 秒，再核对参考：

> **Hi, I've submitted my bank account application and received a reference number. I'd like to understand what happens next. Does that number only confirm submission, or does it mean the application has been approved? How will I know when the process is complete? Could you tell me where to check the official status and any next steps? I'll wait for confirmation rather than assume the account is ready. Thank you for your help.**

最后 10 秒自检：有没有区分 **提交、受理、批准、实际可用**？

**40 分钟完成。今天最重要的一句：What does done look like, and how will we know it worked?**
