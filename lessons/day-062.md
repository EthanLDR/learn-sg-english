# Day 62 | It only happens when… Describe an intermittent problem clearly

### 今日主题：问题不是一直出现，怎样说清触发条件、发生频率和已经尝试过什么

今天的新技能是 **describe the symptom → identify when it happens → say how often → report what you've tried → agree on the next check**（描述现象 → 找触发条件 → 说明频率 → 汇报已尝试的方法 → 确认下一步）。昨天讨论了备用方案；今天练的是：**排查问题时，别只说 “It doesn't work”，要让别人听懂问题到底怎么出现。**

> **It only happens when I switch between tabs.** 只有切换标签页时才会出现。
>
> **It doesn't happen every time.** 不是每次都会发生。
>
> **I can reproduce it on my phone, but not on my laptop.** 我可以在手机上复现，但在笔记本上复现不了。
>
> **I've already tried restarting the app.** 我已经试过重启应用。
>
> **Could we narrow down what triggers it?** 我们能进一步缩小触发原因的范围吗？

**reproduce a bug** = 复现问题；**intermittent** = 间歇性发生；**trigger** = 触发条件；**narrow down** = 缩小排查范围。注意 **I can't reproduce it** 不等于 **the bug is fixed**。只分享允许用于排查的信息；不要在公开群聊里贴真实用户数据、密码或访问令牌。

旧句型穿插复习：**I'm still waiting for / should be able to / by、on、before / if + 一般现在时**。对话中的技术问题和新加坡服务情境均为模拟，具体处理以相关官方说明为准。

**准确计时 40 分钟：0–5（5）+ 5–17（12）+ 17–23（6）+ 23–30（7）+ 30–35（5）+ 35–37（2）+ 37–38（1）+ 38–40（2）= 40。** 朗读、替换、独立输出、核对都包含在各时段内。

## 0–5 min | Warm-up：别只说 It doesn't work

**0–2 min｜四句各读三遍，余下时间连起来说：**

> **The screen sometimes freezes after I tap Save.** 我点保存后，页面有时会卡住。
>
> **Does it happen every time?** 每次都这样吗？
>
> **It seems to happen only on mobile.** 看起来只有手机端会出现。
>
> **Let me check one more case before I conclude.** 我再检查一种情况，然后再下结论。

**2–4 min｜两轮各一分钟：第一轮分角色朗读，第二轮遮住 You。**

**QA:** The upload button isn't working for me.

**You:** Does it fail every time, or only with certain files?

**QA:** Only with larger files, as far as I can tell.

**You:** Got it. Could you share the file size and the steps you followed, using our approved test data?

第二轮替换 **upload button → search box**、**larger files → long search queries**。练习说“目前观察到的情况”，不把猜测说成确定结论。

**4–5 min｜中文转英文，然后核对：**

“这个问题不是每次都会出现。” → **The issue doesn't happen every time.**

“我还在等测试日志。” → **I'm still waiting for the test logs.**

“如果中午前拿到，我应该能最迟四点缩小排查范围。” → **If I get them by noon, I should be able to narrow it down by 4 p.m.**

## 5–17 min | Office Communication & Meetings

### 5–9 min | Scene 1：前端页面偶尔卡住，先弄清触发条件

**QA:** The settings page sometimes freezes after saving.

**You:** Thanks for flagging it. Does it happen every time?

**QA:** No. I've seen it twice today.

**You:** Were you on mobile or desktop when it happened?

**QA:** Mobile. I haven't reproduced it on desktop.

**You:** Okay. Could you share the exact steps and the test environment?

**QA:** I'll add them to the ticket.

**You:** Great. I'm still waiting for the logs. If they arrive by noon, I should be able to narrow down the cause by 4 p.m. I'll share what we've confirmed, not just my guess.

**5–7 min：**朗读两轮，第二轮遮住 You。**7–8 min：**不看稿回答：How many times? Which device? What evidence is missing? **8–9 min：**40 秒口述，20 秒自检：

> **The issue is ___. It happens ___, mainly when ___. So far, I can reproduce it on ___ but not on ___. I'm still waiting for ___. If ___, I should be able to ___ by ___.**

**as far as I can tell** = 就目前观察来看；**so far** = 截至目前。对偶发问题，观察次数少时不要轻易下绝对结论。

### 9–13 min | Scene 2：会议里汇报 AI 流式响应的间歇性问题

**Lead:** What's the status of the streaming response issue?

**You:** The response occasionally stops updating after the user switches tabs.

**Lead:** Can you reproduce it consistently?

**You:** Not yet. It happened three times in our approved test environment, but not in every run.

**Backend engineer:** Do we know whether the server stopped sending data?

**You:** We don't know yet. I'd like to compare the client events with the server-side test logs.

**Lead:** What's the next step?

**You:** I'll document the reproduction steps and ask the relevant owners to check the logs. I won't call it a backend issue until we have evidence.

**9–11 min：**朗读两轮；第二轮替换 **switches tabs → locks the screen**、**streaming response → upload progress**。**11–12 min：**按 **symptom → frequency → environment → unknown cause → next evidence** 复述。**12–13 min：**脱稿说：

> **The symptom is ___. It seems to happen when ___. We haven't confirmed whether ___ yet. To narrow it down, I'd like to check ___ and ___.**

**consistently** = 每次或稳定地；**client events** = 客户端事件。说 **We don't know yet** 是准确汇报，不是能力不足。

### 13–15 min | Scene 3：Code Review 中汇报“无法复现”

**Engineer:** I tried your steps, but I couldn't reproduce the issue.

**You:** Thanks for checking. Which browser and device did you use?

**Engineer:** Desktop Chrome with the current test build.

**You:** That helps. I saw it on a phone with the previous test build. Let's compare the environments before we close the ticket.

**Engineer:** Agreed. Can you add the version and steps?

**You:** Yes. I'll update the ticket today and mark the cause as unconfirmed for now.

**13–14 min：**朗读，重读 **couldn't reproduce / cause unconfirmed**。**14–15 min：**40 秒脱稿复述 **your environment → my environment → difference → next check**，20 秒再说：**Not reproducing a bug doesn't prove it's fixed.**

### 15–17 min | Timed Oral Substitution：12 轮，每轮 10 秒

**15:00–15:40｜A. 描述触发条件（4 轮）**

模板：**It only happens when ___.**

1. I switch tabs
2. I upload a large file
3. I reopen the page
4. the network connection drops

**15:40–16:20｜B. 说明频率和环境（4 轮）**

模板：**It happens ___ on ___, but I haven't seen it on ___.**

1. sometimes / mobile / desktop
2. occasionally / Android / iOS
3. twice a day / the test build / the stable build
4. after long sessions / my laptop / my phone

**16:20–17:00｜C. 条件与期限（4 轮）**

模板：**If ___, I should be able to ___ ___.**

1. the logs arrive by noon / investigate further / by 4
2. QA replies on Monday / reproduce it / on Tuesday
3. the test device arrives today / check the bug / before Friday
4. the report is ready by Thursday / share the findings / on Friday

每轮 **3 秒看提示 + 7 秒完整大声说**，共 120 秒。**by Friday** = 最迟周五；**on Friday** = 周五当天；**before Friday** = 周五之前。

## 17–23 min | Colleague Small Talk & Socializing

### 17–20 min | Scene 4：同事聊天，说明自己偶尔找不到会议室

**Colleague:** How are you finding the new office?

**You:** Pretty good! I still get lost sometimes when looking for meeting rooms.

**Colleague:** Really? Which area confuses you?

**You:** Mainly the rooms near the back corridor. It doesn't happen when I use the main entrance.

**Colleague:** I can show you the easier route after lunch.

**You:** That'd be great. Thanks for helping me figure it out!

**17–18 min：**读两轮。**18–19 min：**替换 **meeting rooms → pantry**、**back corridor → side entrance**。**19–20 min：**脱稿说 **friendly answer → occasional issue → where it happens → accept help**，40 秒输出、20 秒复读。

**I still get lost sometimes** = 我偶尔还是会迷路；不必把生活里的小麻烦说得像严重故障。

### 20–23 min | Scene 5：朋友问你手机导航准不准

**Colleague:** Does the map work well around here?

**You:** Most of the time, yes. But it sometimes points me to the wrong entrance.

**Colleague:** Does that happen everywhere?

**You:** No, mainly near large malls. I usually check the entrance signs as well.

**Colleague:** Good idea. Want me to show you the entrance for lunch?

**You:** Sure. If I finish my call before noon, I'll meet you there.

**20–21 min：**朗读。**21–22 min：**换成 **bus arrival estimate / crowded stations**，练 **most of the time → exception → workaround**。**22–23 min：**40 秒口述 + 20 秒自检，不把 **sometimes** 误说为 **always**。

**You:** I've noticed it mainly when I'm indoors. I'm not sure if that's the cause, though.

**Support:** Please follow the provider's official network checks.

**You:** Okay. I'm still waiting for the service status to update. If it changes today, I should be able to run another test before tomorrow.

**Support:** Please contact official support if the problem continues.

**33–34 min：**朗读。**34–35 min：**40 秒脱稿说 **working feature → failing feature → possible trigger → uncertainty → next test**，20 秒自检。不要将位置相关性直接当成已证实的原因。

## 35–37 min | Accurate Grammar Corrections

**35–36 min｜先改前三句，再核对：**

1. ❌ **It happen only when I switch tabs.** → ✅ **It happens only when I switch tabs.**（单数主语 it，一般现在时动词加 -s）
2. ❌ **I've already try restarting the app.** → ✅ **I've already tried restarting the app.**（现在完成时 have + 过去分词；try → tried）
3. ❌ **It doesn't happens every time.** → ✅ **It doesn't happen every time.**（doesn't 后用动词原形）

**36–37 min｜复习两句：**

4. ❌ **I'm still waiting the logs.** → ✅ **I'm still waiting for the logs.**
5. ❌ **If the logs will arrive today, I should able to check them by Friday.** → ✅ **If the logs arrive today, I should be able to check them by Friday.**（普通未来 if 从句用一般现在时；should be able to）

**正确替代表达，不算错误：** **It sometimes freezes / It freezes sometimes** 都自然；**I can't reproduce it / I haven't been able to reproduce it** 都正确，后者强调截至目前的尝试；**It happens only on mobile / It only happens on mobile** 都正确；**I'll check by Friday / on Friday / before Friday** 都正确，但时间含义不同。

## 38–40 min | Final Speaking Challenges

### 38–39 min | Workplace：40 秒脱稿 + 15 秒参考核对 + 5 秒自检

提示：**AI streaming response → stops after tab switch → not every time → three occurrences → test environment → client/server logs → no confirmed cause → logs pending → if noon investigate by 4**。

**38:00–38:40：**不看参考，向 Lead 汇报问题。**38:40–38:55：**快速对照参考。**38:55–39:00：**确认没有把怀疑说成已证实。

> **We've found an intermittent issue with the AI streaming response. It sometimes stops updating after the user switches tabs, but it doesn't happen every time. We've seen it three times in the test environment. We haven't confirmed the cause yet, so I'd like to compare the client events and server-side logs. I'm still waiting for the logs. If they arrive by noon, I should be able to investigate further by 4 p.m.**

### 39–40 min | Everyday：40 秒脱稿 + 15 秒参考核对 + 5 秒自检

提示：**banking app → usually logs in → sometimes freezes after verification screen → restarted app → report device/version/time → official support only → don't share OTP**。

**39:00–39:40：**不看参考，向客服描述情况。**39:40–39:55：**快速对照。**39:55–40:00：**检查是否说明症状、频率和已尝试步骤。

> **Hi, I'm having an intermittent problem with the banking app. Most of the time I can log in, but sometimes it freezes after the verification screen. I've already tried restarting the app, but the issue still happens occasionally. Could you tell me how to report the device type, app version and time of the issue through your official support channel? I won't share my password or OTP. Thanks for your help.**

**40 分钟完成。今天最重要的一句：It only happens when ___. It doesn't happen every time, and we haven't confirmed the cause yet.**
