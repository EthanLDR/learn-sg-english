# Day 61 | What's our backup plan? Prepare a fallback without overpromising

### 今日主题：原计划可能失败时，提前提出备选方案，并约定什么情况下启用

今天的新技能是 **name the risk → set a trigger → offer a fallback → confirm the next update**（说明风险 → 约定触发条件 → 提出备选方案 → 确认下次更新）。昨天练的是小范围试行；今天练的是：**如果 Plan A 没有按预期成功，怎么继续推进，而不是临时慌张？**

> **What's our backup plan if this doesn't work?** 如果这个方案行不通，我们的备选方案是什么？
>
> **If the API isn't ready by noon, we could use approved mock data for the internal demo.** 如果 API 到中午还没准备好，我们可以在内部演示中使用获准的模拟数据。
>
> **Let's agree on when to switch to Plan B.** 我们约定什么时候切换到 B 方案。
>
> **I'd rather flag the risk early than surprise everyone later.** 我宁愿提前提醒风险，也不想最后让大家措手不及。
>
> **I'll confirm the next step before we change the plan.** 改计划之前，我会先确认下一步。

**fallback / backup plan** = 备选方案；**trigger** = 触发条件；**workaround** = 临时绕行办法，未必能长期使用；**switch to Plan B** = 转向 B 方案。**could** 是提出一种可选方案，不代表已获批准；真正执行前要确认责任人和限制。今天简短复习 **I'm still waiting for / should be able to / by、on、before / 未来 if 条件句**。以下为模拟情境，涉及公司系统、订单或银行流程时遵守实际规则。

**严格 40 分钟：0–5（5）+ 5–17（12）+ 17–23（6）+ 23–30（7）+ 30–35（5）+ 35–37（2）+ 37–38（1）+ 38–40（2）= 40。** 每项朗读、替换、独立回答、对照和自检均包含在相应时段内。

## 0–5 min | Warm-up：先说主方案，再说触发条件

**0–2 min｜四句各读三遍；余下时间连起来说：**

> **Plan A is to finish the integration today.** A 方案是今天完成集成。
>
> **What if the dependency is delayed?** 如果依赖延期怎么办？
>
> **We could prepare a fallback for the demo.** 我们可以为演示准备一个备选方案。
>
> **Let's check again at noon before deciding.** 我们中午再核对一次，然后决定。

**2–4 min｜两轮各一分钟：第一轮分角色读；第二轮遮住 You。**

**Lead:** Are we ready for tomorrow's demo?

**You:** The UI is ready, but I'm still waiting for the updated API.

**Lead:** What if it doesn't arrive today?

**You:** We could use an approved mock response for the internal demo, but we should confirm that with the team first.

第二轮把 **updated API → final design copy**、**mock response → existing approved copy**；重复完整对话。重点把 **could** 说成“建议”，不要说成已决定。

**4–5 min｜中文转英文，然后核对：**

“我还在等测试结果。” → **I'm still waiting for the test results.**

“如果中午前收到，我应该能最迟下午四点更新大家。” → **If I get them by noon, I should be able to update everyone by 4 p.m.**

“如果今天不行，我们有备选方案吗？” → **If it doesn't work today, do we have a backup plan?**

## 5–17 min | Office Communication & Meetings

### 5–9 min | Scene 1：API 可能赶不上内部 Demo，提前准备 Plan B

**PM:** Can we still show the new upload flow in tomorrow's internal demo?

**You:** The UI is ready, but I'm still waiting for the final API response.

**PM:** Does that put the demo at risk?

**You:** It could. If the response isn't ready by noon, could we switch to an approved mock-data demo?

**PM:** Would the audience know it's simulated?

**You:** Definitely. We'd label it clearly and avoid presenting it as a working integration.

**PM:** Okay. Let's confirm with the demo owner before changing the plan.

**You:** Agreed. If the real API arrives by noon, I should be able to check the integration by 4 p.m. Otherwise, I'll report the blocker and the proposed fallback.

**5–7 min：**分角色朗读两轮；第二轮只看 PM，独立说 You。**7–8 min：**不看稿回答：What is ready? What's missing? What triggers Plan B? What must the audience know? **8–9 min：**连续说 40–50 秒：

> **Plan A is ___. I'm still waiting for ___. If ___ isn't ready by ___, could we ___? We'd make it clear that ___. I'll confirm the plan with ___ before proceeding.**

**mock data** = 模拟数据；**working integration** = 真正打通的联调。不能把模拟演示说成真实服务已完成，也不能擅自把未批准的数据或功能放到公开环境。

### 9–13 min | Scene 2：会上讨论备用方案的触发条件与负责人

**Lead:** Let's discuss the release risk. What happens if QA finds a blocking issue?

**You:** Could we agree on a decision point before the release meeting?

**QA:** We can share the test status by Thursday afternoon.

**You:** Great. If a release-blocking issue is still open then, I'd suggest holding the release rather than skipping the checks.

**Lead:** Who makes the final call?

**You:** Let's confirm the release owner and record the decision in the ticket.

**QA:** What should we do meanwhile?

**You:** We can prepare a status summary and the approved recovery options, but we shouldn't deploy a workaround without review.

**9–11 min：**朗读两轮；第二轮替换 **blocking issue → critical accessibility issue**、**Thursday afternoon → Friday morning**。**11–12 min：**只看 **risk → trigger → fallback → owner → record** 复述。**12–13 min：**独立口述：

> **If ___ is still open by ___, I'd suggest ___. Before doing that, we need ___ to confirm. I'll document ___ so everyone knows the next step.**

**hold the release** = 暂缓发布；**blocking issue** = 阻断发布的问题。**I'd suggest** 是建议，正式是否发布仍由授权负责人决定。

### 13–15 min | Scene 3：代码评审时区分临时方案与长期修复

**Engineer:** The loading state fails when the request takes too long.

**You:** Thanks for flagging it. Is there a safe short-term workaround?

**Engineer:** We could show a clearer timeout message, but the retry behaviour needs a separate review.

**You:** That sounds reasonable as a proposal. Let's confirm the expected behaviour and test it before changing the UI.

**Engineer:** And the longer-term fix?

**You:** I'll create a follow-up task so the workaround doesn't silently become the permanent solution.

**13–14 min：**朗读，练 **short-term workaround / longer-term fix**。**14–15 min：**用 40 秒复述 **immediate risk → temporary proposal → review → follow-up**；20 秒重复：**A workaround isn't automatically the final fix.**

### 15–17 min | Timed Oral Substitution：12 轮，每轮 10 秒

**15:00–15:40｜A. 询问备选方案（4 轮）**

模板：**What's our backup plan if ___?**

1. the API is delayed
2. the demo build fails
3. QA finds a blocker
4. the meeting runs over

**15:40–16:20｜B. 提出触发条件与选项（4 轮）**

模板：**If ___ by ___, we could ___.**

1. the API isn't ready / noon / use approved mock data
2. QA hasn't signed off / Thursday / hold the release
3. the design isn't final / Friday / review the existing version
4. the test build fails / 3 p.m. / reschedule the internal demo

**16:20–17:00｜C. 复习条件与期限（4 轮）**

模板：**If ___, I should be able to ___ ___.**

1. the API arrives by noon / test the integration / by 4
2. QA replies on Monday / share an update / on Tuesday
3. the copy arrives today / finish the UI / before Friday
4. the review finishes by Thursday / send the decision / on Friday

每轮 **3 秒看提示 + 7 秒完整大声说**，刚好 120 秒。**by Friday** = 最迟周五；**on Friday** = 周五当天；**before Friday** = 周五之前。建议句里的 **could** 不等于实际授权。

## 17–23 min | Colleague Small Talk & Socializing

### 17–20 min | Scene 4：和同事约午饭，热门食阁没座位怎么办

**Colleague:** Shall we try that busy hawker centre for lunch?

**You:** Sounds good! What if we can't find seats?

**Colleague:** We could try the quieter place across the road.

**You:** Nice. Let's check the seating when we arrive, then decide.

**Colleague:** Okay. We're leaving at 12:30.

**You:** Great. If my meeting finishes before 12:30, I'll join you. Otherwise, please go ahead.

**17–18 min：**读两轮。**18–19 min：**替换 **hawker centre → café**、**can't find seats → queue is too long**。**19–20 min：**40 秒脱稿说 **friendly acceptance → possible problem → backup → conditional plan**，20 秒复读。

**What if ...?** 是提出可能性，不是抱怨；**otherwise** = 否则。说 **Let's check first** 比凭空断定店里肯定没座位更自然。

### 20–23 min | Scene 5：周末活动下雨，提前讨论室内选项

**Colleague:** We're planning an outdoor walk on Saturday.

**You:** I'd love to join. Do we have an indoor option if it rains?

**Colleague:** We might go to a museum instead, but nothing's confirmed.

**You:** Sounds good. Could we agree on a time to make the call?

**Colleague:** We'll check the weather and update the group on Friday evening.

**You:** Thanks. I'll watch for the update before making my way there.

**20–21 min：**朗读。**21–22 min：**替换 **outdoor walk → picnic**、**museum → café**。**22–23 min：**40 秒说 **interest → weather risk → indoor fallback → decision time**；20 秒检查自己有没有把“可能”说成“已确定”。

## 23–30 min | Restaurant / Shopping / Ride-hailing

### 23–25 min | Restaurant：想点的菜售罄，询问替代选择

**Staff:** Sorry, this dish is sold out.

**You:** No problem. What would you recommend instead?

**Staff:** You can check the other dishes on the menu.

**You:** Thanks. I'd prefer something not too spicy. Could you tell me which options might suit that?

**Staff:** Let me check the options with you.

**You:** Great. I'll choose after confirming the ingredients.

**23–24 min：**朗读。**24–25 min：**换成 **drink unavailable / unsweetened alternative**，练 **accept change → state preference → ask alternative → verify**。如有过敏，应明确向店家核实配料与交叉接触风险。

### 25–27 min | Shopping：想买的型号没货，比较替代品而不是直接升级

**Staff:** That keyboard is out of stock.

**You:** Thanks for checking. Do you have an alternative with a similar layout?

**Staff:** We can compare the models that are available.

**You:** Great. I'd like to check compatibility and the return terms before choosing.

**Staff:** Let's look at the official specifications.

**You:** Thanks. If none of them meet my needs, I'll wait rather than buy the wrong one.

**25–26 min：**朗读。**26–27 min：**换成 **monitor / USB-C display support**，练 **essential requirement → alternative → check → decision**。可用不代表适用，先核对关键规格。

### 27–30 min | Ride-hailing：上车点人太多，不能临时要求危险停车

**Driver:** The pickup area is crowded.

**You:** Thanks for letting me know. Should I follow the alternate pickup option shown in the app?

**Driver:** Please check the app's current instructions.

**You:** Understood. If the original point is still available, I'll go there. Otherwise, I'll use an approved alternative shown in the app.

**Driver:** Okay, keep me updated through the app.

**You:** Will do. I won't ask you to stop outside the permitted area.

**27–28 min：**分角色读两轮。**28–29 min：**替换 **crowded → temporarily unavailable**、**alternate pickup → designated waiting area**。**29–30 min：**40 秒独立说 **problem → official fallback → conditional choice → safe update**；20 秒自检。实际上车点、等待费及更改方式以平台指引为准。

## 30–35 min | Practical Singapore Errands

### 30–33 min | Scene 9：银行申请未完成，先问可用的官方后续渠道

**You:** Hi, I've submitted an account application, but the status hasn't changed.

**Support:** Please check the latest status and instructions in the bank's official channel.

**You:** I'm still waiting for confirmation. If the application isn't processed by the date shown, what's the correct next step?

**Support:** Please follow the status-specific guidance or contact official support.

**You:** Understood. Is there an official alternative support channel if I can't use the app?

**Support:** Please refer to the bank's verified contact information.

**You:** Thanks. I'll keep the existing reference number and won't submit a duplicate application without guidance.

**30–31 min：**朗读。**31–32 min：**按 **pending status → trigger date → official fallback channel → avoid duplicate** 复述。**32–33 min：**替换为 **debit card delivery enquiry**，问三句：**What if the status doesn't change? / Is there another official contact option? / Should I keep the same reference number?** 不假设任何银行允许即时开户或现场取卡。

### 33–35 min | Scene 10：手机数据连不上，说明已检查内容并请求安全替代方案

**You:** Hi, calls work, but mobile data still isn't connecting.

**Support:** Have you checked the troubleshooting steps in the official app?

**You:** Yes. If the connection still doesn't work after those checks, what's the next approved step?

**Support:** Please use the provider's official technical-support guidance.

**You:** Thanks. Is there another verified way to contact support if I can't use mobile data?

**Support:** Please check the provider's published contact options.

**You:** Got it. I'll use an official channel and explain what I've already tried.

**33–34 min：**朗读。**34–35 min：**40 秒脱稿说 **what works → what fails → what you've tried → fallback support**；20 秒检查。不要通过未知链接或来电提供密码、验证码。

## 35–37 min | Accurate Grammar Corrections

**35–36 min｜先独立修改前三句，再核对：**

1. ❌ **What's our backup plan if the API will be late?** → ✅ **What's our backup plan if the API is late?**（普通未来条件句用 if + 一般现在时）
2. ❌ **We could to use mock data.** → ✅ **We could use mock data.**（could 后接动词原形）
3. ❌ **Let's discuss about the fallback.** → ✅ **Let's discuss the fallback.** / ✅ **Let's talk about the fallback.**（discuss 后直接接宾语；talk about 才用 about）

**36–37 min｜复习两句：**

4. ❌ **I'm still waiting the final response.** → ✅ **I'm still waiting for the final response.**
5. ❌ **I should able to reply by Friday.** → ✅ **I should be able to reply by Friday.**

**正确替代表达，不算错误：** **What's our backup plan? / What's our Plan B?** 都自然；**We could postpone it / We might need to postpone it** 都正确，语气和确定程度略有不同；**If it rains, we'll stay indoors / If it rains, we can stay indoors** 都正确。**We'll review it by Friday / on Friday / before Friday** 都正确，但时间含义不同。

## 37–38 min | Compact Review

**37:00–37:30：**遮住右栏，中文快速转英文。**37:30–38:00：**每句替换成一个自己的工作或生活场景。

| 目的 | 可复用英语 |
|---|---|
| 问备选方案 | **What's our backup plan if ___?** |
| 说明当前风险 | **I'm still waiting for ___.** |
| 设定触发条件 | **If ___ isn't ready by noon, ___.** |
| 提议选择 | **We could ___ instead.** |
| 约定决定时间 | **Let's decide by ___.** |
| 确认负责人 | **Who makes the final call?** |

## 38–40 min | Final Speaking Challenges

### 38–39 min | Workplace：40 秒脱稿 + 15 秒参考核对 + 5 秒自检

提示：**upload demo tomorrow → UI ready → API pending → if not by noon → approved mock-data internal demo → label simulated → get demo-owner approval → if API arrives → integration check by 4**。

**38:00–38:40：**不看参考，向 PM 提一个备选方案。**38:40–38:55：**快速核对参考。**38:55–39:00：**确认没有把模拟结果说成真实功能已完成。

> **The UI is ready for tomorrow's internal demo, but I'm still waiting for the final API response. What's our backup plan if it isn't ready by noon? We could use approved mock data, clearly label the demo as simulated, and confirm the change with the demo owner first. If the real API arrives by noon, I should be able to check the integration by 4 p.m. I'll keep everyone updated.**

### 39–40 min | Everyday：40 秒脱稿 + 15 秒参考核对 + 5 秒自检

提示：**weekend outdoor walk → rain risk → indoor alternative not confirmed → ask decision time → check group Friday evening → don't assume location**。

**39:00–39:40：**不看参考，向同事讨论周末备选计划。**39:40–39:55：**快速核对参考。**39:55–40:00：**检查是否分清“备选建议”和“已确认安排”。

> **I'd love to join the outdoor walk on Saturday. What if it rains? Could we keep an indoor option as our backup plan? Maybe a museum or café, depending on what everyone prefers. Let's agree on when to make the final call. I'll check the group chat on Friday evening before heading out, so I don't assume the original location is still confirmed.**

**40 分钟完成。今天最重要的一句：What's our backup plan if this doesn't work? Let's agree on when to switch and who makes the call.**
