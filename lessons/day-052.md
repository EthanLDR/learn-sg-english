# Day 52 | Who should I check with? Find the right owner and ask for help clearly

### 今日主题：刚到新团队或新环境，不知道该找谁时，如何自然开口

今天的新技能是 **give context → identify the right person → make a specific request → agree on the next step**（交代背景 → 找到合适负责人 → 提出具体请求 → 确认下一步）。特别适合新加坡入职第一周：申请开发环境权限、寻找项目负责人、问同事生活建议，以及办理电话卡、预约和购物问题。

> **I'm new to the team. Who should I check with about access?** 我刚加入团队，权限问题应该找谁？
>
> **Is this the right channel to ask about the test environment?** 测试环境的问题在这个频道问合适吗？
>
> **Could you point me in the right direction?** 能告诉我该找谁或往哪里查吗？
>
> **Could you introduce me to the person who owns this?** 能介绍负责这件事的人给我吗？
>
> **I'll share the details so they have enough context.** 我会把信息补齐，方便对方理解。

**owner** 在工程沟通里常指某项工作或系统的负责人，不一定是经理；**point me in the right direction** 表示“指个方向”，未必要求对方亲自解决。复习 **I'm still waiting for / should be able to / by、on、before / if + 一般现在时**。所有人物、项目、业务流程和服务规则都是模拟练习，实际以对应团队或机构说明为准。

**准确计时 40 分钟：0–5（5）+ 5–17（12）+ 17–23（6）+ 23–30（7）+ 30–35（5）+ 35–37（2）+ 37–38（1）+ 38–40（2）= 40。** 朗读、替换、自由表达和自检均包含在对应时段内。

---

## 0–5 min | Warm-up：问对人，比问一大堆更有效

**0–2 min｜四句各读三遍：**

> **Who should I speak to about this?** 这件事我应该找谁？
>
> **I'm not sure who owns this part.** 我不确定这部分归谁负责。
>
> **Could you tell me where to start?** 能告诉我从哪里开始吗？
>
> **Thanks. I'll reach out to them with the details.** 谢谢，我会带上具体信息联系他们。

**2–4 min｜两轮各一分钟：**

**Colleague:** Are you all set up for development?

**You:** Not quite. I'm still waiting for access to the test environment.

**Colleague:** Have you asked the platform team?

**You:** Not yet. Is there a specific person or channel I should contact?

第一轮分角色朗读；第二轮将 **test environment → design files**、**platform team → design team**，遮住 You 台词重新回答。练习时不要提供真实账户资料。

**4–5 min｜中文口译，随后核对：**

“我刚加入项目，不确定谁负责 API。” → **I'm new to the project, and I'm not sure who owns the API.**

“如果今天拿到权限，我应该能最迟周二跑通项目。” → **If I get access today, I should be able to get the project running by Tuesday.**

“能帮我找到正确的联系人吗？” → **Could you help me find the right contact?**

## 5–17 min | Office Communication & Meetings

### 5–9 min | Scene 1：入职后开发环境权限不齐

**You:** Hi, I'm getting my development environment ready. Could I ask a quick question?

**Teammate:** Sure. What's missing?

**You:** I can open the repository, but I don't have access to the staging environment yet.

**Teammate:** Access requests go through our internal support process.

**You:** Got it. Could you point me to the correct request form or channel?

**Teammate:** I'll send you the instructions.

**You:** Thanks. I'm still waiting for access. If it's approved by noon, I should be able to run the app locally and check the staging flow by 4 p.m.

**Teammate:** Sounds good. Let me know if the instructions aren't clear.

**5–7 min：**读两轮，第二轮遮住 You。**7–8 min：**脱稿回答：What works already? What's missing? What exactly did you ask for? **8–9 min：**用 40–50 秒表达：

> **I'm setting up ___. I can already ___, but I'm still waiting for ___. Who should I contact about ___? If ___, I should be able to ___ by ___.**

**staging environment** = 预发布或测试环境；**access request** = 权限申请。只走公司授权流程，不请求他人的密码或私下共享账户。

### 9–13 min | Scene 2：多人会议中，不清楚谁负责接口

**PM:** We need to confirm the error format before the UI work continues.

**You:** I can update the error handling, but I'm not sure who owns the API contract.

**Engineer:** The backend team maintains the endpoint.

**You:** Thanks. Is there a specific owner for the response schema, or should I ask in the backend channel?

**Engineer:** Please ask in the backend channel and link the ticket.

**You:** Will do. I'll include the current response and the fields the UI needs.

**PM:** When can we get an estimate?

**You:** If the API details are confirmed on Monday, I should be able to share the UI estimate on Tuesday.

**9–11 min：**读两轮；第二轮换成 **image upload endpoint / upload response fields**。**11–12 min：**按 **my responsibility → missing decision → correct channel → useful context** 复述。**12–13 min：**脱稿说：

> **I can own ___. I need clarification on ___. Should I check with ___ or ask in ___? I'll share ___ so the owner can respond.**

**API contract / response schema** = 接口约定 / 响应字段结构。问“谁负责”不是推卸责任，而是减少来回沟通。

### 13–15 min | Scene 3：在会议里明确由谁做下一步

**Lead:** Let's make sure the onboarding tasks don't get lost.

**You:** I can take the UI setup. Who's the best person to check with about the test data?

**Lead:** QA can help you find the approved sample data.

**You:** Great. I'll contact QA through the usual channel. Should I include the ticket number?

**Lead:** Yes, that will help.

**You:** Understood. I'll send the request today and update the ticket when I hear back.

**13–14 min：**读对话，找出 **your action → right contact → context → follow-up**。**14–15 min：**脱稿说 40 秒；最后 20 秒重复：**I'll include the ticket number so they have the context.**

### 15–17 min | Timed oral substitution：12 轮，每轮 10 秒

**15:00–15:40｜A. 找负责人（4 轮）**

模板：**Who should I check with about ___?**

1. staging access
2. the API contract
3. the design system
4. the QA test data

**15:40–16:20｜B. 找渠道并补上下文（4 轮）**

模板：**Is ___ the right place to ask about ___? I'll include ___.**

1. this channel / the UI build / the ticket link
2. the design channel / the mockups / the screen name
3. the support portal / account access / the request ID
4. the team chat / meeting notes / the meeting date

**16:20–17:00｜C. 条件与期限（4 轮）**

模板：**If ___, I should be able to ___ ___.**

1. access is approved by noon / run the tests / by 4
2. QA replies on Monday / update the ticket / on Tuesday
3. the design arrives today / finish the draft / before Friday
4. the API is ready by Thursday / share the demo / on Friday

每轮 **3 秒看提示 + 7 秒完整说句子**。**by Friday** = 最迟周五；**on Friday** = 周五当天；**before Friday** = 周五之前。

## 17–23 min | Colleague Small Talk & Socializing

### 17–20 min | Scene 4：刚认识同事，问午餐去哪儿方便

**Colleague:** Welcome to the team! How's your first week going?

**You:** Pretty good, thanks! I'm still getting familiar with the area.

**Colleague:** Have you tried the food court nearby?

**You:** Not yet. Could you point me toward a good lunch spot within walking distance?

**Colleague:** There are a few. I can show you on the map.

**You:** That would be great. Maybe we can grab lunch together sometime.

**17–18 min：**读两轮。**18–19 min：**换成 **coffee place / quiet spot to chat**。**19–20 min：**遮稿说 **friendly reply → what you don't know → specific request → invitation**，40 秒表达，20 秒复读。

**get familiar with** = 逐渐熟悉；**within walking distance** = 步行可达。问推荐时说明需求，比只说 “Where to eat?” 更自然。

### 20–23 min | Scene 5：同事邀请活动，但不知道组织者是谁

**Colleague:** A few of us are going for a walk this weekend. Want to join?

**You:** Sounds nice! Who's organizing it?

**Colleague:** A teammate is putting the plan together in a group chat.

**You:** Could you add me to the chat if that's okay?

**Colleague:** Sure. The details should be there.

**You:** Thanks! If my schedule is clear by Friday, I'll confirm before Saturday.

**20–21 min：**读对话。**21–22 min：**替换为 **badminton / booking a court**。**22–23 min：**40 秒脱稿完成 **show interest → ask organizer → join correct channel → confirm by when**；最后 20 秒自检。

## 23–30 min | Restaurant / Shopping / Ride-hailing

### 23–25 min | Restaurant：点餐台处理不了的问题，该问谁？

**You:** Excuse me, I'd like to check whether my order went through.

**Staff:** Could you show me the order confirmation?

**You:** Yes, here it is. I'm not sure if this is the right counter.

**Staff:** Let me check where you should ask.

**You:** Thanks. Could you point me to the correct pickup or help counter?

**23–24 min：**读对话。**24–25 min：**替换成 **missing item / order number**，练 **problem → reference → right counter**。避免在付款状态不明时直接重复支付。

### 25–27 min | Shopping：保修问题该联系店员还是品牌售后？

**You:** Hi, I have a question about the warranty for this monitor.

**Staff:** What would you like to know?

**You:** If something goes wrong later, should I contact the store or the manufacturer's support team?

**Staff:** Let's check the written warranty terms.

**You:** Great. Could you show me the official support contact?

**25–26 min：**读一遍并交换角色。**26–27 min：**换成 **keyboard / return policy**，练习 **Who should I contact if ___?** 实际售后责任以购买凭证及保修条款为准。

### 27–30 min | Ride-hailing：上车点不清楚，使用哪个沟通渠道？

**Driver:** I'm at the pickup point shown in the app.

**You:** I'm near the mall entrance, but I can't find the pickup point.

**Driver:** Please check the pickup instructions.

**You:** Got it. Is in-app messaging the best way to update you if I still can't find it?

**Driver:** Yes, please use the app.

**You:** Thanks. If I find the point by 6:30, I should be there before 6:35.

**27–28 min：**读两轮。**28–29 min：**换成 **office lobby / Pickup Point B**。**29–30 min：**脱稿说 **where I am → what's unclear → correct communication channel → conditional ETA**，40 秒输出 + 20 秒检查。只使用平台认可的安全上车点。

## 30–35 min | Practical Singapore Errands

### 30–33 min | Scene 9：电话卡出现问题，先找到官方支持渠道

**You:** Hi, I'm new to this mobile plan. I can make calls, but I can't use mobile data.

**Staff:** Have you checked the plan status in the provider's app?

**You:** Not yet. Is that the best place to start, or should I contact technical support?

**Staff:** Please follow the provider's official troubleshooting instructions.

**You:** Thanks. If the app shows the service as active but data still doesn't work, who should I contact?

**Staff:** Please use the support channel listed in the app.

**You:** Understood. I'll check the status first and describe the issue clearly.

**30–31 min：**读两轮。**31–32 min：**按 **what works → what fails → right channel → next action** 复述。**32–33 min：**换成 **home internet connection**，说三句：**Where should I start? / Is this the right support channel? / What details should I provide?** 不通过陌生链接透露密码、OTP 或完整身份信息。

### 33–35 min | Scene 10：办理预约时，不知道找哪个部门

**You:** Hi, I need to ask about an appointment request, but I'm not sure which department handles it.

**Support:** Please check the contact information in the official portal.

**You:** Okay. Could you point me to the right section for existing appointments?

**Support:** Follow the instructions for checking or changing an appointment.

**You:** Thanks. I'll check the status before making another request.

**33–34 min：**读对话。**34–35 min：**脱稿用 **why I'm contacting → correct department → existing request → safe next step** 说 40 秒；余下 20 秒检查。预约及证件办理规则以对应官方服务为准。

## 35–37 min | Accurate Grammar Corrections

**35–36 min｜先改前三句，再核对：**

1. ❌ **Who I should contact about access?** → ✅ **Who should I contact about access?**（直接疑问句：疑问词 + should + 主语）
2. ❌ **Could you point me in right direction?** → ✅ **Could you point me in the right direction?**（固定搭配要有 the）
3. ❌ **I'm new in this team.** → ✅ **I'm new to this team.**（表达刚加入某团队，常用 new to）

**36–37 min｜两句复习：**

4. ❌ **I'm still waiting the approval.** → ✅ **I'm still waiting for approval.**
5. ❌ **If I will get access today, I should able to start.** → ✅ **If I get access today, I should be able to start.**

**正确替代，不算错误：** **Who should I speak to? / Who should I talk to? / Who should I contact?** 都自然；**Can you point me in the right direction? / Could you point me in the right direction?** 都正确，后者更委婉；**I'm new here / I've just joined the team** 都正确。**I don't know who I should contact** 是正确的嵌入句，和第 1 题的直接疑问句结构不同。

## 38–40 min | Final Speaking Challenges

### 38–39 min | Workplace：50 秒脱稿说 + 10 秒自检

提示：**new to project → repository works → staging access missing → correct request channel → ask owner → ticket/context → if approved by noon → run test by 4**。

先独立讲 50 秒，再看参考：

> **Hi, I'm new to the project and I'm setting up my development environment. I can already access the repository, but I'm still waiting for staging access. Could you point me to the right request channel, or tell me who owns this? I'll include the ticket number and the details of what I need. If access is approved by noon, I should be able to run the test by 4 p.m. Thanks for pointing me in the right direction.**

最后 10 秒检查：有没有说清**已经能做什么、缺什么、找谁、带什么信息和下一步**？

### 39–40 min | Everyday：50 秒脱稿说 + 10 秒自检

提示：**mobile plan → calls work → data doesn't → unsure which support channel → check official app → if active but still failing → ask support**。

先独立讲 50 秒，再看参考：

> **Hi, I'm having a problem with my mobile plan. I can make calls, but mobile data isn't working. I'm not sure which support channel handles this. Should I check the service status in the official app first? If it says the service is active but data still doesn't work, who should I contact? I'll share the relevant error details through the official channel. Thanks for your help.**

最后 10 秒检查：有没有**说明现象、找到正确渠道、提出可执行下一步**？

**40 分钟完成。今天记住：I'm new to ___. Who should I check with about ___? Could you point me in the right direction?**
