# Day 24 | Turning vague feedback into clear acceptance criteria

### Theme: 把“再优化一下”“更顺一点”变成可以真正开发、测试和验收的具体标准

今天重点练一个全栈工程师很常见的场景：**别人给的反馈很模糊时，不急着猜，而是把需求问具体、确认优先级、约定验收标准，再决定时间。**

你会反复练这几个动作：

- 把模糊反馈问具体：**Could you give me a specific example?**
- 确认真正目标：**What outcome are we trying to achieve?**
- 区分必须做和最好做：**Is this a must-have or a nice-to-have?**
- 复述验收标准：**So this is done when users can complete the flow without refreshing the page, right?**
- 在范围变化后重新确认时间：**If we add this requirement, I should still be able to finish by Friday, but testing may move to Monday.**

同时继续复习：**I’m still waiting... / should be able to / by / on / before / future if**。

---

## 0–5 min | Warm-up：先把“问具体”说顺

下面 5 句，每句大声说 3 遍。

> **Could you give me a specific example?**  
> 你能给我一个具体例子吗？

> **What outcome are we trying to achieve?**  
> 我们真正想达到的结果是什么？

> **Is this a must-have or a nice-to-have?**  
> 这是必须做，还是有最好但不是必须？

> **I’m still waiting for the final copy, so I’m using placeholder text for now.**  
> 我还在等最终文案，所以现在先用占位文本。

> **If the scope stays the same, I should be able to finish by Friday.**  
> 如果范围保持不变，我应该能在周五前完成。

快速复习：

- **by Friday** = 最迟周五完成
- **on Friday** = 周五当天发生
- **before Friday** = 周五之前，不包括周五

Future `if`：

> **If product confirms the requirement today, we can test tomorrow.**

不是：

> ❌ If product will confirm the requirement today...

# 5–17 min | Office Communication & Meetings

## 5–9 min | 场景 1：PM 说“这个页面再 polished 一点”

**PM:**  
The page works, but can we make it feel a bit more polished?

**You:**  
Sure. Could you give me a specific example of what feels unfinished?

**PM:**  
The loading state feels a little rough, and the transition is too sudden.

**You:**  
Got it. So the main issue is the loading experience rather than the overall layout. Is that right?

**PM:**  
Exactly.

**You:**  
Okay. I can improve the loading state and the transition without changing the page structure.

这里最重要的是：不要把 **polished / better / cleaner / smoother** 当作已经足够清楚的需求。

一个很好用的三步结构：

> **Could you give me a specific example?**  
> **So the main issue is ___ rather than ___, right?**  
> **Okay. I’ll focus on ___.**

例如：

> Could you give me a specific example of what feels confusing?

> So the main issue is the error message rather than the form itself, right?

> Okay. I’ll focus on making the recovery step clearer.

---

## 9–13 min | 场景 2：把需求变成 acceptance criteria

**Designer:**  
Users should be able to recover more easily if the upload fails.

**You:**  
Makes sense. What should the user be able to do after a failure?

**Designer:**  
Retry without selecting the file again.

**You:**  
Okay. And should the error message stay visible until the retry succeeds?

**Designer:**  
Yes.

**You:**  
Got it. So the acceptance criteria are: the user sees the error, can retry the same file, and doesn’t need to start over. Is that correct?

**Designer:**  
Yes, that’s exactly it.

`acceptance criteria` 可以理解成：**做到什么程度，大家才算这个需求完成了。**

非常实用的问法：

> **What should the user be able to do?**

> **What should happen if ___?**

> **What counts as done here?**

> **Is this the expected behaviour?**

如果需求突然又加了一项：

**PM:**  
Can we also add analytics for the retry button?

**You:**  
Yes, but that adds a little scope. Is the analytics event required for this release, or can it follow later?

**PM:**  
It’s required.

**You:**  
Okay. If we add it now, I should still be able to finish the implementation by Friday, but I’d prefer to keep Monday morning for final testing.

注意这里不是拒绝，而是：**范围变化 → 时间重新确认。**

---

## 13–15 min | 场景 3：开发完成前，确认“done”到底是什么

**You:**  
Before I wrap this up, I want to confirm one thing. Is this considered done once the frontend behaviour is complete, or do we also need analytics verification?

**PM:**  
We need analytics verification as well.

**You:**  
Got it. I’m still waiting for the event name from data, so I’ll finish the UI first and wire up the event once they confirm it.

**PM:**  
Sounds good.

**You:**  
If I get the event name by 3 p.m., I should be able to finish everything today.

几个很好用的句型：

> **Before I wrap this up, I want to confirm...**

> **Is this considered done once ___?**

> **Do we also need ___?**

> **I’m still waiting for ___, so I’ll ___ first.**

---

## 15–17 min | 2-minute Oral Substitution Drill

不要默读，直接开口替换。每个 Pattern 快速说 4 轮。

### Pattern 1

> **Could you give me a specific example of what feels unclear?**

替换：

- what feels slow
- what feels unfinished
- what feels confusing
- what you want to simplify

### Pattern 2

> **Is this a must-have or a nice-to-have?**

替换：

- Is this required for this release or can it follow later?
- Is this part of the current scope or a new request?
- Do we need this before launch or after launch?
- Is this blocking release or just an improvement?

### Pattern 3

> **If the scope stays the same, I should be able to finish by Friday.**

替换：

- get the copy by noon / finish today
- receive the event name before 3 p.m. / finish by the end of the day
- freeze the design today / test on Thursday
- get approval by Wednesday / release on Friday

# 17–23 min | Colleague Small Talk & Socializing

## 17–20 min | 场景 1：同事说“这家店很好吃”，你想问具体一点

**Colleague:**  
You should try that new place near the office. It’s really good.

**You:**  
What do you like about it?

**Colleague:**  
The noodles are good, and it’s not too expensive.

**You:**  
Nice. Is it usually crowded at lunchtime?

**Colleague:**  
A little. If you go before 12, it’s much easier to get a table.

**You:**  
Good to know. I might try it tomorrow.

这里的重点也是“把模糊评价问具体”：

> **What do you like about it?**

> **What’s good there?**

> **Is it usually crowded?**

> **Anything you’d recommend?**

这些都比只回一句 `Okay` 更容易继续聊天。

---

## 20–23 min | 场景 2：同事约活动，你想先确认安排

**Colleague:**  
A few of us are going out after work. Want to join?

**You:**  
Maybe. What’s the plan?

**Colleague:**  
Probably dinner first, then maybe drinks.

**You:**  
Sounds good. What time are you heading out?

**Colleague:**  
Around 6:30.

**You:**  
Okay. I’m still waiting for one review to come back. If it’s done by 6, I should be able to join you.

这里复习：

> **What’s the plan?** = 具体怎么安排？

> **If it’s done by 6, I should be able to join you.**

Future `if` 还是用一般现在时：

> If it **is** done...

不是：

> ❌ If it **will be** done...

# 23–30 min | Restaurant / Shopping / Ride-hailing

## 23–25 min | Restaurant：问“微辣”到底有多辣

**You:**  
How spicy is the medium level?

**Staff:**  
It’s quite spicy.

**You:**  
Could you compare it with the mild level?

**Staff:**  
Medium is much stronger. If you don’t usually eat very spicy food, I’d recommend mild.

**You:**  
Okay, I’ll go with mild then.

很好用：

> **How spicy is it?**

> **Could you compare it with ___?**

> **What would you recommend if I want something less spicy?**

你不是在追求“高级英语”，而是在减少误解。

---

## 25–27 min | Shopping：确认“可以退”具体是什么意思

**Staff:**  
You can return it if it doesn’t fit.

**You:**  
Great. Just to confirm, how many days do I have to return it?

**Staff:**  
Fourteen days.

**You:**  
And does it need to be unopened, or is trying it on okay?

**Staff:**  
Trying it on is fine, as long as the tags are still attached.

**You:**  
Got it. Thanks.

这里不要只听到 `You can return it` 就结束。

可以继续问：

> **How many days do I have?**

> **Does it need to be unopened?**

> **Do I need the receipt?**

> **Is the refund to the original payment method?**

这些问题是否适用取决于商家的真实政策；这里练的是语言结构，不代表具体商店政策。

---

## 27–30 min | Grab：把模糊上车位置说具体

**Driver:**  
I’m nearby. Where exactly are you?

**You:**  
I’m outside Tower B, next to the taxi stand.

**Driver:**  
Is that the entrance facing the main road?

**You:**  
Yes, exactly. I’m wearing a black T-shirt and standing beside the blue sign.

**Driver:**  
Okay, I see you.

如果你还没到：

> **I’m still waiting for the lift. I should be downstairs in about two minutes.**

如果对方说的位置不明确：

> **Do you mean the entrance facing the main road?**

> **Could you tell me which pickup point you’re at?**

> **I’m at Pickup Point B, not the taxi queue.**

核心就是：**landmark + 具体位置 + 可识别特征**。

# 30–35 min | Practical Singapore Life Errands

## 30–33 min | 场景 1：办事时确认材料要求

**You:**  
Hi, I just want to make sure I have the right documents before I come down.

**Staff:**  
Sure. What are you applying for?

**You:**  
I’m updating my account details. Do I need the original document, or is a digital copy enough?

**Staff:**  
Please bring the original.

**You:**  
Okay. Do I need to make an appointment, or can I walk in?

**Staff:**  
You can walk in before 4 p.m.

**You:**  
Great. If I arrive by 3:30, I should still be able to submit it today, right?

这类办事场景非常适合用“具体化问题”：

> **Do I need the original, or is a digital copy enough?**

> **Do I need an appointment, or can I walk in?**

> **Is there anything else I need to bring?**

> **What time do I need to arrive by?**

---

## 33–35 min | 场景 2：预约已经提交，但确认信息不完整

**You:**  
Hi, I’ve received the appointment confirmation, but it doesn’t show which counter I should go to.

**Staff:**  
Which service did you book?

**You:**  
The document verification service on Friday morning.

**Staff:**  
You can go to Counter 6.

**You:**  
Thanks. And should I arrive before the appointment time, or is arriving exactly on time okay?

如果还缺信息：

> **I’m still waiting for the confirmation email with the reference number.**

> **If I don’t receive it by tomorrow, should I contact you again?**

再次复习：

- **on Friday morning** = 周五上午这个时间段发生
- **before the appointment** = 预约时间之前
- **by tomorrow** = 最迟明天

# 35–38 min | Common Grammar Fixes

今天只纠正确实有问题的句子。

### 1

❌ **Can you explain me what you mean?**  
✅ **Can you explain to me what you mean?**  
✅ **Can you tell me what you mean?**

`explain` 后面如果要接“对某人解释”，用 **explain something to someone**。

---

### 2

❌ **What does this means?**  
✅ **What does this mean?**

有了 `does`，后面的动词用原形 `mean`。

---

### 3

❌ **If product will confirm it today, we can test tomorrow.**  
✅ **If product confirms it today, we can test tomorrow.**

Future `if` 条件从句通常用一般现在时。

---

### 4

❌ **I should can finish it by Friday.**  
✅ **I should be able to finish it by Friday.**

`should` 后面不能直接再接 `can`。

---

### 5

❌ **I’m waiting for their feedback since yesterday.**  
✅ **I’ve been waiting for their feedback since yesterday.**

从昨天开始一直等到现在，用现在完成进行时很自然。

注意：下面这些表达都正确，只是意思不同：

> **I’ll finish it by Friday.** = 最迟周五完成  
> **We’ll release it on Friday.** = 周五当天发布  
> **We need to test it before Friday.** = 周五之前完成测试

# 38–40 min | Final Speaking Challenge

## 第 1 分钟：Workplace Challenge

只看关键词，自己说 45–60 秒：

**vague feedback → specific example → outcome → acceptance criteria → new scope → waiting → by Friday**

参考版本：

> The feedback is that the page should feel more polished, but I want to make that more specific before I change anything. Could you give me an example of what feels unfinished? I also want to confirm the expected outcome and the acceptance criteria. If the new analytics event is required for this release, that adds a little scope. I’m still waiting for the final event name, but if I get it by 3 p.m., I should be able to finish the implementation by Friday.

## 第 2 分钟：Everyday Challenge

关键词：

**appointment → documents → original or digital → Friday → arrive before → waiting → by tomorrow**

参考版本：

> Hi, I’m calling to confirm what I need for my appointment on Friday. Do I need to bring the original document, or is a digital copy enough? Also, should I arrive before the appointment time? I’m still waiting for the email with my reference number. If I don’t receive it by tomorrow, should I contact you again?

# Day 24 Compact Review

| 场景 | 直接说 |
|---|---|
| 要具体例子 | **Could you give me a specific example?** |
| 确认目标 | **What outcome are we trying to achieve?** |
| 确认用户行为 | **What should the user be able to do?** |
| 确认验收标准 | **What counts as done here?** |
| 区分优先级 | **Is this a must-have or a nice-to-have?** |
| 判断是否新增范围 | **Is this part of the current scope or a new request?** |
| 还在等待 | **I’m still waiting for...** |
| 条件 + 时间 | **If the scope stays the same, I should be able to finish by Friday.** |
| 最迟周五 | **by Friday** |
| 周五当天 | **on Friday** |
| 周五之前 | **before Friday** |
| 问具体计划 | **What’s the plan?** |
| 办事确认材料 | **Do I need the original, or is a digital copy enough?** |
| 确认时间要求 | **What time do I need to arrive by?** |

今天最值得练到脱口而出的 6 句：

> **Could you give me a specific example?**

> **What outcome are we trying to achieve?**

> **What counts as done here?**

> **Is this a must-have or a nice-to-have?**

> **I’m still waiting for the final copy, so I’m using placeholder text for now.**

> **If the scope stays the same, I should be able to finish by Friday.**
