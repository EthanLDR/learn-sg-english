# Day 77 | What are we optimising for? Explain priorities and make trade-offs

### 今日主题：面对多个可行方案，先明确最重要的目标，再解释为什么这样选择

今天练 **goal → options → trade-off → recommendation**（目标 → 选项 → 取舍 → 建议）。不是简单地说哪个方案更好，而是说明它在哪个维度更好。适合 AI Agent、全栈工程研发，也适合新加坡日常消费和办事。

> **What are we optimising for?** 我们最想优化的是什么？
>
> **Our main priority is reliability.** 我们最优先考虑的是可靠性。
>
> **Option A is faster, but option B is more reliable.** A 更快，但 B 更可靠。
>
> **Given our constraints, I'd go with option B.** 考虑到我们的限制，我会选 B。
>
> **Is the extra cost worth it?** 额外的成本值得吗？

**trade-off** = 取舍；**constraint** = 限制条件；**prioritise A over B** = 优先考虑 A 而不是 B；**worth + 名词或动名词** = 值得。所有场景和数字均为模拟，不代表真实项目数据、商家报价或机构政策。

**40 分钟计时：0–5（5）+ 5–17（12）+ 17–23（6）+ 23–30（7）+ 30–35（5）+ 35–37（2）+ 37–38（1）+ 38–40（2）= 40。** 阅读、朗读、替换、脱稿和核对均包含在各段内。

## 0–5 min | Warm-up：用一句话解释选择

**0–2 min：**以下四句各读三遍，剩余时间连说。重读 priority、faster、reliable、worth。

> **Speed matters, but reliability comes first.** 速度很重要，但可靠性优先。
>
> **I'm willing to spend a little more if it's worth it.** 如果值得，我愿意多花一点。
>
> **It depends on what matters most to us.** 这取决于我们最看重什么。
>
> **I'd rather keep the scope small.** 我宁愿把范围控制得小一点。

**2–4 min：**每轮一分钟；第一轮分角色读，第二轮遮住 You，把 response time 换成 cost，把 accuracy 换成 reliability。

**Lead:** Which matters more for this feature, response time or accuracy?

**You:** Accuracy comes first, although response time still matters.

**Lead:** So should we ignore speed?

**You:** No. We should agree on an acceptable response time as well.

**4–5 min：**先口译，再核对并重复。

“我还在等评估结果。” → **I'm still waiting for the evaluation results.**

“如果中午前收到，我应该能最迟四点给出建议。” → **If I get them by noon, I should be able to make a recommendation by 4 p.m.**

“这个额外成本值得吗？” → **Is the extra cost worth it?**

## 5–17 min | Office Communication & Meetings

### 5–9 min | Scene 1：AI Agent 模型选择，质量与成本的平衡

**PM:** Should we use the more expensive model for every request?

**You:** What are we optimising for? Answer quality, latency or cost?

**PM:** Quality is the main priority, but we need to keep costs reasonable.

**You:** Then I'd compare the models on the same approved evaluation cases. A cheaper model might be sufficient for simple tasks.

**Lead:** What about complex tasks?

**You:** We could evaluate a stronger model for those. We'd need to check whether the quality improvement justifies the extra cost.

**PM:** When can you recommend an approach?

**You:** I'm still waiting for the evaluation results. If they arrive by noon, I should be able to share a recommendation by 4 p.m.

**5–7 min：**分角色朗读两轮，第二轮遮住 You。**7–8 min：**回答 What's the priority? What's the constraint? What evidence is needed? **8–9 min：**40 秒脱稿，20 秒自检。

> **Our main priority is ___. We also need to consider ___. I'd compare ___ before deciding whether ___ is worth it. If ___, I should be able to ___ by ___.**

**latency** = 延迟；**sufficient** = 足够；**justify the cost** = 证明这笔成本值得。没有评估结果，不预设某个模型一定更好。

### 9–13 min | Scene 2：会议中讨论新需求与交付时间

**PM:** Can we add the advanced settings to Friday's release?

**You:** We could, but we'd need to consider the impact on the schedule.

**Designer:** Would it take much longer?

**You:** The UI isn't the only cost. We'd also need integration and testing time.

**Lead:** What's your recommendation?

**You:** Given the deadline, I'd prioritise the core workflow over the optional settings.

**PM:** Can we review the remaining work next week?

**You:** Yes. If we agree on the smaller scope today, I should be able to share an updated plan before Friday.

**9–11 min：**读两轮；第二轮替换 advanced settings 为 export options、core workflow 为 the basic reporting flow。**11–12 min：**按 goal → added work → trade-off → recommendation 复述。**12–13 min：**40 秒自由输出，20 秒核对。

> **We could add ___, but that would require ___. Given ___, I'd prioritise ___ over ___.**

**given the deadline** = 考虑到截止时间；**optional** = 可选的。缩小范围不等于省略必要测试。

### 13–15 min | Scene 3：Code Review 中比较两种实现

**Reviewer:** Why did you choose the simpler implementation?

**You:** It covers our current requirements and is easier to maintain.

**Reviewer:** The other approach might be more flexible.

**You:** True. The trade-off is additional complexity. I'd introduce that flexibility when we have a clear need for it.

**Reviewer:** Can you document the decision?

**You:** Sure. I'll explain the benefits and limitations in the PR.

**13–14 min：**朗读，重读 maintain、flexible、complexity。**14–15 min：**40 秒脱稿比较两个方案，20 秒重复：**I'd keep it simple unless we have a clear reason to add complexity.**

### 15–17 min | Timed Oral Substitution：12 轮 × 10 秒

**15:00–15:40｜A. 表达优先级（4 轮）**

模板：**I'd prioritise ___ over ___ for now.**

1. reliability / speed
2. accuracy / lower cost
3. the core workflow / optional features
4. maintainability / flexibility

**15:40–16:20｜B. 询问是否值得（4 轮）**

模板：**Is ___ worth ___?**

1. the quality improvement / the extra cost
2. the extra feature / the additional effort
3. the shorter journey / the higher fare
4. the larger room / the higher rent

**16:20–17:00｜C. 条件与期限（4 轮）**

模板：**If ___, I should be able to ___ ___.**

1. the results arrive by noon / compare the models / by 4
2. QA replies on Monday / update the plan / on Tuesday
3. the estimate arrives today / review it / before Friday
4. the team agrees by Thursday / share the decision / on Friday

每轮 3 秒看提示 + 7 秒大声说，共 120 秒。**by Friday** 最迟周五；**on Friday** 周五当天；**before Friday** 周五之前。

## 17–23 min | Colleague Small Talk & Socializing

### 20–23 min | Scene 5：讨论周末活动的预算

**Colleague:** Would you rather go to the cinema or try an escape room?

**You:** Both sound fun. How much would each option cost?

**Colleague:** The escape room might cost more per person.

**You:** I'd be happy to spend a bit more if everyone prefers it. What's everyone's budget?

**Colleague:** Let's ask the group.

**You:** Good idea. I'd rather choose something everyone is comfortable with.

**20–21 min：**朗读。**21–22 min：**换成 bowling 和 a board-game café。**22–23 min：**40 秒表达个人偏好并询问集体预算，20 秒自检。

### 27–30 min | Ride-hailing：更快的车是否值得多花钱

## 35–37 min | Accurate Grammar Corrections

**35–36 min：**先口头纠正前三句，再核对。

1. ❌ **I prefer reliability than speed.** → ✅ **I prefer reliability to speed.**（prefer A to B）
2. ❌ **Is it worth to pay extra?** → ✅ **Is it worth paying extra?**（worth + 动名词）
3. ❌ **This option is more cheaper.** → ✅ **This option is cheaper.**（cheaper 已经是比较级）

**36–37 min：**复习两句并口头解释。

4. ❌ **I'm still waiting the results.** → ✅ **I'm still waiting for the results.**
5. ❌ **If the results will arrive today, I should able to decide by Friday.** → ✅ **If the results arrive today, I should be able to decide by Friday.**（普通未来条件句用 if + 一般现在时；should be able to）

**正确替代，不算错误：** I'd rather use A than B / I'd prefer to use A rather than B 都正确。Optimise / optimize 均为正确拼写。More reliable / more dependable 都自然。By Friday / on Friday / before Friday 都正确，时间含义不同。
