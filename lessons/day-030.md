# Day 30 | Explaining technical problems in plain English and checking understanding

### Theme: 不只“说对”，还要让非技术同事真正听懂——少用术语，多说影响、原因和下一步

今天重点练一个全栈工程师很实用的能力：**把技术问题解释给 PM、设计师、运营或客户听时，不堆术语，而是先说发生了什么、用户受到什么影响、我们正在做什么。**

你会反复练这几个动作：

- 先说用户影响：**The main issue is that some users can’t complete the checkout.**
- 再说简单原因：**The app is getting an unexpected response from the server.**
- 避免过度技术化：**In simple terms, the frontend and backend aren’t agreeing on the data format.**
- 检查对方是否理解：**Does that make sense?**
- 给下一步和时间：**I’m still waiting for one backend change. If I get it by noon, I should be able to finish by Friday.**

同时继续复习：**I’m still waiting... / should be able to / by / on / before / future if**。

---

## 0–5 min | Warm-up：把“技术话 → 人话”说顺

下面 5 句，每句大声说 3 遍。

> **The main issue is that some users can’t complete the checkout.**  
> 主要问题是，一些用户无法完成结账。

> **In simple terms, the app is getting the wrong kind of data back.**  
> 简单来说，应用拿回来的数据格式不对。

> **The technical detail isn’t the important part here—the user impact is.**  
> 这里最重要的不是技术细节，而是用户影响。

> **I’m still waiting for one backend change.**  
> 我还在等一个后端修改。

> **If I get it by noon, I should be able to finish the fix by Friday.**  
> 如果中午前拿到，我应该能在周五前完成修复。

快速复习：

- **by Friday** = 最迟周五完成
- **on Friday** = 周五当天发生
- **before Friday** = 周五之前，不包括周五

Future `if`：

> **If the backend sends the correct field, the page will work normally.**

不是：

> ❌ If the backend will send the correct field...

# 5–17 min | Office Communication & Meetings

## 5–9 min | 场景 1：PM 听不懂技术术语，你要换一种说法

**PM:**  
What’s causing the checkout issue?

**You:**  
The short version is that the frontend expects one data format, but the backend is returning another.

**PM:**  
What does that mean for users?

**You:**  
Some users see an error after they click “Pay”, so they can’t complete the checkout.

**PM:**  
Is it a frontend bug or a backend bug?

**You:**  
It’s really an integration issue between the two. I’m still waiting for one backend change, and I’m updating the frontend handling at the same time.

**PM:**  
When can we retest?

**You:**  
If I get the backend change by noon, I should be able to retest this afternoon.

这里最值得记的是顺序：

> **Simple cause → User impact → Current action → Timing**

不要一上来就说：

> The DTO schema is inconsistent with the client-side type definition.

技术上可能没错，但 PM 未必需要这些细节。

可以换成：

> **The frontend and backend are using different data formats.**

更简单、更有用。

### Reusable Pattern

> **The short version is that ___. That means users ___. We’re currently ___.**

例如：

> The short version is that the login token expires too early. That means some users are being signed out unexpectedly. We’re currently updating the refresh logic.

> The short version is that the page loads too much data at once. That means it feels slow on weaker connections. We’re currently reducing the initial payload.

---

## 9–13 min | 场景 2：设计师问“为什么这个动画会卡？”

**Designer:**  
Why does the animation feel smooth on some devices but laggy on others?

**You:**  
In simple terms, some devices have less processing power, and this animation is doing too much work at once.

**Designer:**  
Can we make it smoother without changing the design?

**You:**  
Probably. We can simplify the animation slightly and reduce the amount of work happening on every frame.

**Designer:**  
Will users notice the difference?

**You:**  
Visually, the change should be small. The main benefit is that the interaction should feel smoother on slower devices.

这里很好用：

> **In simple terms...**

> **The main benefit is...**

> **From the user’s point of view...**

> **Visually, the difference should be small.**

如果对方继续问技术细节，再往下讲；不要一开始就把所有实现细节倒出来。

---

## 13–15 min | 场景 3：解释完以后，确认对方有没有理解

**You:**  
So the current problem isn’t that the payment itself is failing. The problem is that the page can’t correctly read one part of the response. Does that make sense?

**PM:**  
Yes. So once the response format is fixed, users should be able to continue normally?

**You:**  
Exactly. I’ll also add a safer fallback on the frontend so the page handles unexpected data better in the future.

你可以用：

> **Does that make sense?**

> **Is that clear so far?**

> **Would it help if I gave you an example?**

> **The key point is ___.**

注意：`Does that make sense?` 很自然，但语气要像“我有没有解释清楚”，而不是像在质疑对方理解能力。

---

## 15–17 min | 2-minute Oral Substitution Drill

不要默读，直接快速替换。

### Pattern 1

> **The short version is that the frontend and backend expect different data.**

替换：

- the page is loading too much data at once
- the token expires earlier than expected
- the cache still has old information
- the service is taking too long to respond

### Pattern 2

> **That means some users can’t complete the checkout.**

替换：

- some users get signed out
- the page feels slow
- users see outdated information
- the button appears to do nothing

### Pattern 3

> **If I get the backend change by noon, I should be able to finish by Friday.**

替换：

- get the logs by 2 p.m. / identify the cause today
- receive the fix today / retest tomorrow
- get approval before lunch / deploy this afternoon
- finish testing by Thursday / release on Friday

# 17–23 min | Colleague Small Talk & Socializing

## 17–20 min | 场景 1：别人问“你到底是做什么的？”

**Colleague:**  
You’re a full-stack engineer, right? What does that actually mean?

**You:**  
Basically, I work on both the part users see and the server-side systems behind it.

**Colleague:**  
So both frontend and backend?

**You:**  
Exactly. I used to focus more on frontend, but now I work across the whole flow and also spend more time on AI-related features.

**Colleague:**  
Sounds like a lot.

**You:**  
It can be, but I like understanding how the whole product fits together.

这里不要把自我介绍讲成技术栈列表。

很好用：

> **Basically, I work on...**

> **The part users see...**

> **The systems behind it...**

> **I work across the whole flow.**

这些表达让非技术同事也能听懂。

---

## 20–23 min | 场景 2：同事问你为什么还不能去吃饭

**Colleague:**  
Are you still working on that bug?

**You:**  
Yeah. I’m still waiting for one backend change.

**Colleague:**  
Is it serious?

**You:**  
Not really. The fix itself is small; I just can’t verify it until the backend change is ready.

**Colleague:**  
Want to grab lunch later?

**You:**  
Sure. If the change is ready by 12:30, I should be free before 1.

这里可以练：

> **The fix itself is small; the dependency is the issue.**

> **I can’t verify it until ___.**

> **If it’s ready by 12:30, I should be free before 1.**

继续体会：

- **by 12:30** = 最迟 12:30
- **before 1** = 1 点之前

# 23–30 min | Restaurant / Shopping / Ride-hailing

## 23–25 min | Restaurant：描述问题，不需要知道专业词

你点了一杯饮料，但拿到的和预期不一样。

**You:**  
Hi, I think there may be a problem with this drink.

**Staff:**  
What seems to be wrong?

**You:**  
I ordered it without sugar, but this tastes very sweet.

**Staff:**  
Sorry about that. We can remake it.

**You:**  
Thanks. Could you make sure the replacement has no added sugar?

这里的重点是：

> **What seems to be wrong?**

> **The issue is that ___.**

> **Could you make sure ___?**

你不需要知道饮料制作里的专业术语，只需要把“现象 + 期望”说清楚。

---

## 25–27 min | Shopping：电子产品有问题，描述“症状”而不是猜原因

**You:**  
Hi, I bought this yesterday, but it keeps turning off by itself.

**Staff:**  
Does it happen while you’re using it?

**You:**  
Yes. It usually works for a few minutes and then shuts down.

**Staff:**  
Have you tried charging it fully?

**You:**  
Yes. The battery shows 100%, but the problem still happens.

**Staff:**  
Okay, we can inspect it.

这里很实用：

> **It keeps turning off by itself.**

> **It works for a few minutes and then ___.**

> **The problem still happens.**

不要随便猜：

> The motherboard is broken.

除非你真的确定。描述症状通常更有效。

---

## 27–30 min | Grab：司机听不懂你的位置，换成简单地标

**Driver:**  
I can’t find the pickup point.

**You:**  
No problem. I’m outside Tower B, next to the taxi stand.

**Driver:**  
Is that near the main road?

**You:**  
Yes. In simple terms, if you drive past the main entrance, the taxi stand is immediately on your left.

**Driver:**  
Okay, I see it.

**You:**  
Great. I’m still waiting for the lift, but I should be there in about two minutes.

这里的原则和解释技术问题一样：

**别堆信息，给对方最容易执行的描述。**

> **next to the taxi stand**

> **on your left**

> **just past the main entrance**

> **I should be there in about two minutes.**

# 30–35 min | Practical Singapore Life Errands

## 30–33 min | 场景 1：向维修人员描述空调问题

**Staff:**  
What seems to be wrong with the air conditioner?

**You:**  
It turns on normally, but after about ten minutes, it stops blowing cold air.

**Staff:**  
Does it turn off completely?

**You:**  
No. The unit stays on, but the air becomes warm.

**Staff:**  
Okay. We’ll send a technician to check it.

**You:**  
Thanks. I’m still waiting for the appointment confirmation. If I get it by this afternoon, should someone be able to come tomorrow?

这里不要只说：

> The air conditioner is broken.

更有用的是：

> **It turns on normally, but...**

> **After about ten minutes...**

> **The unit stays on, but...**

维修、售后、客服电话都适合这样描述：**正常部分 + 异常部分 + 什么时候发生。**

---

## 33–35 min | 场景 2：银行 / 柜台系统报错，你只描述看到的现象

**You:**  
Hi, I’m trying to submit this form online, but I keep getting an error after I click “Submit”.

**Staff:**  
What does the error message say?

**You:**  
It says “Something went wrong”, but it doesn’t give me an error code.

**Staff:**  
Have you tried again?

**You:**  
Yes. I tried twice this morning and got the same result.

**Staff:**  
Okay. You can submit it here instead.

**You:**  
Great. If I submit it in person today, should it still be processed by Friday?

很好用：

> **I keep getting an error when I ___.**

> **It doesn’t give me an error code.**

> **I tried twice and got the same result.**

> **If I submit it today, should it still be processed by Friday?**

# 35–38 min | Common Grammar Fixes

今天只纠正确实有问题的表达。

### 1

❌ **Let me explain you the problem.**  
✅ **Let me explain the problem to you.**  
✅ **Let me explain what’s happening.**

`explain` 常用结构是 `explain something to someone`。

---

### 2

❌ **The problem is some users cannot checkout.**  
✅ **The problem is that some users can’t check out.**

这里 `check out` 是动词短语；`checkout` 常见作名词或形容词，例如 `checkout page`。

---

### 3

❌ **I’m still waiting the backend change.**  
✅ **I’m still waiting for the backend change.**

`wait for + 人 / 事物`。

---

### 4

❌ **If the backend will fix it today, we can test tomorrow.**  
✅ **If the backend fixes it today, we can test tomorrow.**

Future `if` 条件从句通常用一般现在时。

---

### 5

❌ **I should can finish it by Friday.**  
✅ **I should be able to finish it by Friday.**

`should` 后不能直接接 `can`。

注意下面三句都正确，只是意思不同：

> **I should be able to finish by Friday.** = 最迟周五完成

> **We’re planning to release on Friday.** = 周五当天发布

> **We need to finish testing before Friday.** = 周五之前完成测试

# 38–40 min | Final Speaking Challenge

## 第 1 分钟：Workplace Challenge

只看关键词，自己说 45–60 秒：

**simple explanation → user impact → backend change → current action → by noon → should be able to → Friday → check understanding**

参考版本：

> The short version is that the frontend and backend are using different data formats. That means some users see an error after they try to pay, so they can’t complete the checkout. I’m still waiting for one backend change, and I’m updating the frontend handling at the same time. If I get the backend change by noon, I should be able to finish the fix by Friday. The key point is that the payment itself isn’t failing—the page is reading part of the response incorrectly. Does that make sense?

## 第 2 分钟：Everyday Challenge

关键词：

**air conditioner → turns on → ten minutes → warm air → appointment → waiting → by afternoon → tomorrow**

参考版本：

> Hi, I’m calling about my air conditioner. It turns on normally, but after about ten minutes it stops blowing cold air. The unit stays on, but the air becomes warm. I’m still waiting for the appointment confirmation. If I receive it by this afternoon, should someone be able to come tomorrow and check it?

# Day 30 Compact Review

| 场景 | 直接说 |
|---|---|
| 简化技术解释 | **The short version is that...** |
| 换成人话 | **In simple terms...** |
| 强调用户影响 | **That means users...** |
| 强调关键点 | **The key point is...** |
| 从用户角度说 | **From the user’s point of view...** |
| 检查理解 | **Does that make sense?** |
| 主动举例 | **Would it help if I gave you an example?** |
| 还在等待 | **I’m still waiting for the backend change.** |
| 条件化时间 | **If I get it by noon, I should be able to finish by Friday.** |
| 最迟周五 | **by Friday** |
| 周五当天 | **on Friday** |
| 周五之前 | **before Friday** |
| 描述故障现象 | **It works for a few minutes and then...** |
| 描述重复报错 | **I keep getting an error when I...** |

> **The short version is that the frontend and backend are using different data formats.**

> **In simple terms, the app is getting the wrong kind of data back.**

> **That means some users can’t complete the checkout.**

> **Does that make sense?**

> **I’m still waiting for one backend change.**

> **If I get it by noon, I should be able to finish the fix by Friday.**
