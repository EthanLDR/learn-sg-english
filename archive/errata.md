## 整理说明：原文保留，纠错另列

这部分是本次整理新增的复习补充，不冒充当时已经讲过的内容。前面的 15 份课程与现场转写保留原来的表达、例句和反馈；其中有些 ❌ 实际只是“不够贴合当时情境”，并非语法错误。复习时请以这里的澄清为准。

## 01｜by / on / before：不是越换越“自然”，而是意思不同

**by Friday** 表示“最迟在周五这个截止点完成”，可以更早完成，也可以周五完成，不等于“必须周四结束前完成”。只说日期时，具体截止到几点还需要看约定。

| 你要表达的意思 | 可用表达 |
|---|---|
| 明天做完 | I’ll finish it tomorrow. |
| 最迟明天做完 | I’ll finish it by tomorrow. |
| 明天之前就做好 | I’ll have it ready before tomorrow. |
| 周五当天发布 | We can release it on Friday. |
| 最迟周五发布 | We can release it by Friday. |
| 下周三完成 | I should be able to finish it next Wednesday. |
| 最迟下周三完成 | I should be able to finish it by next Wednesday. |
| 17 号当天完成 | I should be able to finish it on the 17th. |
| 最迟 17 号完成 | I should be able to finish it by the 17th. |
| 明天下午 5 点前完成 | I should be able to finish it by 5 p.m. tomorrow. |

你当时问到“17 号”，现场没有完整回答；上表补上。**the 17th** 读作 **the seventeenth**。如果跨月份沟通，加上月份，例如 **by September 17**，避免歧义。

**tomorrow / today / next Wednesday** 作时间状语时，通常直接使用，不说 **at tomorrow** 或 **on next Wednesday**。但是 **by tomorrow** 合法，因为 by 明确增加了“截止时间”的含义。

原先把 **by tomorrow** 说成“最晚明天之前”、把 **by** 当成比 **tomorrow** 更自然的升级，都不够准确。你说的 **I should be able to finish the work tomorrow.** 本身是完整正确的句子。

## 02｜拆开 should be able to

> I / should / be able to / finish it / by Friday.

**should** 在这里表示基于目前情况作出的预期；**be able to** 表示“能够”；**finish it** 是具体动作；**by Friday** 是截止时间。

结构是 **主语 + should + be able to + 动词原形**。should 后接原形 be，不能说 **should can**，也不能把 **be** 漏掉。

> I should be able to finish it by Friday.  
> I should be able to join the meeting.  
> I should be able to send it over this afternoon.

**I will finish it tomorrow** 也是正确的职场表达；视语境可表示预测、决定或较明确的承诺，并不自动等于“保证”。**I should be able to…** 更突出“按目前判断应该有能力做到”，不是所有时候都更专业。需要明确承诺时，不要只用模糊表达。

**I should finish it tomorrow** 还可能表示“我应该／理应明天完成”，也可能是预期，要结合上下文判断。

## 03｜if 后面不是“永远不能用 will”

在本次练的“将来真实条件”里，通常用 **if + 一般现在时** 表示未来条件，主句可用 **will / can / may / should be able to**。

> If the API is ready today, I should be able to finish it tomorrow.  
> If we finish testing tomorrow, we can release it on Friday.

也可能用现在完成时突出“到时已经完成”：

> If we’ve finished testing by Thursday, we can release it on Friday.

不要把规则扩展到所有 if。**if = whether（是否）** 时可以用 will：

> I don’t know if the API will be ready tomorrow.

这里是“我不知道 API 明天是否准备好”，不是“如果 API 准备好”。表示愿意、坚持等特殊意义时，条件从句也可能出现 will；当前练习先掌握普通条件句即可。

## 04｜when：时间从句与间接问句要分开

> I’ll let you know when I finish.

意思是“我完成的时候会通知你”。when 引导时间从句，通常不用 will 表示将来。

> I’ll tell you when I expect to finish.

意思是“我会告诉你，我预计什么时候完成”。这里 when 引导的是要告知的内容，即间接问句。**I’ll tell you when I’ll finish** 在这一意思下也可以成立，不能无条件判错。

**once it’s ready / before I leave / as soon as it’s ready** 同样可以用现在时表达未来的时间关系。

## 05｜finish 可以不带宾语

原先“finish 后面要有对象”的说法不正确。上下文清楚时，可以说：

> I should finish by Friday.  
> When do you think you can finish?

你当时的 **I can be by tomorrow** 主要问题是 be 后面的意思没有说完整，不是所有句子都必须有 it。可改为：

> I can finish it by tomorrow.  
> I can be ready by tomorrow.

## 06｜team 不一定永远配单数

本次练习把团队视为一个整体，使用 **my team finishes** 很合适。

> If my team finishes testing tomorrow, we can release it on Friday.

英式英语中，team 等集合名词也可因强调成员而使用复数动词，不能一概说 **my team finish** 必定错误。初学时统一练“整体单数”便于保持一致；强调成员可直接说：

> If my team members finish testing tomorrow, we can release it on Friday.

## 07｜提问要看句子的层次

| 类型 | 例句 | 要点 |
|---|---|---|
| 直接问句 | Which task should I prioritize? | should 放在 I 前面 |
| 间接问句 | I’ll ask which task I should prioritize. | which 后用陈述语序 |
| 直接问句 | Where are you? | are 在 you 前面 |
| 间接问句 | Could you tell me where you are? | you 在 are 前面 |
| 询问主语 | Who handles the deployment? | who 本身就是主语，不加 do |
| 用 be 提问 | Where is the counter? | be 直接参与倒装 |

所以，“Wh-word + 助动词 + 主语 + 动词”只覆盖部分情况，不是所有特殊疑问句的通用公式。

## 08｜时态、等待与被卡住

有明确过去时间时：**I finished it yesterday.** 强调现在的完成结果时：**I’ve finished it.** **I’ve already finished it** 和 **I already finished it** 都能成立；使用习惯和语境不同，不要把带 already 的一般过去时一概判错。

表示“正在等”要保留 **am**：**I’m still waiting for the API.** 不能漏成 **I still waiting**。表示“已经完成”则是 **I’ve finished**，不能漏成 **I have the frontend UI** 来表达同一个意思。

**wait for** 是通用表达；课程里的 **wait on** 在“等待某人或依赖项”这一用法中也可成立。**I’m blocked by…** 并不天然失礼：如果确实不能继续，直接说明 blocker 反而更清楚。只说 **I’m waiting for…** 不一定表达出“工作已被阻塞”。

## 09｜这些被打 ❌ 的句子，并非都存在语法错误

| 原课程中的句子 | 更准确的理解 |
|---|---|
| I don’t understand what you said just now. | 语法正确，表示不理解内容；I didn’t catch that 常表示没听清。不是完全同义。 |
| Can I interrupt you? | 语法正确；是否生硬取决于语气和场合。 |
| Can you repeat again? | 多数场景显重复，但不宜等同于基础语法错误；repeat that 更清楚。 |
| Let’s go to eat lunch. | 语法可成立；Let’s grab lunch / Let’s go for lunch 更简洁惯用。 |
| Can we delay the meeting to 4? | 能理解；Can we move the meeting to 4? 或 delay it until 4 更清楚。 |
| Something suddenly happened to me. | 语法正确，表示有事发生在“我”身上；不一定等于临时另有安排。 |
| Maybe I will go. | 正确；I might go 是另一种表达，并不是强制纠正。 |
| Tomorrow I don’t work. | 在排班语境可成立；I’m not working tomorrow / I’m off tomorrow 更通用。 |
| Tomorrow I will take a holiday. | 语法可成立；如果只表示请一天假，可说 I’m taking a day off tomorrow。 |
| Can I pay with cash? | 正确。pay in cash / pay with cash 都可以。 |
| This will influence the release. | 语法正确；改为 could affect 同时改变了确定性，不能当成纯词汇替换。 |
| How is the project going now? | 完整正确；How’s it coming along? 是另一个表达。 |
| I will go to see a cafe. | 可理解；若意思是探店，可说 I’ll check out a cafe。改成 might 会改变确定性。 |
| This thing is new for me. | 可在合适语境使用；表示“不熟悉这个东西”常用 new to me。 |
| What is this money for? | 正确，问钱的用途；问陌生扣款则用 What is this charge for? 更精确。 |
| I checked this problem already. | 可理解；checked 和 looked into 的语义侧重点不同，不是硬性语法替换。 |
| I am going down now. | 语法正确；对楼下等你的司机说 coming down，体现朝对方移动的视角。 |
| Can you help me to check? | help someone do / help someone to do 都对；必要时补 it / this 等检查对象。 |
| I went there two times before. | 是否用过去时看上下文；谈截至现在的经历可说 I’ve been there twice。two times 本身并不错误。 |

类似 **I disagree / I want… / What should I do? / Where are you going? / My air conditioner is broken** 都可以是正常英语。课程给出的版本是额外选择，不应把原句全部视为“不自然”或“不专业”。

## 10｜搭配细节：把意思说完整

原文 **I have a question I’d like to confirm** 不够贴切。通常“提出问题”用 ask，“确认信息／事项”用 confirm：

> I have a question I’d like to ask.  
> There’s something I’d like to confirm.  
> I’d like to confirm one detail.

**toast** 表示烤面包时通常不可数，通用表达可说 **another slice of toast / another portion of kaya toast / a kaya toast set**；点餐中把某道菜单项目当作“一份”时，也可能出现 a kaya toast 等省略。

**Do you take card?** 能在口语中听到；更通用完整的表达是 **Do you accept cards? / Can I pay by card?**

**after two minutes** 并非任何情况下都错，例如 **After two minutes, restart the app.** 是“过两分钟后重启”。从现在起说“我两分钟后到”，通常用 **I’ll be there in two minutes.**

## 11｜现场练习补纠：不能用“Perfect”代替具体纠正

当时有几次在句子还不完整时就给予了“Perfect”等肯定。应把“意思能听懂”和“语法已准确”分开。

| 现场表达／转写片段 | 可复习的完整版本 |
|---|---|
| Hi, I’m Ethan … AI full stack engineer. | Hi, I’m Ethan. I’m an AI full-stack engineer. |
| happiness family | a happy family；happiness 是名词，happy 是形容词。 |
| I have a daughter … he … | I have a daughter. She…；指女儿时用 she。 |
| I got a Singapore PR last year. | I got permanent residency in Singapore last year. / I became a Singapore permanent resident last year. |
| I focus on building AI full stack skills. | I’m focusing on building my AI full-stack skills. 原来的 I focus on… 也能成立，侧重点不同。 |
| Does that help me my company … users’ flow | That helps my company improve user flows. 若想表达目的，可说 I’m developing these skills to help my company improve user flows. |
| It made make sense to ship … small version first. | It might make sense to ship a smaller version first. |
| I can release small version first. | I can release a smaller version first. / We can ship a smaller version first. |
| I have … the frontend UI, but I … still waiting… | I’ve finished the frontend UI, but I’m still waiting for the backend API. |
| I’m coding working on… | I’m working on the mock data. / I’m coding…；不要把 coding working 直接连用。 |
| If we finish testing tomorrow, can release… | If we finish testing tomorrow, we can release it on Friday. 主句补 we。 |
| I will order my dinner. | 语法正确；临时暂停去点餐也可说 I’m going to order dinner. |

教练当时说的 **what’s your focusing** 也不准确，应为 **what you’re focusing on**（嵌入句子中）或 **What are you focusing on?**（直接提问）。

现场中出现了 yesterday / last year、tomorrow / next year 的自我修正，以及 “Vivio”“Activity store”等不够明确的转写。本页保留这些原话，但不据此确认你的家庭姓名或出行日期。
